## Введение

Вы уже умеете запускать скрипты в фоновом режиме (`&`) и управлять ими с помощью `jobs`, `fg` и `bg`. Но что, если нужно **остановить** задачу, **возобновить** её или **завершить** — не просто нажав `Ctrl+C`, а с помощью команд?

Для этого в Linux есть мощный инструмент — **управление задачами (Job Control)**. Он позволяет:

- Останавливать и возобновлять задачи.
- Завершать задачи с помощью `kill`.
- Переключаться между задачами.
- Работать с несколькими задачами одновременно.

Этот урок поможет вам:

- Понять, что такое задачи и как их просматривать.
- Научиться останавливать, возобновлять и завершать задачи.
- Создавать надёжные скрипты, которые можно контролировать во время выполнения.

## Просмотр задач с помощью `jobs`

### Что это такое?

Команда `jobs` показывает список задач, запущенных в текущей сессии терминала. Каждая задача имеет номер (job number) и статус.

### Синтаксис:

```bash
jobs [опции]
```

По умолчанию `jobs` показывает только задачи, запущенные в текущей сессии.

### Просмотр задач

Файл `long_script.sh`:

```bash
#!/bin/bash
# Долгий скрипт

echo "Начинаю долгую работу..."
for i in {1..5}; do
    echo "Шаг $i"
    sleep 5
done
echo "Работа завершена."
```

Скрипт был запущен в фоне, и `jobs` показал его статус.

## Остановка и возобновление задач

### Остановка задачи

Чтобы остановить задачу, используйте `Ctrl+Z`. Это отправит сигнал `SIGTSTP`, который приостановит процесс.

### Возобновление задачи

Чтобы возобновить задачу, используйте:

- `fg` — вернуть задачу на передний план (в терминал).
- `bg` — вернуть задачу в фоновый режим.

### Остановка и возобновление

Файл `pause_resume.sh`:

```bash
#!/bin/bash
# Остановка и возобновление задачи

echo "Нажмите Ctrl+Z для приостановки."
while true; do
    echo "Работаю..."
    sleep 5
done
```

![](https://ucarecdn.stepik.net/f371db7a-be36-4be7-83ba-57d8dc564c43/)

Мы приостановили задачу (`Ctrl+Z`), посмотрели её статус (`jobs`), и вернули на передний план (`fg`).

## Завершение задач с помощью `kill`

### Что это такое?

Команда `kill` отправляет сигнал процессу, который может завершить его работу.

### Синтаксис:

```bash
kill [сигнал] PID
```

По умолчанию `kill` отправляет сигнал `SIGTERM` (15), который можно перехватить. Для принудительного завершения используйте `kill -9 PID`.

### Завершение задачи

Файл `stop_job.sh`:

```bash
#!/bin/bash
# Завершение задачи

echo "Нажмите Ctrl+Z для приостановки."
while true; do
    echo "Работаю..."
    sleep 5
done
```

![](https://ucarecdn.stepik.net/3a6cbff2-1026-4ded-ba15-ce45593c47b6/)

Мы завершили её с помощью `kill`.

## Управление задачами с помощью `bg` и `fg`

### Команда `bg`

Переводит задачу в фоновый режим.

### Команда `fg`

Переводит задачу на передний план.

### Управление задачами

Файл `manage_jobs.sh`:

```bash
#!/bin/bash
# Управление задачами

echo "Нажмите Ctrl+Z для приостановки."
while true; do
    echo "Работаю..."
    sleep 10
done
```

Мы приостановили задачу, а затем перевели её в фоновый режим с помощью `bg`.

## Практическое задание: создайте скрипт «Менеджер задач»

### Цель:

Написать скрипт `task_manager.sh`, который:

1. Запускает два скрипта в фоновом режиме.
2. Выводит список задач.
3. Останавливает одну из задач.
4. Возобновляет её в фоновом режиме.
5. Завершает обе задачи.

### Инструкция:

1. Создайте файл `task_manager.sh`.
2. Добавьте shebang `#!/bin/bash`.
3. Запустите два скрипта в фоне.
4. Используйте `jobs` для просмотра задач.
5. Используйте `kill` для завершения задач.
6. Сохраните, дайте права: `chmod u+x task_manager.sh`.
7. Запустите: `./task_manager.sh`.

### Пример решения:

```bash
#!/bin/bash
# Менеджер задач

# Запускаем два скрипта в фоне
echo "Запускаю скрипт 1..."
./script1.sh &
echo "Запускаю скрипт 2..."
./script2.sh &

# Ждём 2 секунды, чтобы задачи запустились
sleep 2

# Просматриваем задачи
echo ""
echo "=== Список задач ==="
jobs

# Останавливаем первую задачу
echo ""
echo "Останавливаю первую задачу..."
kill -STOP %1

# Просматриваем задачи
echo ""
echo "=== Список задач после остановки ==="
jobs

# Возобновляем первую задачу в фоне
echo ""
echo "Возобновляю первую задачу в фоне..."
kill -CONT %1

# Ждём 2 секунды
sleep 2

# Завершаем обе задачи
echo ""
echo "Завершаю обе задачи..."
kill %1 %2

echo ""
echo "Все задачи завершены."
```

![](https://ucarecdn.stepik.net/67d46273-7a32-4534-aeda-d34829bd64be/)

Команда `jobs` отображает состояние задач, управляемых текущей оболочкой. Но когда вы отправляете `SIGSTOP` напрямую через `kill`, оболочка _может не обновить статус_ в своём внутреннем списке задач — особенно если процесс не в foreground.

Плюс — если процесс был запущен в фоне (`&`), он не получает сигналы от терминала, и `SIGSTOP` может быть отправлен, но не отражён в `jobs`.
