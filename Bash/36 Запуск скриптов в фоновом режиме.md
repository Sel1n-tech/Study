## Введение

Вы уже умеете запускать скрипты из командной строки — но что, если скрипт выполняется долго, и вы хотите продолжить работу в терминале? Или запустить несколько скриптов одновременно?

Для этого в Linux есть возможность запускать процессы **в фоновом режиме** — это значит, что они работают «за кулисами», не блокируя ваш терминал.

Этот урок поможет вам:

- Понять, как запускать скрипты в фоновом режиме.
- Управлять фоновыми процессами с помощью `jobs`, `fg` и `bg`.
- Запускать скрипты без привязки к терминалу с помощью `nohup`.
- Создавать надёжные скрипты, которые продолжают работать даже после выхода из сессии.

## Запуск скрипта в фоновом режиме

### Что это такое?

Запуск в фоновом режиме — это когда скрипт работает **не в текущем терминале**, а в отдельном процессе. Вы можете продолжать вводить команды, пока скрипт работает.

### Синтаксис:

```bash
./скрипт.sh &
```

Амперсанд `&` ставится **в конце** команды.

### Простой запуск в фоне

Файл `background_loop.sh`:

```bash
#!/bin/bash
# Цикл, который работает в фоне

echo "Начинаю цикл..."
count=1
while [ $count -le 5 ]; do
    echo "Цикл #$count"
    sleep 1
    count=$((count + 1))
done
echo "Цикл завершён."
```

## Управление фоновыми задачами

### Команда `jobs`

Показывает список фоновых задач в текущей сессии.

Полезно, чтобы проверить, какие задачи запущены.

### Команды `fg` и `bg`

- `fg` — переводит задачу из фона на передний план (в терминал).
- `bg` — переводит остановленную задачу обратно в фон.

### Приостановка и возобновление задачи

Файл `pause_resume.sh`:

```bash
#!/bin/bash
# Приостановка и возобновление задачи

echo "Нажмите Ctrl+Z для приостановки."
while true; do
    echo "Работаю..."
    sleep 1
done
```

![](https://ucarecdn.stepik.net/b14305e9-bba3-49a4-87ab-361032dfdf7b/)

Мы приостановили задачу (`Ctrl+Z`), посмотрели её статус (`jobs`), и вернули на передний план (`fg`).

## Запуск нескольких фоновых задач

Вы можете запускать несколько задач одновременно — каждая получит свой номер задачи.

### Запуск нескольких задач

Файл `script1.sh`:

```bash
#!/bin/bash
echo "Запускаю скрипт 1..."
sleep 3
echo "Скрипт 1 завершён."
```

Файл `script2.sh`:

```bash
#!/bin/bash
echo "Запускаю скрипт 2..."

```

## Запуск скрипта без привязки к терминалу (`nohup`)

### Что это такое?

Если вы закроете терминал, все фоновые задачи завершатся. Чтобы скрипт продолжал работать после выхода из сессии, используйте команду `nohup`.

### Синтаксис:

```bash
nohup ./скрипт.sh &
```

По умолчанию `nohup` перенаправляет вывод в файл `nohup.out`.

Вы можете указать другой файл: `nohup ./скрипт.sh > output.txt 2>&1 &`.

### Запуск скрипта с `nohup`

Файл `long_script.sh`:

```bash
#!/bin/bash
# Долгий скрипт

echo "Начинаю долгую работу..."
for i in {1..10}; do
    echo "Шаг $i"
    sleep 1
done
echo "Работа завершена."
```

## Практическое задание: создайте скрипт «Мониторинг системы»

### Цель:

Написать скрипт `monitor_system.sh`, который:

1. Запускается в фоновом режиме.
2. Каждые 5 секунд выводит:
    - Текущее время.
    - Список запущенных процессов (`ps aux | head -n 5`).
3. Сохраняет вывод в файл `system_monitor.log`.
4. При завершении — выводит сообщение «Мониторинг остановлен».

### Инструкция:

1. Создайте файл `monitor_system.sh`.
2. Добавьте shebang `#!/bin/bash`.
3. Установите обработчик `EXIT` для вывода сообщения.
4. Запустите бесконечный цикл.
5. Используйте `>>` для записи в файл.
6. Сохраните, дайте права: `chmod u+x monitor_system.sh`.
7. Запустите: `./monitor_system.sh &`.

### Пример решения:

```bash
#!/bin/bash
# Мониторинг системы

# Обработчик завершения
trap 'echo "Мониторинг остановлен." >> system_monitor.log' EXIT

echo "Мониторинг запущен. Лог пишется в system_monitor.log"

while true; do
    echo "------------------------" >> system_monitor.log
    echo "Время: $(date)" >> system_monitor.log
    echo "Процессы:" >> system_monitor.log
    ps aux | head -n 5 >> system_monitor.log
    sleep 5
done
```
