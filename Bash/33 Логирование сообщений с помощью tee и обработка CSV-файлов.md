## Введение

Вы уже умеете перенаправлять вывод команд в файлы (`>`, `>>`) и подавлять его с помощью `/dev/null`. Но что, если нужно **одновременно** отображать вывод на экране **и** сохранять его в файле? Например, при запуске скрипта в фоновом режиме — вы хотите видеть результат, но и иметь лог для анализа.

Для этого в Linux есть мощный инструмент — команда **`tee`**. Она работает как «тройник» (T-образный разветвитель) — принимает данные из `STDIN` и отправляет их одновременно в `STDOUT` и в указанный файл.

Этот урок поможет вам:

- Понять, как работает команда `tee`.
- Использовать `tee` для логирования.
- Обрабатывать CSV-файлы с помощью цикла `while` и `read`.

## Команда `tee` — логирование и дублирование вывода

### Что это такое?

Команда `tee` читает данные из `STDIN` и записывает их одновременно в `STDOUT` (на экран) и в указанный файл.

### Синтаксис:

```bash
команда | tee [опции] имя_файла
```

По умолчанию `tee` перезаписывает файл. Чтобы добавлять данные в конец файла, используйте опцию `-a`.

### Логирование вывода команды

Файл `log_date.sh`:

```bash
#!/bin/bash
# Логируем текущую дату

date | tee date.log
echo "Дата записана в date.log"
```

### Добавление данных в файл

```bash
#!/bin/bash
```

## Обработка CSV-файлов

### Что это такое?

CSV (Comma-Separated Values) — это формат данных, где значения разделены запятыми.

Он часто используется в таблицах Excel и базах данных.

Чтобы обработать CSV-файл в Bash, можно использовать цикл `while` и команду `read`, предварительно установив `IFS=','`.

### Чтение CSV-файла

Файл `read_csv.sh`:

```bash
#!/bin/bash
# Читаем CSV-файл

filename="members.csv"

if [ ! -f "$filename" ]; then
    echo "Файл $filename не найден."
    exit 1
fi

# Устанавливаем IFS на запятую
IFS=","

echo "=== Список участников ==="
while read lname fname address city state zip
do
    echo "Имя: $fname $lname"
    echo "Адрес: $address, $city, $state $zip"
    echo "---"
done < "$filename"

# Восстанавливаем IFS
IFS=$' \t\n'
```

```no-highlight
Спондж,Боб,456 Oak Ave.,Columbus,OH,43201
```

## Создание SQL-запросов из CSV-файла

### Зачем это нужно?

Если вы хотите импортировать данные из CSV-файла в базу данных MySQL, можно создать SQL-запросы прямо в скрипте.

### Генерация SQL-запросов

Файл `create_sql.sh`:

```bash
#!/bin/bash
# Генерируем SQL-запросы из CSV-файла

input_file="$1"
output_file="members.sql"

if [ $# -ne 1 ]; then
    echo "Использование: $0 <имя_csv_файла>"
    exit 1
fi

if [ ! -f "$input_file" ]; then
    echo "Файл $input_file не найден."
    exit 1
fi

# Устанавливаем IFS на запятую
IFS=","

# Создаем файл с SQL-запросами
cat > "$output_file" << EOF
-- SQL-запросы для импорта данных
EOF

while read lname fname address city state zip
do
    echo "INSERT INTO members (lname, fname, address, city, state, zip) VALUES ('$lname', '$fname', '$address', '$city', '$state', '$zip');" >> "$output_file"
done < "$input_file"

echo "SQL-запросы созданы в файле $output_file"
```

## Практическое задание: создайте скрипт «Анализ продаж»

### Цель:

Написать скрипт `analyze_sales.sh`, который:

1. Принимает имя CSV-файла с данными о продажах как аргумент.
2. Читает файл и выводит:
    - Общую сумму продаж.
    - Среднюю стоимость продажи.
    - Самую дорогую продажу.
3. Сохраняет результаты в файл `sales_report.txt` с помощью `tee`.

### Инструкция:

1. Создайте файл `analyze_sales.sh`.
2. Добавьте shebang `#!/bin/bash`.
3. Проверьте количество аргументов: `if [ $# -ne 1 ]; then ... exit 1; fi`.
4. Проверьте существование файла: `if [ ! -f "$1" ]; then ... exit 1; fi`.
5. Установите `IFS=","`.
6. Используйте `while read` для чтения строк.
7. Вычислите общую сумму, среднее значение и максимальную цену.
8. Используйте `tee` для вывода результатов на экран и в файл.
9. Сохраните, дайте права: `chmod u+x analyze_sales.sh`.
10. Создайте тестовый файл `sales.csv` и запустите: `./analyze_sales.sh sales.csv`.

### Пример решения:

```bash
#!/bin/bash
# Анализ продаж

if [ $# -ne 1 ]; then
    echo "Использование: $0 <имя_csv_файла>"
    exit 1
fi

filename="$1"

if [ ! -f "$filename" ]; then
    echo "Файл $filename не найден."
    exit 1
fi

# Устанавливаем IFS на запятую
IFS=","

total=0
count=0
max_price=0

while read product price
do
    total=$((total + price))
    ((count++))
    if [ $price -gt $max_price ]; then
        max_price=$price
    fi
done < "$filename"

# Восстанавливаем IFS
IFS=$' \t\n'

# Выводим результаты
echo "=== Отчёт по продажам ===" | tee sales_report.txt
echo "Общая сумма продаж: $total" | tee -a sales_report.txt
echo "Средняя стоимость: $((total / count))" | tee -a sales_report.txt
echo "Самая дорогая продажа: $max_price" | tee -a sales_report.txt
echo "Отчёт сохранён в sales_report.txt"
```
