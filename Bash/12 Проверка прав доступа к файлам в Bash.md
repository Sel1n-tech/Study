## Введение

Вы уже умеете проверять существование файлов и директорий, а также их тип. Но часто нужно убедиться, что вы **имеете права** на чтение, запись или выполнение файла — особенно если ваш скрипт должен работать с конфиденциальными данными, создавать логи или запускать другие программы.

Этот урок поможет вам:

- Понять, как проверить права доступа к файлу.
- Использовать операторы `-r`, `-w`, `-x`.
- Создавать надёжные скрипты, которые не сломаются при отсутствии нужных прав.
- Избегать распространённых ошибок при работе с файлами.

## Операторы проверки прав доступа

Команда `test` (или `[ ]`) позволяет проверять права доступа к файлам с помощью следующих операторов:

|Оператор|Описание|
|---|---|
|`-r file`|Проверяет, существует ли файл и доступен ли для **чтения**|
|`-w file`|Проверяет, существует ли файл и доступен ли для **записи**|
|`-x file`|Проверяет, существует ли файл и доступен ли для **выполнения**|

Эти операторы работают только если файл существует. Поэтому перед проверкой прав рекомендуется сначала проверить существование файла с помощью `-e` или `-f`.

## Проверка прав на чтение (`-r`)

Часто нужно убедиться, что файл можно прочитать, прежде чем пытаться его обработать.

### Проверка прав на чтение файла `/etc/passwd`

Файл `check_read.sh`:

```bash
#!/bin/bash
# Проверяем, можно ли прочитать файл

pwfile="/etc/passwd"

if [ -f "$pwfile" ]
then
    if [ -r "$pwfile" ]
    then
        echo "Файл $pwfile существует и доступен для чтения."
        # Выводим последние 5 строк файла
        tail -n 5 "$pwfile"
    else
        echo "Файл $pwfile существует, но недоступен для чтения."
    fi
else
    echo "Файл $pwfile не существует."
fi
```

## Проверка, является ли файл пустым (`-s`)

Иногда нужно проверить, содержит ли файл данные, чтобы не удалять важный файл по ошибке.

### Проверка и удаление пустого файла

Файл `check_empty.sh`:

```bash
#!/bin/bash
# Проверяем, пустой ли файл, и удаляем его, если да

file_name="$HOME/dobro.txt"

if [ -f "$file_name" ]
then
    if [ -s "$file_name" ]
    then
        echo "Файл $file_name существует и содержит данные. Не удаляем."
    else
        echo "Файл $file_name существует, но пуст. Удаляем..."
        rm "$file_name"
        echo "Файл удалён."
    fi
else
    echo "Файл $file_name не существует."
fi
```

![](https://ucarecdn.stepik.net/8d371e01-f327-4311-9002-1808d8c0a866/)

Оператор `-s` возвращает `true`, если файл существует и **не пустой** (размер > 0).

## Проверка прав на запись (`-w`)

Если ваш скрипт должен записывать данные в файл, важно убедиться, что у вас есть права на запись.

### Проверка прав на запись и запись данных

Файл `check_write.sh`:

```bash
#!/bin/bash
# Проверяем, можно ли записать в файл

item_name="$HOME/dobro.txt"

echo "Проверяем объект: $item_name"

if [ -f "$item_name" ]
then
    echo "Объект $item_name существует."

    if [ -w "$item_name" ]
    then
        echo "Файл доступен для записи."
        echo "Текущее время: $(date)" >> "$item_name"
        echo "Данные успешно записаны."
    else
        echo "Файл недоступен для записи."
    fi
else
    echo "Объект $item_name не существует."
fi
```

## Практическое задание: создайте скрипт «Безопасное обновление»

### Цель:

Написать скрипт `safe_update.sh`, который:

1. Проверяет, существует ли файл `/var/log/myapp/app.log`.
2. Если файл не существует — создаёт его.
3. Проверяет, доступен ли файл для записи.
4. Если файл доступен для записи — добавляет текущую дату и время в конец файла.
5. Если файл не доступен для записи — выводит сообщение об ошибке.

### Инструкция:

1. Создайте файл `safe_update.sh`.
2. Добавьте shebang `#!/bin/bash`.
3. Используйте `[ -f ... ]` для проверки файла, `[ -w ... ]` для проверки прав.
4. Используйте `touch` для создания файла, `>>` для добавления данных.
5. Сохраните, дайте права: `chmod u+x safe_update.sh`.
6. Запустите: `./safe_update.sh`.

### Пример решения:

```bash
#!/bin/bash
# Безопасное обновление лог-файла

log_file="/var/log/myapp/app.log"

# Проверяем и создаём файл, если он не существует
if [ ! -f "$log_file" ]; then
    echo "Файл $log_file не существует. Создаём..."
    sudo touch "$log_file"
    if [ $? -eq 0 ]; then
        echo "Файл создан."
    else
        echo "Не удалось создать файл. Проверьте права."
        exit 1
    fi
fi

# Проверяем права на запись
if [ -w "$log_file" ]; then
    echo "Файл доступен для записи."
    echo "$(date): Скрипт выполнен." >> "$log_file"
    echo "Лог-файл обновлён."
else
    echo "Файл $log_file недоступен для записи."
    echo "Попробуйте изменить права с помощью 'chmod u+w $log_file'"
fi
```
