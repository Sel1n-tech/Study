**Git индекс** (или staging area) — это промежуточная область, где формируется содержимое следующего коммита, позволяя выбрать конкретные изменения для фиксации.

## Компоненты Git

![](https://ucarecdn.stepik.net/9d8f2415-86e7-4a01-a874-638fedf4fde9/)

## Состояния файлов в Git

![](https://ucarecdn.stepik.net/40dab66b-86e8-4a0b-9e7b-f2b698d27854/)

1. **Untracked** — файл не отслеживается Git.
    
2. **Staged** — файл добавлен в индекс и готов к коммиту.
    
3. **Modified** — файл изменён, но изменения не добавлены в индекс.
    
4. **Unmodified** — файл не изменён с момента последнего коммита.
    

## Новые команды

```bash
# отменить все изменения после последнего коммита
# (подробнее будет рассмотрена далее в курсе)
git reset --hard
```
