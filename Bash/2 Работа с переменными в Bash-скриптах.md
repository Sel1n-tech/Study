## Введение

Вы уже умеете создавать простые скрипты, которые выполняют последовательность команд. Но настоящая мощь скриптов раскрывается, когда вы начинаете использовать **переменные** — «коробки», в которые можно временно сохранять данные (текст, числа, результаты команд) и использовать их позже в скрипте. Это делает ваши скрипты гибкими и динамичными.

## Системные переменные (окружение)

### Что это такое?

Это переменные, которые система создаёт автоматически при запуске оболочки. Они хранят важную информацию о системе и пользователе: имя пользователя, домашнюю директорию, путь к исполняемым файлам и т.д.

Чтобы увидеть все доступные переменные окружения, используйте команду:

```bash
set
```

![697](https://ucarecdn.stepik.net/99eb2626-1c91-4d25-ab0d-7f0158416733/)

Часто используемые переменные — `HOME`, `USER`, `PATH`. Запомните их — они вам пригодятся!

![](https://ucarecdn.stepik.net/2cebe9b2-4d4a-43de-a8e5-365f345ddc75/)

### Как использовать системные переменные?

Чтобы получить значение переменной, нужно поставить перед её именем знак доллара `$`.

**Пример скрипта `user_info.sh`:**

```bash
#!/bin/bash
# Выводим информацию о текущем пользователе
echo "Привет, $USER!"
echo "Твой UID (идентификатор пользователя): $UID"
echo "Твоя домашняя директория: $HOME"
```

![](https://ucarecdn.stepik.net/64cbe795-beb3-4404-bb48-e1de97c4de83/)

Переменные чувствительны к регистру! `$USER` и `$user` — это разные переменные (если `$user` не был создан, он будет пустым).

![](https://ucarecdn.stepik.net/e73f4197-8e4a-4650-b91b-d1f7034157e4/)

## Как избежать ошибок с символом `$`

Иногда вам нужно вывести текст, содержащий символ `$`, например, цену товара.

**Неправильно:**

```bash
echo "Стоимость товара: $15"
```

![](https://ucarecdn.stepik.net/45d362bf-ebf0-43e9-900c-80bb59546199/)

Shell интерпретирует `$15` как переменную с именем `1`, которая не существует, поэтому выводит пустую строку. Оставшийся `5` — это просто текст.

**Правильно:**

```bash
echo "Стоимость товара: \$15"
```

![](https://ucarecdn.stepik.net/6b09e466-331e-4cc6-aacd-2502f3221a6d/)

_Как работает?_ Обратный слэш `\` экранирует символ `$`, заставляя shell воспринимать его как обычный текст.

**Альтернатива:** можно использовать одинарные кавычки `'...'`, внутри которых переменные не подставляются:

```bash
echo 'Стоимость товара: $15'
```

![](https://ucarecdn.stepik.net/9c433459-548f-4445-a059-39a3f61e1e23/)

## Создание своих переменных (пользовательские переменные)

### Как объявить переменную?

Синтаксис очень простой:

```bash
имя_переменной=значение
```

**Важные правила:**

- Никаких пробелов до и после знака `=`.
- Имя может содержать буквы, цифры и символ `_` (нижнее подчеркивание).
- Имя чувствительно к регистру: `MyVar` ≠ `myvar`.
- Длина имени — до 20 символов (хотя на практике ограничений нет).

**Примеры:**

```bash
count=5
name="Тукс"
message="Привет, мир!"
is_active=true
```

### Как использовать переменную?

Чтобы получить значение переменной, используйте `$` перед её именем:

```bash
echo "Имя: $name"
echo "Количество: $count"
```

![](https://ucarecdn.stepik.net/80b2d6eb-05bf-42d9-89a5-943b8c179333/)

Пример скрипта `greeting.sh`:

```bash
#!/bin/bash
# Простой приветственный скрипт
name="Аделаида"
days=7

echo "Привет, $name!"
echo "Ты была здесь $days дней назад."
echo "--------------------------"

# Меняем значения
name="Прокофий"
days=1

echo "Привет, $name!"
echo "Ты был здесь $days день назад."
```

![](https://ucarecdn.stepik.net/751207fd-3544-4c10-b577-0916b69608b9/)

При _присваивании_ значения переменной — `$` не используется. При _использовании_ значения — `$` обязателен.

## Командная подстановка — сохраняем результат команды в переменную

Это одна из самых полезных возможностей в скриптах! Вы можете выполнить команду и сохранить её вывод в переменную.

Есть два способа.

### Способ 1: Обратные кавычки (backticks) `` `...` ``

```bash
current_date=`date`
echo "Сегодня: $current_date"
```

![](https://ucarecdn.stepik.net/04e3cb3d-5f8a-4d6c-8a0e-6e60f1420248/)

### Способ 2: `$()` — предпочтительный способ

```bash
current_date=$(date)
echo "Сегодня: $current_date"
```

![](https://ucarecdn.stepik.net/46e843f8-e140-4119-86b3-1e97bd5a40b8/)

Используйте `$()`, так как это современный стандарт, более читаемый и позволяет вкладывать команды друг в друга.

### Пример скрипта `log_today.sh`:

```bash
#!/bin/bash
# Создаём лог-файл с текущей датой в имени

# Получаем дату в формате ГГММДД
today=$(date +%Y%m%d)

# Создаём файл с логом
ls -l /usr/bin > log.$today

echo "Лог-файл создан: log.$today"
echo "Содержимое файла:"
cat log.$today
```

![](https://ucarecdn.stepik.net/1122733f-9632-482b-b60a-80a48982625d/)

`%Y%m%d` — это формат даты: год (4 цифры), месяц (2 цифры), день (2 цифры).

Такой формат удобен для сортировки файлов по дате.














## Практическое задание: создайте свой скрипт с переменными

### Цель:

Написать скрипт, который:

1. Выводит приветствие с вашим именем (используйте переменную).
2. Сохраняет текущую дату в переменную.
3. Создаёт файл с именем `backup_YYYYMMDD.txt`, где `YYYYMMDD` — текущая дата.
4. Записывает в этот файл список файлов в вашей домашней директории (`ls ~`).
5. Выводит сообщение о создании файла.

### Инструкция:

1. Создайте файл `my_backup.sh`.
2. Добавьте shebang `#!/bin/bash`.
3. Напишите код, используя переменные и командную подстановку.
4. Сохраните, дайте права: `chmod u+x my_backup.sh`.
5. Запустите: `./my_backup.sh`.

### Пример решения:

```bash
#!/bin/bash
# Мой скрипт резервного копирования

# Имя пользователя
my_name="Аристарх"

# Текущая дата
backup_date=$(date +%Y%m%d)

# Имя файла
filename="backup_$backup_date.txt"

# Создаём файл и записываем в него список файлов
ls ~ > "$filename"

# Выводим сообщение
echo "Привет, $my_name!"
echo "Файл резервной копии создан: $filename"
echo "Содержимое файла:"
cat "$filename"
```

## Заключение

Вы узнали, как:

- Использовать системные переменные (`$USER`, `$HOME` и др.).
- Создавать и использовать свои переменные.
- Экранировать символ `$` с помощью `\` или одинарных кавычек.
- Сохранять результат выполнения команд в переменные с помощью `$()`.

Переменные — это основа любого серьёзного скрипта. Без них вы не сможете писать гибкие и универсальные программы.
