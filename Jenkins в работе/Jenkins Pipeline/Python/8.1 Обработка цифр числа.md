## Обработка цифр числа с помощью цикла while

При изучении целых чисел (тип данных `int`) мы [говорили](https://stepik.org/lesson/284816/step/1?unit=266160) про операцию целочисленного деления `//` и операцию нахождения остатка от деления одного целого числа на другое `%`. Используя цикл `while` и две данных операции, можно обработать цифры числа с произвольным количеством разрядов (цифр).

Пусть дано натуральное число `num`. Тогда:

- результатом операции `num % 10` является последняя цифра числа
- результатом операции `num // 10` является число с удалённой последней цифрой

Напишем программу, которая считывает натуральное число и обрабатывает его цифры.

```python
num = int(input())                                # считываем число
while num != 0:                                   # проверяем, что цифры числа не закончились
    last_digit = num % 10                         # получаем последнюю цифру числа
    ...                                           # обрабатываем последнюю цифру числа
    num = num // 10                               # удаляем последнюю цифру из числа
```

Цикл `while` работает до тех пор, пока в числе есть необработанные цифры. Тело цикла содержит:

1. процедуру получения последней цифры `last_digit = num % 10`
2. код обработки последней цифры
3. процедуру удаления последней цифры из числа `num = num // 10`

В качестве процедуры обработки может быть всё что угодно: вывод цифр, нахождение суммы, произведения цифр, нахождение наибольшей или наименьшей цифры, подсчёт цифр, удовлетворяющих некоторому условию, и так далее.

Напишем программу, которая определяет, есть ли в числе `num` цифра `7`.

```python
num = 1576
has_seven = False                                 # сигнальная метка (флаг)

while num != 0:
    last_digit = num % 10
    if last_digit == 7:
        has_seven = True
    num = num // 10

if has_seven == True:
    print('YES')
else:
    print('NO')
```

Приведённый выше код выводит:

```no-highlight
YES
```

## Обработка цифр числа с помощью цикла for

В одном из уроков мы [говорили](https://stepik.org/lesson/284816/step/19?unit=266160) про получение любой цифры числа по формуле:

 `(num // 10 ** (n - i)) % 10`

где `n` – количество разрядов числа, `i` – номер цифры числа (слева направо, начиная с `1`).

Для того чтобы пройтись по всем цифрам числа, нам нужно лишь знать количество разрядов `n` этого числа. Мы можем найти количество разрядов `n` следующим способом:

```python
n = len(str(num))
```

Другими словами, можно сказать, что тут мы находим «длину» числа.

Если все разряды числа пронумеровать от `1` до `n` включительно, то мы можем рассмотреть все цифры числа слева направо следующим образом:

```python
num = int(input())                                # считываем число
n = len(str(num))                                 # количество разрядов числа
for i in range(1, n + 1):                         # проходим по всем разрядам числа от 1 до n
    digit = num // 10 ** (n - i) % 10             # получаем i-ю цифру числа
    ...                                           # обрабатываем i-ю цифру числа
```

Приведённый ниже код:

```python
num = 8619
n = len(str(num))
for i in range(1, n + 1):
    digit = num // 10 ** (n - i) % 10
    print(i, '-я', ' цифра равна ', digit, sep='')
```

выводит:

```no-highlight
1-я цифра равна 8
2-я цифра равна 6
3-я цифра равна 1
4-я цифра равна 9
```
