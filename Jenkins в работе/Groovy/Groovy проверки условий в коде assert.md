## Проверки условий в коде

`**assert**` — это ключевое слово в Groovy lang, которое используется для проверки условий в коде, позволяет убедиться, что определённые условия выполняются, и если это не так, то генерируется исключение **AssertionError**.

> **логическое выражение** — это конструкция языка программирования, которая принимает значение "истина" или "ложь". 

**Синтаксис использования assert**:

```java
assert <условие>
```

или с сообщением

```php-template
assert <условие>: <сообщение об ошибке>
```

где:

- `**условие**` — это логическое выражение, которое должно быть истинным;
- `**сообщение об ошибке**` — это необязательное сообщение, которое будет выведено, если условие не выполняется.

Если условие не выполняется, то генерируется **исключение AssertionError**.

1. Начните утверждение с ключевого слова `assert`.
    
2. Укажите условие, которое хотите проверить.
    
3. Если условие истинно, код продолжит выполняться. Если ложно, будет выброшено исключение AssertionError.
    
4. При необходимости добавьте сообщение после запятой, чтобы предоставить больше контекста для утверждения.
    

Пример:

```java
assert 2 + 2 == 4
```

В этом примере утверждение проверяет равенство суммы `2 + 2` с ожидаемым значением 4. Если условие не выполняется, будет выброшено исключение AssertionError. Вот другой пример с ошибкой:

```java
assert 2 + 1 == 4
```

Пример использования синтаксиса `**assert с условием и сообщением об ошибке**` в Groovy:

```java
def isEven = { num -> num % 2 == 0 }
assert isEven(5): "The number must be even" // Число должно быть чётным
```

В этом примере проверяется, является ли число чётным. Если число нечётное, то генерируется исключение **AssertionError** с сообщением **_"The number must be even"_**.

![](https://ucarecdn.stepik.net/8a602dfa-eb57-49ab-a596-ce891819127f/)

Вот несколько примеров использования assert:

1. **Проверка равенства**:
    
    ```java
    assert 5 == 3 // вызовет исключение AssertionError, так как условие не выполняется
    ```
    
2. **Проверка неравенства**:
    
    ```java
    assert 5 != 3 // не вызовет исключения, так как условие выполняется
    ```
    
3. **Проверка логического выражения**:
    
    ```java
    def isEven = { num -> num % 2 == 0 }
    assert isEven(5) // вызовет исключение AssertionError, так как 5 нечётное число
    ```
    
4. **Проверка диапазона**:
    
    ```java
    assert 10 >= 5 // не вызовет исключения, так как условие выполняется
    assert 10 < 15 // не вызовет исключения, так как условие выполняется
    ```
    
5. **Проверка типа**:
    
    ```java
    def isString = { obj -> obj instanceof String }
    def str = "Hello"
    assert isString(str) // не вызовет исключения, так как str является строкой
    ```
    
6. **Проверка наличия элемента в коллекции**:
    

`**contains**` — это один из методов коллекций в Groovy, который используется для проверки наличия элемента в коллекции. Он принимает элемент в качестве аргумента и возвращает **true** если элемент присутствует в коллекции, а **false -** если его нет.

**Синтаксис использования метода**:

```scss
collection.contains(element)
```

где:

- **collection** — это коллекция, в которой нужно проверить наличие элемента;
- **element** — это элемент, который нужно проверить на наличие в коллекции.

Вот несколько примеров использования метода contains:

1. **Проверка наличия элемента в списке**:
    
    ```java
    def list1 = [1, 2, 3, 4, 5]
    assert list1.contains(3) // вернёт true, так как 3 присутствует в списке
    ```
    
2. **Проверка наличия элемента в map** 
    
    ```yaml
    def map1 = [a: 1, b: 2, c: 3]
    assert map1.containsValue(2) // вернёт true, так как значение 2 присутствует
    ```
    

Обратите внимание что **использование assert может быть отключено в режиме оптимизации**. Поэтому, если вы используете `assert` для проверки условий, которые должны выполняться всегда, убедитесь, что вы не отключаете оптимизацию.

Также стоит учесть, что **assert не следует использовать для проверки входных данных**, так как это может привести к неожиданным результатам. Вместо этого используйте `assert` для проверки внутренних условий вашего кода.
