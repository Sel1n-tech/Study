## Введение

Вы уже умеете обрабатывать опции командной строки вручную с помощью `case` и `shift`. Но что, если пользователь хочет передать опции в сокращённом виде (например, `-abc` вместо `-a -b -c`) или с пробелами в значениях? Ручная обработка становится сложной и подвержена ошибкам.

Для таких случаев в Linux есть мощный инструмент — команда **`getopt`**. Она автоматически разбирает опции и параметры, приводит их к стандартному формату и позволяет легко работать с ними в скрипте.

Этот урок поможет вам:

- Понять, как работает команда `getopt`.
- Использовать её для обработки опций.
- Обрабатывать сокращённые опции и значения с пробелами.
- Создавать удобные и надёжные скрипты.

## Что такое `getopt`?

Команда `getopt` принимает список опций и параметров, анализирует их и возвращает отформатированную строку, которую можно использовать в скрипте.

### Синтаксис:

```bash
getopt [опции] опция_строка параметры
```

Опция `-q` подавляет сообщения об ошибках, а `-o` (или `--options`) указывает допустимые опции.

## Формат опции-строки

Опция-строка (`optstring`) определяет, какие опции разрешены и требуют ли они значений.

|Символ|Значение|
|---|---|
|`a`|Опция `-a` без значения|
|`a:`|Опция `-a`, требующая значения (двоеточие после буквы)|

### Простой вызов `getopt`

Файл `test_getopt.sh`:

```bash
#!/bin/bash
# Тестирование getopt

echo "Исходные параметры: $@"
result=$(getopt -q ab:c "$@")
echo "Результат: $result"
```

## Интеграция `getopt` в скрипт

Чтобы использовать `getopt` в скрипте, нужно заменить исходные параметры на отформатированные. Для этого используется команда `set`.

### Использование `getopt` в скрипте

Файл `handle_options_getopt.sh`:

```bash
#!/bin/bash
# Обработка опций с помощью getopt

# Получаем отформатированные параметры
set -- $(getopt -q ab:c "$@")

# Обрабатываем опции
while [ -n "$1" ]; do
    case "$1" in
        -a)
            echo "Найдена опция -a"
            ;;
        -b)
            value="$2"
            echo "Найдена опция -b со значением: $value"
            shift  # Убираем значение
            ;;
        -c)
            echo "Найдена опция -c"
            ;;
        --)
            shift  # Убираем --
            break
            ;;
        *)
            echo "Неизвестная опция: $1"
            ;;
    esac
    shift
done

echo ""
echo "Параметры:"
count=1
for param in "$@"
do
    echo "Параметр #$count: $param"
    ((count++))
done
```

## Обработка сокращённых опций

Одна из главных особенностей `getopt` — это поддержка сокращённых опций. Например, `-abc` эквивалентно `-a -b -c`.

![](https://ucarecdn.stepik.net/2b1bfb48-35fe-4781-a2ac-f6874945fda6/)

### Пример 3: Сокращённые опции

Файл `short_options.sh`:

```bash
#!/bin/bash
# Обработка сокращённых опций

set -- $(getopt -q abc "$@")

while [ -n "$1" ]; do
    case "$1" in
        -a)
            echo "Найдена опция -a"
            ;;
        -b)
            echo "Найдена опция -b"
            ;;
        -c)
            echo "Найдена опция -c"
            ;;
        --)
            shift
            break
            ;;
        *)
            echo "Неизвестная опция: $1"
            ;;
    esac
    shift
done
```

## Ограничения `getopt`

Хотя `getopt` очень мощный, у него есть ограничения:

- Не работает с опциями, содержащими пробелы (если не использовать кавычки).
- Не поддерживает длинные опции (например, `--help`).

Для решения этих проблем в современных системах используется `getopts` — но об этом в другом уроке.

## Практическое задание: создайте скрипт «Умный калькулятор»

### Цель:

Написать скрипт `smart_calc.sh`, который:

1. Принимает опции:
    - `-h` — выводит справку.
    - `-v` — включает подробный вывод.
    - `-o <file>` — указывает файл для вывода.
2. После опций обрабатывает оставшиеся параметры как числа для вычисления.
3. Выполняет операцию сложения или умножения в зависимости от опции.
4. Выводит результат.

### Инструкция:

1. Создайте файл `smart_calc.sh`.
2. Добавьте shebang `#!/bin/bash`.
3. Используйте `getopt` для обработки опций.
4. Используйте `set` для замены параметров.
5. Используйте `case` для обработки опций.
6. Сохраните, дайте права: `chmod u+x smart_calc.sh`.
7. Запустите: `./smart_calc.sh -v -o result.txt 10 20 30`.

### Пример решения:

```bash
#!/bin/bash
# Умный калькулятор

# Получаем отформатированные параметры
set -- $(getopt -q hv:o: "$@")

verbose=false
output_file=""
operation="add"

while [ -n "$1" ]; do
    case "$1" in
        -h)
            echo "Использование: $0 [-h] [-v] [-o <файл>] <числа>"
            echo "  -h    Показать эту справку"
            echo "  -v    Включить подробный вывод"
            echo "  -o    Указать файл для вывода"
            echo "  Числа  Список чисел для вычисления"
            exit 0
            ;;
        -v)
            verbose=true
            echo "Подробный вывод включён."
            ;;
        -o)
            output_file="$2"
            echo "Файл вывода: $output_file"
            shift  # Убираем значение
            ;;
        --)
            shift
            break
            ;;
        *)
            echo "Неизвестная опция: $1"
            ;;
    esac
    shift
done

# Проверяем, что переданы числа
if [ $# -eq 0 ]; then
    echo "Не переданы числа. Использование: $0 <число1> <число2> ..."
    exit 1
fi

# Вычисляем сумму
sum=0
for num in "$@"
do
    num=${num//\'/}
    sum=$((sum + num))
done

# Выводим результат
if [ -n "$output_file" ]; then
    output_file=${output_file//\'/}
    echo "Результат: $sum" > "$output_file"
    echo "Результат записан в файл: $output_file"
else
    echo "Результат: $sum"
fi

if [ "$verbose" = true ]; then
    echo ""
    echo "Подробная информация:"
    for num in "$@"
    do
        echo "  Число: $num"
    done
fi
```
