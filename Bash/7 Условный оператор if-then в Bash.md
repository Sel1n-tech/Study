## Введение

Вы уже умеете создавать скрипты, которые выполняют команды последовательно. Но настоящая мощь программирования раскрывается, когда вы начинаете **принимать решения** на основе данных. В Bash это делает условный оператор `if-then`.

Этот урок поможет вам:

- Понять, как работает `if-then` в Bash (это не так, как в Python или C!).
- Использовать команды для проверки условий.
- Обрабатывать несколько команд внутри блока `then`.
- Добавлять альтернативные ветки с помощью `else`.

## Основной синтаксис `if-then`

### Как это работает?

В отличие от других языков, где `if` проверяет выражение на `true/false`, в Bash **команда после `if` запускается**, и её **код завершения (`$?`)** определяет дальнейшее выполнение:

- Если код завершения **равен 0** → условие считается **истинным** → выполняются команды в блоке `then`.
- Если код завершения **не равен 0** → условие **ложное** → команды в `then` пропускаются.

### Базовый синтаксис:

```no-highlight
if команда
then
    команды_если_успешно
fi
```

Команда после `if` может быть любой — `pwd`, `ls`, `grep`, даже ваш собственный скрипт. Главное — её код завершения должен быть `0` для "истины".

## Примеры работы `if-then`

### Простая проверка

Файл `check_pwd.sh`:

```bash
#!/bin/bash
# Проверяем, успешно ли выполнилась команда pwd

if pwd
then
    echo "Команда pwd выполнилась успешно!"
fi
```

## Много команд в блоке `then`

Блок `then` может содержать **любое количество команд**. Они выполняются все, если условие истинно.

### Проверка пользователя

Файл `check_user.sh`:

```bash
#!/bin/bash
# Проверяем, существует ли пользователь 'mrkitty'

testuser="mrkitty"

if grep "$testuser" /etc/passwd
then
    echo "Пользователь $testuser найден!"
    echo "Его домашняя директория:"
    grep "$testuser" /etc/passwd | cut -d: -f6
    echo "Список файлов в его домашней директории:"
    ls -a "/home/$testuser"
fi
```

![](https://ucarecdn.stepik.net/eb9e50f7-a7ec-4d1c-ada6-757b2dacf2b2/)

`grep "$testuser" /etc/passwd` — ищет строку с именем пользователя.

Если строка найдена → `grep` возвращает `0` → выполняется блок `then`.

Если не найдена → `grep` возвращает `1` → блок `then` пропускается.

Если в системе нет пользователя, ничего не выведется. Это нормально — условие ложно.

## Альтернативный синтаксис — `if; then`

Иногда удобнее писать `if` и `then` в одной строке, разделив их точкой с запятой `;`. Это полезно для коротких условий.

### Синтаксис:

```bash
if команда; then
    команды
fi
```

**Пример:**

```bash
if [ -f "myfile.txt" ]; then
    echo "Файл существует."
fi
```

Этот стиль часто используется в однострочных командах в терминале.

## Добавляем `else` — обработка "иначе"

Часто нужно сделать что-то, если условие **не** выполнилось. Для этого используется блок `else`.

### Синтаксис:

```bash
if команда
then
    команды_если_успешно
else
    команды_если_неуспешно
fi
```

### Улучшенная проверка пользователя

## Практическое задание: создайте свой скрипт с `if-then-else`

### Цель:

Написать скрипт `file_check.sh`, который:

1. Проверяет, существует ли файл `data.txt` в текущей директории.
2. Если файл существует — выводит его размер и дату изменения.
3. Если файла нет — создаёт его и пишет туда сообщение "Файл создан автоматически".
4. В любом случае выводит сообщение о результате.

### Инструкция:

1. Создайте файл `file_check.sh`.
2. Добавьте shebang `#!/bin/bash`.
3. Используйте команду `[ -f "data.txt" ]` для проверки существования файла.
    
    `[ -f имя_файла ]` — это команда, которая возвращает `0`, если файл существует и является обычным файлом.
    
4. В блоке `then` используйте `ls -l data.txt` для вывода информации.
5. В блоке `else` используйте `touch data.txt` и `echo "..." >> data.txt`.
6. Сохраните, дайте права: `chmod u+x file_check.sh`.
7. Запустите: `./file_check.sh`.

### Пример решения:

```bash
#!/bin/bash
# Проверка и создание файла data.txt

if [ -f "data.txt" ]
then
    echo "Файл data.txt существует."
    echo "Информация о файле:"
    ls -l data.txt
else
    echo "Файл data.txt не найден. Создаём новый файл..."
    touch data.txt
    echo "Файл создан автоматически." >> data.txt
    echo "Файл data.txt успешно создан."
fi
```
