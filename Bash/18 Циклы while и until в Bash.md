## Введение

Вы уже умеете использовать цикл `for`, который повторяет команды для каждого элемента из списка. Но что, если вы не знаете, сколько раз нужно повторить команды? Например, вам нужно читать ввод пользователя до тех пор, пока он не введёт "quit", или выполнять команду до тех пор, пока файл не будет создан.

Для таких задач в Bash есть два мощных инструмента:

- **Цикл `while`** — выполняет команды, пока условие истинно.
- **Цикл `until`** — выполняет команды, пока условие ложно.

Этот урок поможет вам:

- Понять, как работают циклы `while` и `until`.
- Использовать их с переменными и командами.
- Избежать бесконечных циклов.
- Применять циклы в реальных задачах.

## Цикл `while`

### Что это такое?

Цикл `while` повторяет набор команд, пока условие (команда) возвращает **нулевой код завершения** (истина).

### Синтаксис:

```bash
while команда_проверки
do
    команды
done
```

Команда проверки может быть любой — от простого сравнения переменной до сложного выражения с `[ ]` или `(( ))`.

### Обратный отсчёт

Файл `countdown.sh`:

```bash
#!/bin/bash
# Обратный отсчёт от 5 до 1

count=5

while [ $count -gt 0 ]
do
    echo "Осталось: $count"
    count=$((count - 1))
done

echo "Пуск!"
```

Внутри цикла мы **обязательно изменяем переменную**, иначе цикл станет бесконечным!

## Множественные команды в условии `while`

Иногда нужно проверить несколько условий. В `while` можно указать несколько команд — но **учитывается только код завершения последней команды**.

### Проверка двух условий

Файл `multi_condition.sh`:

```bash
#!/bin/bash
# Проверяем два условия

count=10

while echo "Текущее значение: $count" && [ $count -ge 0 ]
do
    echo "Это внутри цикла"
    count=$((count - 1))
done
```

![](https://ucarecdn.stepik.net/1e3386bf-6164-4395-9848-b2c2f913d06d/)

Последняя команда `[ $count -ge 0 ]` вернула `1` (ложь), когда `count = -1`, поэтому цикл остановился. Но первая команда `echo` всегда возвращает `0`, поэтому она не влияет на условие.

Если вы хотите, чтобы цикл продолжался, пока **оба** условия истинны, используйте `&&` внутри `[ ]`:

```bash
while [ $count -ge 0 ] && [ $count -le 10 ]; do ...
```

## Цикл `until`

### Что это такое?

Цикл `until` — это «обратный» `while`. Он повторяет команды, пока условие **ложно** (возвращает ненулевой код завершения). Как только условие становится истинным — цикл останавливается.

### Синтаксис:

```bash
until команда_проверки
do
    команды
done
```

Используйте `until`, когда вам удобнее думать в терминах «делай, пока не произойдёт X».

### Отсчёт с шагом 25

Файл `until_count.sh`:

```bash
#!/bin/bash
# Отсчёт от 100 до 0 с шагом 25

count=100

until [ $count -eq 0 ]
do
    echo "Осталось: $count"
    count=$((count - 25))
done

echo "Готово!"
```

![](https://ucarecdn.stepik.net/2b651d6f-23ee-4f8d-8878-2eb857998ef7/)

Цикл остановился, когда `count` стал равен `0` — условие `[ $count -eq 0 ]` стало истинным.

## Бесконечные циклы — как избежать

Бесконечный цикл — это когда условие никогда не становится ложным (для `while`) или истинным (для `until`). Это самая распространённая ошибка при работе с циклами.

### Бесконечный цикл (ошибка)

Файл `infinite_loop.sh`:

```bash
#!/bin/bash
# ОШИБКА: переменная не меняется!

count=5

while [ $count -gt 0 ]
do
    echo "Бесконечный цикл!"
    # Забыли уменьшить count!
done
```

![](https://ucarecdn.stepik.net/b74e5f6e-de69-4f04-b052-725afa8f4ba0/)

Этот скрипт будет выводить `"Бесконечный цикл!"` бесконечно.

### Решение:

Всегда **изменяйте переменную**, используемую в условии, внутри цикла.

## Практическое задание: создайте скрипт «Угадай число»

### Цель:

Написать скрипт `guess_number.sh`, который:

1. Генерирует случайное число от 1 до 10.
2. Запрашивает у пользователя ввод числа.
3. Пока пользователь не угадает число, скрипт сообщает:
    - "Слишком мало" — если введённое число меньше загаданного.
    - "Слишком много" — если введённое число больше загаданного.
4. Когда пользователь угадывает — выводит сообщение о победе и количество попыток.

### Инструкция:

1. Создайте файл `guess_number.sh`.
2. Добавьте shebang `#!/bin/bash`.
3. Сгенерируйте случайное число: `number=$((RANDOM % 10 + 1))`.
4. Используйте `while true` для бесконечного цикла (остановится, когда пользователь угадает).
5. Используйте `read` для получения ввода пользователя.
6. Используйте `[ $guess -lt $number ]` для сравнения.
7. Сохраните, дайте права: `chmod u+x guess_number.sh`.
8. Запустите: `./guess_number.sh`.

### Пример решения:

```bash
#!/bin/bash
# Угадай число

number=$((RANDOM % 10 + 1))
attempts=0

echo "Я загадал число от 1 до 10. Попробуй угадать!"

while true
do
    attempts=$((attempts + 1))
    echo -n "Ваше число: "
    read guess

    if [ $guess -eq $number ]; then
        echo "Поздравляю! Вы угадали число $number за $attempts попыток!"
        break
    elif [ $guess -lt $number ]; then
        echo "Слишком мало. Попробуйте ещё раз."
    else
        echo "Слишком много. Попробуйте ещё раз."
    fi
done
```
