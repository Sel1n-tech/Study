Команда **`git checkout`** позволяет переключаться между ветками, коммитами или файлами, обновляя рабочую директорию в соответствии с выбранным состоянием.

Команда **`git switch`** также предназначена для переключения между ветками в свежих версиях Git, что делает этот процесс более интуитивно понятным и безопасным.

## Новые команды

```bash
# переключиться на существующую ветку
git checkout feature/registration_page

# то же для версий Git, начиная с 2.23
git switch feature/registration_page

# перейти к указанному коммиту
git checkout 2cc4e0b

# вывести историю коммитов в кратком и графическом виде
git log --graph --oneline

# переключиться на предыдущую ветку
git checkout -

# то же для версий Git, начиная с 2.23
git switch -

```

## **Сценарии использования команды 'git checkout'**

- **`git checkout <ветка>`** — для переключения между ветками.
    
- **`git checkout -b`** — для создания новой ветки.
    
- **`git checkout -- <файл>`** — для отмены изменений.
    
- **`git checkout <коммит>`** — для временного просмотра старого кода.
    

**Совет:** В новых версиях Git (2.23+) лучше использовать `git switch` и `git restore` для ясности.

### ⚠️ **Осторожно!**

- `git checkout -- <файл>` **безвозвратно удаляет** локальные изменения.
    
- В режиме **detached HEAD** коммиты могут потеряться, если не создать ветку.
    

Команда `git checkout` — одна из самых мощных в Git, но требует аккуратного использования! 🔧
