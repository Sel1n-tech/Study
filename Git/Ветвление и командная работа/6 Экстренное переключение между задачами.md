Команда **`git stash`** временно сохраняет незакоммиченные изменения в рабочей директории и индексе, позволяя переключиться на другую задачу без коммита.

## **Базовые команды**

| Команда                                                      | Описание                                           |
| ------------------------------------------------------------ | -------------------------------------------------- |
| `git stash`<br><br>`git stash push`                          | Сохранить изменения в stash (без untracked-файлов) |
| `git stash -u`                                               | Сохранить + untracked-файлы                        |
| `git stash -a`                                               | Сохранить всё, включая игнорируемые файлы          |
| `git stash list`                                             | Показать список stash'ей                           |
| `git stash show stash@{0}`<br><br>`git stash show stash@{1}` | Показать изменения в конкретном stash              |
| `git stash pop`                                              | Применить последний stash и удалить его            |
| `git stash apply`                                            | Применить stash без удаления                       |
| `git stash drop stash@{0}`<br><br>`git stash drop stash@{1}` | Удалить конкретный stash                           |
| `git stash clear`                                            | Удалить все stash'и                                |

## **Полезные опции**

|Опция|Описание|
|---|---|
|`-u` или `--include-untracked`|Сохраняет и неотслеживаемые файлы|
|`-a` или `--all`|Сохраняет все файлы, включая игнорируемые|
|`-p` или `--patch`|Интерактивный выбор изменений для stash|

## При переключении на другую ветку

(Что происходит с незакоммиченными изменениями при переключении на другую ветку)

- **Без конфликтов**: изменения переносятся в новую ветку
    
- **С конфликтами**: Git требует явного решения (stash/commit/reset)
    
- **Untracked-файлы**: всегда остаются нетронутыми
    

## **`git stash` под капотом?**

- Stash сохраняет изменения в **отдельном хранилище** (не в коммитах!)
    
- Данные хранятся в `.git/refs/stash`
    

## **Важные нюансы**

1. **Stash не работает с новыми (untracked) файлами** по умолчанию (используйте `-u`)
    
2. **Изменения можно потерять**, если не восстановить stash перед удалением
    
3. Можно создавать **неограниченное количество** stash'ей
    
4. **Не рекомендуется** долго хранить stash — это не замена коммитам!
    

### **Когда использовать git stash?**

✅ Временное сохранение "рабочего беспорядка"  
✅ Срочное переключение контекста  
✅ Тестирование чужих изменений без коммита
