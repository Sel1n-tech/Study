## Введение

Вы уже умеете создавать скрипты и использовать переменные. Но часто бывает нужно не просто выводить результат команды на экран, а сохранять его в файл, или, наоборот, читать данные из файла для обработки. Также полезно уметь передавать результат одной команды прямо на вход другой — это называется **конвейер** (pipe).

Этот урок научит вас:

- Сохранять вывод команд в файлы.
- Добавлять новые данные в существующие файлы.
- Читать данные из файлов и строк для обработки.
- Объединять команды в цепочки с помощью `|`.

## Перенаправление вывода (Output Redirection)

### Зачем это нужно?

По умолчанию, когда вы запускаете команду (например, `ls` или `date`), её результат выводится на экран (в терминал). Иногда вам нужно сохранить этот результат в файле — например, для анализа, логирования или последующего использования.

### Основной оператор: `>`

Оператор `>` перенаправляет вывод команды в файл. Если файла нет — он создаётся. Если файл существует — его содержимое **перезаписывается**.

**Пример:**

```bash
date > current_time.txt
cat current_time.txt
```

![](https://ucarecdn.stepik.net/8e7c5e06-a391-41b1-83f7-3eba882c03ad/)

Используйте `>` для создания нового файла или полной перезаписи существующего.

### Оператор добавления: `>>`

Если вы хотите **добавить** новый вывод в конец файла, а не стирать старый, используйте `>>`.

**Пример:**

```bash
echo "Начало работы" >> log.txt
date >> log.txt
echo "Завершение работы" >> log.txt
cat log.txt
```

![](https://ucarecdn.stepik.net/8bf941d6-b524-4de0-9f95-0c686997c2fc/)

**Идеальный вариант для логов!** Каждый раз, когда вы запускаете скрипт, новая запись будет добавляться в конец файла.

## Перенаправление ввода (Input Redirection)

### Что это такое?

Это обратный процесс: вместо того чтобы команда выводила что-то на экран, она **читает данные из файла**.

### Основной оператор: `<`

Оператор `<` указывает команде, что нужно считывать данные из файла, а не с клавиатуры.

**Пример:**

Допустим, у нас есть файл `text.txt`:

```no-highlight
Привет!
Как дела?
Хорошо, спасибо!
```

![](https://ucarecdn.stepik.net/beafa1ba-8569-47be-b188-d2633900e1b0/)

Теперь мы можем подсчитать строки, слова и символы в этом файле с помощью команды `wc`:

```bash
wc < text.txt
```

![](https://ucarecdn.stepik.net/4f34ac97-89b0-43c8-9696-0ab43c472cd7/)

`wc` по умолчанию выводит три числа:

- количество строк,
- количество слов,
- количество символов (**байт!**).

Это очень удобно, когда нужно быстро проанализировать содержимое файла без открытия его в редакторе.

## Встроенный ввод (Here Document) — `<<`

Иногда вам нужно передать несколько строк текста в команду, но вы не хотите создавать временный файл. Для этого используется конструкция **here document** (`<<`).

### Синтаксис:

```no-highlight
команда << МАРКЕР
текст
...
МАРКЕР
```

**Пример:**

```bash
wc << EOF
Привет, мир!
Как ты сегодня?
Всё отлично!
EOF
```

![](https://ucarecdn.stepik.net/30d898d6-e317-4762-9d30-8df2324e079b/)

Маркер (здесь `EOF`) может быть любым словом, главное — он должен быть одинаковым в начале и в конце. Часто используют `EOF`, `END`, `STOP`.

Эта конструкция полезна для тестирования, автоматизации ввода данных или создания временных блоков текста в скриптах.

## Конвейеры (Pipes) — `|`

### Что это такое?

Конвейер позволяет передавать **вывод одной команды на вход другой команды**. Это мощный инструмент для фильтрации и обработки данных «на лету».

### Оператор: `|`

Символ `|` (pipe) соединяет две команды: вывод первой команды становится вводом для второй.

**Пример:**

```bash
ls -l | grep ".txt"
```

![](https://ucarecdn.stepik.net/0078a8e4-9072-46f8-8daa-61abfd50cddc/)

`ls -l` выводит список файлов.

`grep ".txt"` фильтрует строки, содержащие `.txt`.

### Пример с `more` или `less`

Если вывод команды слишком длинный, чтобы поместиться на экране, можно передать его в `more` или `less` для постраничного просмотра.

```dos
rpm -qa | sort | more
```

![](https://ucarecdn.stepik.net/0608a1b5-6c7c-4b41-8a2a-52cc46af87c0/)

Используйте `less` вместо `more` — он более функциональный (можно прокручивать вверх/вниз, искать по тексту).

## Комбинирование перенаправления и конвейеров

Вы можете комбинировать все эти техники!

### Пример 1: сохранить отсортированный список пакетов в файл

```bash
rpm -qa | sort > package_list.txt
```

```bash
cat package_list.txt
```

![](https://ucarecdn.stepik.net/4432fd43-3649-4789-8019-b020145ca0c0/)

### Пример 2: посмотреть только первые 10 строк отсортированного списка

```bash
rpm -qa | sort | head -n 10
```

![](https://ucarecdn.stepik.net/9daa8abe-305a-40d7-969f-0e9f9d3f5199/)

`head -n 10` выводит первые 10 строк.

## Практическое задание: создайте свой скрипт с перенаправлением и конвейерами

### Цель:

Написать скрипт `system_report.sh`, который:

1. Сохраняет текущую дату и время в файл `report.txt`.
2. Добавляет в этот же файл список всех установленных пакетов (команда `rpm -qa`).
3. Отсортирует список пакетов и сохранит его в файл `sorted_packages.txt`.
4. Выведет на экран первые 5 строк отсортированного списка.

### Инструкция:

1. Создайте файл `system_report.sh`.
2. Добавьте shebang `#!/bin/bash`.
3. Напишите код, используя `>`, `>>`, `|`, `sort`, `head`.
4. Сохраните, дайте права: `chmod u+x system_report.sh`.
5. Запустите: `./system_report.sh`.

### Пример решения:

```bash
#!/bin/bash
# Генерация отчёта о системе

echo "Отчёт создан:" > report.txt
date >> report.txt
echo "" >> report.txt
echo "Список установленных пакетов:" >> report.txt
rpm -qa >> report.txt

# Сортируем и сохраняем в отдельный файл
rpm -qa | sort > sorted_packages.txt

# Выводим первые 5 строк
echo ""
echo "Первые 5 пакетов (отсортированные):"
head -n 5 sorted_packages.txt
```

## Заключение

Вы узнали, как:

- Сохранять вывод команд в файлы с помощью `>` и `>>`.
- Читать данные из файлов с помощью `<`.
- Передавать многострочный текст с помощью `<<`.
- Объединять команды в цепочки с помощью `|`.
- Комбинировать все эти техники для создания мощных и гибких скриптов.

Эти навыки — основа профессионального администрирования и автоматизации задач в Linux.
