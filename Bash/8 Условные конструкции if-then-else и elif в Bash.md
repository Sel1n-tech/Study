## Введение

Вы уже умеете использовать простой оператор `if-then`, который выполняет команды только при успешном завершении условия. Но в реальной жизни часто нужно сделать что-то **альтернативное**, если условие не выполнилось. Для этого в Bash есть блок `else`.

А если нужно проверить несколько условий подряд? Тогда на помощь приходит `elif` — сокращение от «else if». Это позволяет создавать сложную логику без запутанного вложения `if` в `if`.

Этот урок поможет вам:

- Использовать `else` для обработки "иначе".
- Применять `elif` для последовательной проверки нескольких условий.
- Избегать распространённых ошибок при написании сложных условий.

## Вложенные `if` — можно, но не нужно

Иногда кажется, что для проверки нескольких условий нужно вкладывать один `if` в другой. Например, проверить, существует ли пользователь, а если нет — проверить, есть ли его домашняя директория.

### Вложенный `if`

Файл `nested_if.sh`:

```bash
#!/bin/bash
testuser="NoSuchUser"

if grep "$testuser" /etc/passwd
then
    echo "Пользователь $testuser существует."
else
    if [ -d "/home/$testuser" ]
    then
        echo "Пользователь $testuser удалён, но его директория /home/$testuser осталась."
    else
        echo "Пользователь $testuser не существует, и его директории тоже нет."
    fi
fi
```

## Конструкция `elif` — чистая и простая альтернатива

Вместо вложенных `if` используйте `elif`. Это позволяет проверять несколько условий **последовательно**, и выполнится только **первое** из них, которое окажется истинным.

### Синтаксис:

```bash
if команда1
then
    команды_для_команды1
elif команда2
then
    команды_для_команды2
elif команда3
then
    команды_для_команды3
else
    команды_если_ничего_не_подошло
fi
```

### Улучшенная проверка пользователя с `elif`

Файл `check_user_elif.sh`:

```bash
#!/bin/bash
testuser="NoSuchUser"

if grep "$testuser" /etc/passwd
then
    echo "Пользователь $testuser существует."
elif [ -d "/home/$testuser" ]
then
    echo "Пользователь $testuser удалён, но его директория /home/$testuser осталась."
else
    echo "Пользователь $testuser не существует, и его директории тоже нет."
fi
```

- Легко добавить новые условия — просто добавьте ещё один `elif`.

## Советы и распространённые ошибки

### Порядок важен!

Bash проверяет условия по порядку. Как только одно из них даёт `0` (истина), остальные игнорируются.

**Пример:**

```bash
if [ 5 -eq 5 ]; then
    echo "Первое условие истинно"
elif [ 3 -gt 2 ]; then
    echo "Это никогда не выведется"
fi
```

Вывод: `"Первое условие истинно"` — второе условие даже не проверяется.

Располагайте наиболее вероятные или важные условия в начале.

### Не забывайте `fi`

Блок `if`, `elif`, `else` должен заканчиваться `fi`. Нарушение синтаксиса приведёт к ошибке.

### Используйте `[ ]` для сравнения

Для числовых и строковых сравнений используйте встроенную команду `[ ]` (или `[[ ]]`).

**Правильно:**

```bash
if [ $count -gt 10 ]; then
    echo "Больше 10"
fi
```

**Неправильно:**

```bash
if $count > 10; then  # так не работает!
```

## Практическое задание: создайте скрипт «Проверка файла»

### Цель:

Написать скрипт `file_status.sh`, который:

1. Принимает имя файла как аргумент (`$1`).
2. Проверяет:
    - Если файл существует и является обычным файлом — выводит его размер.
    - Если файл существует, но это каталог — выводит сообщение "Это каталог".
    - Если файла нет — создаёт его и пишет туда "Файл создан автоматически".
3. Всегда выводит сообщение о результате.

### Инструкция:

1. Создайте файл `file_status.sh`.
2. Добавьте shebang `#!/bin/bash`.
3. Проверьте количество аргументов: `if [ $# -ne 1 ]; then ... exit 1; fi`.
4. Используйте `[ -f "$1" ]` для проверки обычного файла.
5. Используйте `[ -d "$1" ]` для проверки каталога.
6. Используйте `touch` и `echo` для создания файла.
7. Сохраните, дайте права: `chmod u+x file_status.sh`.
8. Запустите с разными аргументами: `./file_status.sh myfile.txt`, `./file_status.sh /tmp`, `./file_status.sh nonexist.txt`.

### Пример решения:

```bash
#!/bin/bash
# Проверка статуса файла

if [ $# -ne 1 ]; then
    echo "Использование: $0 <имя_файла>"
    exit 1
fi

filename="$1"

if [ -f "$filename" ]; then
    echo "Файл '$filename' существует."
    echo "Размер файла: $(ls -l "$filename" | awk '{print $5}') байт"
elif [ -d "$filename" ]; then
    echo "'$filename' — это каталог."
else
    echo "Файл '$filename' не найден. Создаём новый файл..."
    touch "$filename"
    echo "Файл создан автоматически." >> "$filename"
    echo "Файл '$filename' успешно создан."
fi
```
