## Введение

Вы уже умеете передавать параметры в скрипт и проверять их наличие. Но что, если нужно обработать **множество параметров** или **опции командной строки** (например, `-a`, `-b`, `-c`)?

Для этого в Bash есть мощные инструменты:

- **Команда `shift`** — позволяет "сдвигать" параметры, чтобы работать с ними по одному.
- **Опции командной строки** — одиночные буквы, начинающиеся с дефиса (`-`), которые изменяют поведение команды.

Этот урок поможет вам:

- Понять, как работает команда `shift`.
- Использовать `shift` для обработки множества параметров.
- Обрабатывать опции командной строки с помощью `case`.
- Разделять опции от параметров с помощью двойного дефиса (`--`).

## Команда `shift`

### Что это такое?

Команда `shift` перемещает все параметры командной строки **на одну позицию влево**. Значение `$1` теряется, значение `$2` становится `$1`, `$3` становится `$2` и т.д.

Это полезно, когда вы хотите обработать параметры по одному, не зная их общего количества.

### Обработка всех параметров с помощью `shift`

Файл `process_all.sh`:

```bash
#!/bin/bash
# Обрабатываем все параметры по очереди

count=1
while [ -n "$1" ]; do
    echo "Параметр #$count: $1"
    count=$((count + 1))
    shift  # Сдвигаем параметры
done

echo "Все параметры обработаны."
```

![](https://ucarecdn.stepik.net/db0cc2bc-00f7-4182-8688-fbb18f030740/)

Цикл продолжается, пока `$1` не станет пустым (нет параметров). Команда `shift` убирает текущий параметр и переходит к следующему.

## Множественный сдвиг

Иногда нужно пропустить несколько параметров сразу — для этого можно указать число после `shift`.

### Пропуск первых двух параметров

Файл `skip_params.sh`:

```bash
#!/bin/bash
# Пропускаем первые два параметра

echo "Исходные параметры: $@"
shift 2  # Пропускаем первые два
echo "Оставшиеся параметры: $@"
```

![](https://ucarecdn.stepik.net/4b2bf946-9afd-4d01-b6ec-bcd5419cd127/)

Команда `shift 2` удаляет первые два параметра, и `$1` теперь содержит третий параметр.

## Работа с опциями командной строки

Опции — это параметры, начинающиеся с дефиса (`-`). Например, `-a`, `-b`, `-c`. Они часто используются для изменения поведения команды.

### Обработка опций с помощью `case`

Файл `handle_options.sh`:

```bash
#!/bin/bash
# Обрабатываем опции командной строки

while [ -n "$1" ]; do
    case "$1" in
        -a)
            echo "Найдена опция -a"
            ;;
        -b)
            echo "Найдена опция -b"
            ;;
        -c)
            echo "Найдена опция -c"
            ;;
        *)
            echo "Неизвестная опция: $1"
            ;;
    esac
    shift
done
```

![](https://ucarecdn.stepik.net/46c42810-4987-462b-9b06-0d2755ceb8ce/)

Оператор `case` позволяет легко обрабатывать различные опции. Каждая опция соответствует своему шаблону.

## Разделение опций от параметров

Если в командной строке есть и опции, и параметры, нужно отделить их друг от друга. Для этого используется **двойной дефис** (`--`).

### Разделение опций и параметров

Файл `separate_options.sh`:

```bash
#!/bin/bash
# Разделяем опции от параметров

while [ -n "$1" ]; do
    case "$1" in
        -a)
            echo "Найдена опция -a"
            ;;
        -b)
            echo "Найдена опция -b"
            ;;
        -c)
            echo "Найдена опция -c"
            ;;
        --)
            shift  # Убираем --
            break  # Выходим из цикла
            ;;
        *)
            echo "Неизвестная опция: $1"
            ;;
    esac
    shift
done

echo ""
echo "Обработка параметров:"
count=1
for param in "$@"
do
    echo "Параметр #$count: $param"
    ((count++))
done
```

![](https://ucarecdn.stepik.net/b6c0fd36-f0ea-4531-8ebb-ca2e8be10ddd/)

Двойной дефис (`--`) означает конец опций. После него все параметры обрабатываются как обычные аргументы.

## Обработка опций с значениями

Некоторые опции требуют дополнительного параметра — например, `-o filename` или `-n 5`.

### Обработка опции с значением

Файл `option_with_value.sh`:

```bash
#!/bin/bash
# Обрабатываем опции с значениями

while [ -n "$1" ]; do
    case "$1" in
        -a)
            echo "Найдена опция -a"
            ;;
        -b)
            value="$2"  # Получаем следующий параметр
            echo "Найдена опция -b со значением: $value"
            shift  # Убираем значение
            ;;
        -c)
            echo "Найдена опция -c"
            ;;
        --)
            shift
            break
            ;;
        *)
            echo "Неизвестная опция: $1"
            ;;
    esac
    shift
done

echo ""
echo "Обработка параметров:"
count=1
for param in "$@"
do
    echo "Параметр #$count: $param"
    ((count++))
done
```

![](https://ucarecdn.stepik.net/08cdb2b9-be29-4e68-acb0-e26c32efdef6/)

При обработке опции с значением мы используем `$2` для получения значения, а затем выполняем `shift` дважды — один раз для опции, второй раз для значения.

## Практическое задание: создайте скрипт «Анализ командной строки»

### Цель:

Написать скрипт `analyze_cli.sh`, который:

1. Принимает опции и параметры.
2. Обрабатывает опции:
    - `-h` — выводит справку.
    - `-v` — включает подробный вывод.
    - `-o <file>` — указывает файл для вывода.
3. После опций обрабатывает оставшиеся параметры как имена файлов.
4. Выводит список файлов и опции.

### Инструкция:

1. Создайте файл `analyze_cli.sh`.
2. Добавьте shebang `#!/bin/bash`.
3. Используйте `while [ -n "$1" ]` для перебора параметров.
4. Используйте `case` для обработки опций.
5. Используйте `shift` для сдвига параметров.
6. Сохраните, дайте права: `chmod u+x analyze_cli.sh`.
7. Запустите: `./analyze_cli.sh -v -o log.txt file1.txt file2.txt`.

### Пример решения:

```bash
#!/bin/bash
# Анализ командной строки

verbose=false
output_file=""

while [ -n "$1" ]; do
    case "$1" in
        -h)
            echo "Использование: $0 [-h] [-v] [-o <файл>] <файлы>"
            echo "  -h    Показать эту справку"
            echo "  -v    Включить подробный вывод"
            echo "  -o    Указать файл для вывода"
            exit 0
            ;;
        -v)
            verbose=true
            echo "Подробный вывод включён."
            ;;
        -o)
            output_file="$2"
            echo "Файл вывода: $output_file"
            shift  # Убираем значение
            ;;
        --)
            shift
            break
            ;;
        *)
            echo "Неизвестная опция: $1"
            ;;
    esac
    shift
done

echo ""
echo "=== Список файлов ==="
count=1
for file in "$@"
do
    echo "Файл #$count: $file"
    ((count++))
done

if [ "$verbose" = true ]; then
    echo ""
    echo "Подробная информация:"
    for file in "$@"
    do
        if [ -f "$file" ]; then
            echo "  $file существует. Размер: $(ls -l "$file" | awk '{print $5}') байт"
        else
            echo "  $file не существует."
        fi
    done
fi
```
