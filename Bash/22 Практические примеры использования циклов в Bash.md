Эти задачи часто встречаются в реальной работе системного администратора или DevOps-инженера. Они помогут вам закрепить навыки работы с циклами, условными операторами и перенаправлением ввода/вывода.

## Поиск исполняемых файлов

### Зачем это нужно?

Когда вы запускаете программу в терминале (например, `ls`), система ищет её в директориях, указанных в переменной `PATH`. Иногда полезно узнать, какие именно исполняемые файлы доступны в этих директориях — например, для аудита или создания списка программ.

### Итерация по директориям в `PATH`

Переменная `PATH` содержит список директорий, разделённых двоеточием (`:`). Чтобы перебрать их в цикле `for`, нужно изменить разделитель полей `IFS`.

Файл `find_executables.sh`:

```bash
#!/bin/bash
# Поиск исполняемых файлов в PATH

# Сохраняем старое значение IFS
IFS_OLD="$IFS"
# Устанавливаем IFS на двоеточие
IFS=":"

echo "Исполняемые файлы в PATH:"

# Перебираем каждую директорию в PATH
for folder in $PATH
do
    echo "$folder:"
    # Перебираем все файлы в директории
    for file in "$folder"/*
    do
        # Проверяем, что файл существует и доступен для выполнения
        if [ -f "$file" ] && [ -x "$file" ]; then
            echo "  $file"
        fi
    done
done

# Восстанавливаем IFS
IFS="$IFS_OLD"
```

## Создание пользовательских аккаунтов

### Зачем это нужно?

Если вы работаете с большим количеством пользователей, создавать их вручную через `useradd` очень утомительно. Гораздо удобнее подготовить файл с данными и автоматизировать процесс.

### Формат данных

Данные о пользователях хранятся в файле `users.csv` в формате:

```bash
userid,full name
homer,Homer Simpson
bart,Bart Simpson
```

### Чтение данных из файла

Чтобы прочитать файл построчно и разобрать каждую строку на части, используем `while read` и установим `IFS=','`.

Файл `create_users.sh`:

```bash
#!/bin/bash
# Создание пользователей из файла users.csv

# Проверяем, что файл существует
if [ ! -f "users.csv" ]; then
    echo "Файл users.csv не найден."
    exit 1
fi

# Сохраняем старое значение IFS
IFS_OLD="$IFS"
# Устанавливаем IFS на запятую
IFS=","

echo "Создание пользователей..."

# Читаем файл построчно
while read userid name
do
    echo "Добавляем пользователя: $userid ($name)"
    # Команда useradd требует прав root — поэтому скрипт нужно запускать от root
    # Для тестирования можно заменить useradd на echo
    # useradd -c "$name" -m -s /bin/bash "$userid"
    echo "Пользователь $userid создан (симуляция)."
done < "users.csv"

# Восстанавливаем IFS
IFS="$IFS_OLD"

echo "Все пользователи созданы."
```
