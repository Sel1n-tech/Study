## Введение

Вы уже умеете использовать простые условия с `if-then`, а также проверять файлы, строки и числа. Но часто нужно проверить **несколько условий одновременно** или использовать **логические операторы** (И, ИЛИ). Также полезно знать, как работать с **сложными математическими выражениями** и **шаблонами строк**.

Этот урок поможет вам:

- Использовать логические операторы `&&` и `||` для объединения условий.
- Применять двойные скобки `(( ))` для сложных математических операций.
- Использовать двойные квадратные скобки `[[ ]]` для расширенных сравнений строк.
- Заменить длинную цепочку `if-elif` на конструкцию `case`.

## Логические операторы — `&&` и `||`

### Зачем они нужны?

Часто нужно проверить два или более условий одновременно. Например, "если файл существует **и** доступен для записи". Для этого используются логические операторы:

- `&&` — **И** (AND). Оба условия должны быть истинны.
- `||` — **ИЛИ** (OR). Достаточно, чтобы одно из условий было истинным.

### Синтаксис:

```bash
if [ условие1 ] && [ условие2 ]; then
    команды_если_оба_истинны
fi

if [ условие1 ] || [ условие2 ]; then
    команды_если_хотя_бы_одно_истинно
fi
```

Операторы `&&` и `||` можно использовать не только в `if`, но и в обычной командной строке.

Например: `mkdir dir && cd dir`.

### Проверка файла и прав на запись

Файл `check_file_write.sh`:

```bash
#!/bin/bash
# Проверяем, существует ли файл и доступен ли для записи

filename="$HOME/testing.txt"

if [ -f "$filename" ] && [ -w "$filename" ]; then
    echo "Файл $filename существует и доступен для записи."
    echo "Текущее время: $(date)" >> "$filename"
else
    echo "Файл $filename не существует или недоступен для записи."
fi
```

Скрипт проверяет сразу два условия.

## Двойные скобки `(( ))` — для сложных математических выражений

### Что это такое?

Двойные скобки `(( ))` позволяют выполнять сложные математические операции без необходимости экранирования символов (`*`, `<`, `>`).

### Преимущества:

- Не нужно экранировать символы (`*`, `/`, `%`).
- Поддерживает инкремент (`++`), декремент (`--`), возведение в степень (`**`).
- Работает с целыми числами (как и `$[ ]`).

### Синтаксис:

```bash
if (( выражение )); then
    команды_если_истина
fi
```

### Проверка квадрата числа

Файл `check_square.sh`:

```bash
#!/bin/bash
# Проверяем, что квадрат числа больше 90

val=10

if (( val ** 2 > 90 )); then
    square=$(( val ** 2 ))
    echo "Квадрат числа $val равен $square и больше 90."
else
    echo "Квадрат числа $val не больше 90."
fi
```

![](https://ucarecdn.stepik.net/c7a9a6c4-8803-433f-ad62-025b4ed652c9/)

Обратите внимание: символ `>` не нужно экранировать внутри `(( ))`.

## Двойные квадратные скобки `[[ ]]` — для расширенных сравнений строк

### Что это такое?

Двойные квадратные скобки `[[ ]]` — это расширение `[ ]`, которое позволяет использовать **регулярные выражения** и другие удобные функции.

### Преимущества:

- Поддерживает шаблоны строк (`==`, `!=`, `=~`).
- Не требует экранирования некоторых символов.
- Более надёжный и читаемый синтаксис.

`[[ ]]` работает только в Bash, а не в старых оболочках (например, `sh`). Поэтому всегда используйте shebang `#!/bin/bash`.

### Проверка имени пользователя с помощью шаблона

Файл `check_user_pattern.sh`:

```bash
#!/bin/bash
# Проверяем, начинается ли имя пользователя с 'r'

if [[ "$USER" == r* ]]; then
    echo "Привет, $USER! Твоё имя начинается с 'r'."
else
    echo "Привет, $USER! Твоё имя не начинается с 'r'."
fi
```

Шаблон `r*` означает "начинается с буквы 'r' и далее любые символы".

## Конструкция `case` — альтернатива длинным `if-elif`

### Зачем она нужна?

Если вам нужно проверить одну переменную на множество возможных значений, писать длинную цепочку `if-elif` неудобно. Конструкция `case` делает это проще и нагляднее.

### Синтаксис:

```bash
case переменная in
    шаблон1)
        команды1
        ;;
    шаблон2)
        команды2
        ;;
    *)
        команды_по_умолчанию
        ;;
esac
```

Используйте `*)` как "всё остальное" — это аналог `else` в `if`.

### Приветствие в зависимости от имени

Файл `greet_user.sh`:

```bash
#!/bin/bash
# Приветствие в зависимости от имени пользователя

case "$USER" in
    root | sviatoslav)
        echo "Привет, $USER! Приятного дня!"
        ;;
    testing)
        echo "Привет, $USER! Это тестовый аккаунт."
        ;;
    simpleuser)
        echo "Привет, $USER! Не забудь выйти из системы."
        ;;
    *)
        echo "Привет, $USER! Добро пожаловать."
        ;;
esac
```

## Практическое задание: создайте скрипт «Умный калькулятор»

### Цель:

Написать скрипт `smart_calc.sh`, который:

1. Принимает два числа и операцию (`+`, `-`, `*`, `/`) как аргументы.
2. Проверяет, что аргументов три.
3. Использует `case` для выбора операции.
4. Выполняет операцию с помощью `(( ))`.
5. Выводит результат.

### Инструкция:

1. Создайте файл `smart_calc.sh`.
2. Добавьте shebang `#!/bin/bash`.
3. Проверьте количество аргументов: `if [ $# -ne 3 ]; then ... exit 1; fi`.
4. Используйте `case` для выбора операции.
5. Используйте `(( ))` для выполнения операции.
6. Сохраните, дайте права: `chmod u+x smart_calc.sh`.
7. Запустите: `./smart_calc.sh 10 + 5`, `./smart_calc.sh 10 * 3`.

### Пример решения:

```bash
#!/bin/bash
# Умный калькулятор

if [ $# -ne 3 ]; then
    echo "Использование: $0 <число1> <операция> <число2>"
    echo "Операции: +, -, *, /"
    exit 1
fi

num1=$1
op=$2
num2=$3

case "$op" in
    "+")
        result=$(( num1 + num2 ))
        echo "$num1 + $num2 = $result"
        ;;
    "-")
        result=$(( num1 - num2 ))
        echo "$num1 - $num2 = $result"
        ;;
    "*")
        result=$(( num1 * num2 ))
        echo "$num1 * $num2 = $result"
        ;;
    "/")
        if [ $num2 -eq 0 ]; then
            echo "Деление на ноль невозможно!"
            exit 1
        fi
        result=$(( num1 / num2 ))
        echo "$num1 / $num2 = $result"
        ;;
    *)
        echo "Неизвестная операция: $op"
        echo "Поддерживаемые операции: +, -, *, /"
        exit 1
        ;;
esac
```
