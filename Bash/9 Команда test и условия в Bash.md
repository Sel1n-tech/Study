## Введение

Вы уже умеете использовать оператор `if-then`, который проверяет успешность выполнения команды. Но что, если вам нужно проверить не результат команды, а **само значение переменной**, или **сравнить два числа**, или **проверить, существует ли файл**? Для этого в Bash есть специальная команда — `test`.

Этот урок поможет вам:

- Понять, как работает команда `test`.
- Использовать `test` с числовыми, строковыми и файловыми сравнениями.
- Применять альтернативный синтаксис `[ ]`.
- Избегать распространённых ошибок (например, при работе с дробными числами).

## Что такое команда `test`?

### Зачем она нужна?

В Bash оператор `if` ожидает команду, которая вернёт код завершения `0` (истина) или ненулевой (ложь). Команда `test` как раз и предназначена для **проверки различных условий** и возврата соответствующего кода.

### Базовый синтаксис:

```bash
test условие
```

Если условие истинно → `test` возвращает `0`.  
Если условие ложно → `test` возвращает `1`.

### Как использовать в `if`:

```bash
if test условие
then
    команды_если_истина
else
    команды_если_ложь
fi
```

Команду `test` можно заменить на квадратные скобки `[ ]` — это одно и то же!

## Альтернативный синтаксис — `[ ]`

Вместо `test` часто используется `[ ]`. 

### Синтаксис:

```bash
if [ условие ]
then
    команды
fi
```

**Важное правило:** между `[` и условием, а также между условием и `]` **обязательны пробелы**! Без них будет ошибка.

**Правильно:**

```bash
if [ $count -gt 5 ]; then
    echo "Больше 5"
fi
```

**Неправильно:**

```bash
if [$count -gt 5]; then   # ❌ Ошибка: нет пробела после [
```

## Три класса условий

Команда `test` (или `[ ]`) может проверять три типа условий:

1. **Числовые сравнения** (`-eq`, `-gt`, `-lt` и т.д.)
2. **Строковые сравнения** (`=`, `!=`, `-z`, `-n`)
3. **Файловые сравнения** (`-f`, `-d`, `-r`, `-w`)

## Числовые сравнения

### Операторы

|Оператор|Описание|
|---|---|
|`-eq`|равно|
|`-ne`|не равно|
|`-gt`|больше|
|`-ge`|больше или равно|
|`-lt`|меньше|
|`-le`|меньше или равно|

### Сравнение чисел

Файл `compare_numbers.sh`:

```bash
#!/bin/bash
# Сравнение чисел

num1=10
num2=15

if [ $num1 -gt 5 ]
then
    echo "$num1 больше 5"
fi

if [ $num1 -eq $num2 ]
then
    echo "$num1 равно $num2"
else
    echo "$num1 не равно $num2"
fi
```

Все числа в Bash — целые. Дробные числа не поддерживаются в `test`!

## Строковые сравнения

### Операторы

|Оператор|Описание|
|---|---|
|`=` или `==`|строки равны|
|`!=`|строки не равны|
|`-z`|строка пустая|
|`-n`|строка не пустая|

### Проверка переменной

Файл `check_string.sh`:

```bash
#!/bin/bash
# Проверка строк

name="Варя"
empty=""

if [ -n "$name" ]
then
    echo "Переменная 'name' содержит значение: $name"
fi

if [ -z "$empty" ]
then
    echo "Переменная 'empty' пуста."
fi

if [ "$name" = "Варя" ]
then
    echo "Имя совпадает!"
fi
```

![](https://ucarecdn.stepik.net/3e1303b4-da3c-47a1-b7ba-5ac530818229/)

Всегда оборачивайте переменные в двойные кавычки: `"$var"` — это предотвращает ошибки при пустых значениях или значениях с пробелами.

## Файловые сравнения

### Операторы

|Оператор|Описание|
|---|---|
|`-e`|файл существует|
|`-f`|файл существует и является обычным файлом|
|`-d`|каталог существует|
|`-r`|файл доступен для чтения|
|`-w`|файл доступен для записи|
|`-x`|файл доступен для выполнения|

### Проверка файла

Файл `check_file.sh`:

```bash
#!/bin/bash
# Проверка файла

filename="data.txt"

if [ -f "$filename" ]
then
    echo "Файл '$filename' существует и является обычным файлом."
elif [ -d "$filename" ]
then
    echo "'$filename' — это каталог."
else
    echo "Файл '$filename' не найден."
fi
```

## Распространённые ошибки и советы

### Забыли пробелы в `[ ]`

**Ошибка:**

```bash
if [$count -gt 5]; then
```

**Решение:**

```bash
if [ $count -gt 5 ]; then
```

### Используете дробные числа

**Ошибка:**

```bash
value=5.5
if [ $value -gt 5 ]; then  # ❌ Ошибка: 5.5 не целое число
```

**Решение:** используйте `bc` для дробных чисел, а для сравнения — преобразуйте в целое или используйте строковое сравнение.

### Не оборачиваете переменные в кавычки

**Ошибка:**

```bash
name="Джонни Пирожок"
if [ $name = "Джонни" ]; then  # ❌ Если name="Джонни Пирожок", это сломается
```

**Решение:**

```bash
if [ "$name" = "Джонни" ]; then
```

## Практическое задание: создайте скрипт «Проверка возраста»

### Цель:

Написать скрипт `age_check.sh`, который:

1. Принимает возраст пользователя как аргумент (`$1`).
2. Проверяет:
    - Если возраст меньше 18 — выводит "Доступ запрещён".
    - Если возраст от 18 до 65 — выводит "Доступ разрешён".
    - Если возраст больше 65 — выводит "Доступ разрешён (пенсионер)".
3. Если аргумент не передан — выводит сообщение об ошибке.

### Инструкция:

1. Создайте файл `age_check.sh`.
2. Добавьте shebang `#!/bin/bash`.
3. Проверьте количество аргументов: `if [ $# -ne 1 ]; then ... exit 1; fi`.
4. Используйте `[ $age -lt 18 ]`, `[ $age -ge 18 ]` и `[ $age -gt 65 ]` для проверки.
5. Сохраните, дайте права: `chmod u+x age_check.sh`.
6. Запустите с разными аргументами: `./age_check.sh 17`, `./age_check.sh 25`, `./age_check.sh 70`.

### Пример решения:

```bash
#!/bin/bash
# Проверка возраста

if [ $# -ne 1 ]; then
    echo "Использование: $0 <возраст>"
    exit 1
fi

age=$1

if [ $age -lt 18 ]; then
    echo "Доступ запрещён. Вам меньше 18 лет."
elif [ $age -gt 65 ]; then
    echo "Доступ разрешён (пенсионер)."
else
    echo "Доступ разрешён."
fi
```
