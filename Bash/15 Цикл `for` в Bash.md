# Цикл `for` в Bash

## Введение

Вы уже умеете создавать скрипты, которые выполняют команды последовательно или принимают решения с помощью `if-then`. Но часто нужно **повторить набор команд несколько раз** — например, обработать все файлы в директории, пройтись по списку пользователей или вывести несколько строк текста. Для этого в Bash используется цикл `for`.

Этот урок поможет вам:

- Понять, как работает цикл `for`.
- Использовать его с простыми и сложными значениями.
- Избежать распространённых ошибок при работе со строками и пробелами.
- Применять цикл `for` в реальных задачах.

## Базовый синтаксис `for`

### Как это работает?

Цикл `for` позволяет выполнить набор команд **для каждого элемента из списка**. На каждой итерации переменная цикла принимает значение следующего элемента списка.

### Синтаксис:

```bash
for переменная in список
do
    команды
done
```

Переменная `переменная` может называться как угодно (например, `i`, `file`, `state`). Она будет содержать текущее значение из списка на каждой итерации.

### Простой цикл

Файл `states.sh`:

```bash
#!/bin/bash
# Выводим список состояний

for state in InProgress Paused Stoped SomethingElse Done Gone
do
    echo "Следующее состояние: $state"
done
```

![](https://ucarecdn.stepik.net/ee1ca27a-e748-46d0-a94d-6395341f3516/)

Каждая строка выводится отдельно, так как переменная `$state` меняется на каждом шаге цикла.

## Работа со сложными значениями

### Одинарные кавычки и пробелы

Если в списке есть значения с пробелами или одинарными кавычками, цикл `for` может работать неправильно, потому что Bash интерпретирует пробелы как разделители.

**Ошибка:**

```bash
for test in I don't know if "this'll" work
do
    echo "word:$test"
done
```

Выводит: `word:I`, `word:don't`, `word:know`, `word:if`, `word:this'll`, `word:work`

Почему? Bash разделил строку по пробелам, не считая кавычки.

На практике может быть ещё хуже:

![](https://ucarecdn.stepik.net/8c09515c-8d68-4e6d-9e32-3b24de3e4f14/)

### Экранирование с помощью `\`

Один из вариантов решения данной проблемы:

```bash
for test in I don\'t know if "this'll" work
do
    echo "word:$test"
done
```

![](https://ucarecdn.stepik.net/e504c179-9099-4c42-b7be-3dfcfe32ac18/)

### Использование двойных кавычек

Можно и так:

```bash
for test in "I don't know" "if this'll work"
do
    echo "phrase: $test"
done
```

Теперь каждая фраза в двойных кавычках считается одним элементом списка.

## Работа с многословными значениями

Если в списке есть значения, содержащие пробелы (например, `"New Omsk"`), их нужно заключать в двойные кавычки.

### Пример 2: Список городов

Файл `cities.sh`:

```bash
#!/bin/bash
# Выводим список городов

for city in Омск "Нижний Новгород" "Великий Устюг" "Вятские Поляны" Верхняя Пышма
do
    echo "Теперь направляемся в $city"
done
```

![](https://ucarecdn.stepik.net/e8c05be9-9a79-437e-af8b-5e0bdd9606c3/)

Последний город "Верхняя Пышма" выведен на экран не совсем корректно, поскольку название не было взято в кавычки.

## Использование переменной для хранения списка

Часто список значений формируется динамически — например, из вывода команды или из файла. В этом случае удобно сохранить список в переменную.

### Список из переменной

Файл `visit.sh`:

```bash
#!/bin/bash
# Задаем список штатов в переменной

list="Омск Новосибирск Красноярск Иркутск Томск"

for city in $list
do
    echo "Вы когда-нибудь посещали $city?"
done
```

![](https://ucarecdn.stepik.net/3cf19253-05b7-4449-aed9-796d7feaa7bf/)

Не используйте кавычки вокруг `$list` в `for city in $list` — иначе весь список будет одним элементом.

## Практическое задание: создайте скрипт «Обработка файлов»

### Цель:

Написать скрипт `process_files.sh`, который:

1. Принимает список имён файлов как аргументы (`$@`).
2. Для каждого файла проверяет:
    - Если файл существует и является обычным файлом — выводит его размер.
    - Если файл не существует — выводит сообщение об ошибке.
3. В конце выводит общее количество обработанных файлов.

### Инструкция:

1. Создайте файл `process_files.sh`.
2. Добавьте shebang `#!/bin/bash`.
3. Используйте `for file in "$@"` для перебора всех аргументов.
4. Используйте `[ -f "$file" ]` для проверки существования файла.
5. Используйте `ls -l "$file" | awk '{print $5}'` для получения размера файла.
6. Сохраните, дайте права: `chmod u+x process_files.sh`.
7. Запустите: `./process_files.sh file1.txt file2.txt nonexist.txt`.

### Пример решения:

```bash
#!/bin/bash
# Обработка списка файлов

count=0

for file in "$@"
do
    count=$((count + 1))
    if [ -f "$file" ]; then
        size=$(ls -l "$file" | awk '{print $5}')
        echo "Файл '$file' существует. Размер: $size байт."
    else
        echo "Файл '$file' не найден."
    fi
done

echo ""
echo "Обработано $count файлов."
```
