### **Folder**

**Folder** в Jenkins — этот тип, который позволяет организовать проекты в виде иерархической структуры. Folder помогает группировать связанные проекты вместе и упрощает управление ими.

### Freestyle project

**Freestyle project** — это тип проекта в Jenkins, который представляет собой свободный стиль сборки и развёртывания. Данный тип проект позволяет настроить процесс сборки, тестирования и развёртывания программного обеспечения. Через веб-интерфейс Jenkins можно создать и настроить Freestyle project.

Основные характеристики **Freestyle projects**:

- Настройка шагов сборки: можно настроить произвольное количество шагов сборки, включая команды оболочки, скрипты и другие задачи.
- Параметризация: можно параметризовать шаги сборки, чтобы сделать их более гибкими и настраиваемыми.
- Триггеры: можно настроить триггеры для запуска сборок при изменении кода или по расписанию.
- Пост-сборка: можно добавить шаги после сборки, такие как тестирование, развёртывание или публикация артефактов.

### Pipeline

**Pipeline** — это тип проекта в Jenkins, который позволяет создавать рабочие процессы сборки, тестирования и развёртывания программного обеспечения. Он использует декларативный или скриптовый подход для определения последовательности задач и их зависимостей.

Основные характеристики проекта Pipeline:

- Позволяет описать рабочий процесс в виде кода(загрузить код в гит репозиторий), что упрощает его понимание и поддержку.
- Повторное использование. Можно повторно использовать код рабочего процесса в разных проектах.
- Гибкость. Поддерживает различные этапы сборки, тестирования и развёртывания.
- Интеграция. Легко интегрируется с другими инструментами и сервисами.
