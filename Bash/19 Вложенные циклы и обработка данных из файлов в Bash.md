## Введение

Вы уже умеете использовать простые циклы `for`, `while` и `until`. Но часто нужно выполнять сложные задачи — например, создать таблицу умножения, обработать каждую строку файла, а затем разобрать её на части. Для этого используются **вложенные циклы** — когда один цикл находится внутри другого.

Также важно уметь читать данные из файлов, особенно если они содержат структурированные данные (например, разделённые двоеточием или запятой).

Этот урок поможет вам:

- Понять, как работают вложенные циклы.
- Избежать распространённых ошибок при их использовании.
- Обрабатывать данные из файлов с помощью `IFS`.
- Создавать скрипты, которые автоматически анализируют структурированные данные.

## Вложенные циклы

### Что это такое?

Вложенный цикл — это цикл, который находится внутри другого цикла. Внешний цикл выполняется один раз, а внутренний — несколько раз для каждой итерации внешнего.

### Таблица умножения

Файл `multiplication_table.sh`:

```bash
#!/bin/bash
# Таблица умножения от 1 до 3

for (( i=1; i<=3; i++ ))
do
    echo "Таблица умножения на $i:"
    for (( j=1; j<=3; j++ ))
    do
        result=$((i * j))
        echo "$i * $j = $result"
    done
    echo ""  # Пустая строка для разделения
done
```

Внутренний цикл (`j`) выполняется три раза для каждого значения внешнего цикла (`i`).

## Смешивание циклов

Можно смешивать разные типы циклов — например, `while` внутри `for` или `until` внутри `while`.

### Цикл `for` внутри `while`

Файл `mixed_loops.sh`:

```bash
#!/bin/bash
# Цикл for внутри while

count=5

while [ $count -ge 0 ]
do
    echo "Внешний цикл: $count"
    for (( i=1; i<=2; i++ ))
    do
        echo "  Внутренний цикл: $i"
    done
    count=$((count - 1))
done
```

Каждый цикл имеет свои собственные переменные и условия — они не пересекаются.

## Обработка данных из файлов

Часто нужно обработать данные, хранящиеся в файлах. Например, файл `/etc/passwd` содержит информацию о пользователях, разделённую двоеточием.

Для этого используется переменная `IFS` (Internal Field Separator) — она определяет, какие символы используются для разделения полей.

### Разбор строки из `/etc/passwd`

Файл `parse_passwd.sh`:

```bash
#!/bin/bash
# Разбираем строки из /etc/passwd

# Сохраняем старое значение IFS
IFS_OLD="$IFS"

# Устанавливаем IFS на двоеточие
IFS=":"

# Читаем файл построчно
while read username password uid gid name home shell
do
    echo "Имя пользователя: $username"
    echo "UID: $uid"
    echo "Домашняя директория: $home"
    echo "---"
done < "/etc/passwd"

# Восстанавливаем IFS
IFS="$IFS_OLD"
```

Теперь вы можете легко извлекать нужные поля из структурированных данных.

## Вложенные циклы для обработки данных

Можно использовать вложенные циклы для обработки данных из файла — например, разобрать каждую строку на части, а затем обработать каждую часть.

### Обработка CSV-файла

Создайте файл `data.csv`:

```no-highlight
name,age,city
Макар,30,Иркутск
Аристарх,25,Новосибирск
Аделаида,35,Омск
```

Файл `process_csv.sh`:

```bash
#!/bin/bash
# Обработка CSV-файла

# Сохраняем старое значение IFS
IFS_OLD="$IFS"

# Устанавливаем IFS на запятую
IFS=","

# Читаем файл построчно
while read name age city
do
    echo "Имя: $name"
    echo "Возраст: $age"
    echo "Город: $city"
    echo "---"
done < "data.csv"

# Восстанавливаем IFS
IFS="$IFS_OLD"
```

Теперь вы можете обрабатывать любые структурированные данные — будь то CSV, TSV или конфигурационные файлы.

## Практическое задание: создайте скрипт «Анализ пользователей»

### Цель:

Написать скрипт `analyze_users.sh`, который:

1. Читает файл `/etc/passwd` построчно.
2. Для каждого пользователя выводит:
    - Имя пользователя.
    - UID.
    - Домашнюю директорию.
    - Командную оболочку.
3. В конце выводит общее количество пользователей.

### Инструкция:

1. Создайте файл `analyze_users.sh`.
2. Добавьте shebang `#!/bin/bash`.
3. Сохраните старое значение `IFS` и установите `IFS=":"`.
4. Используйте `while read username password uid gid name home shell` для чтения строк.
5. Выведите нужные поля.
6. Подсчитайте количество пользователей с помощью переменной.
7. Восстановите `IFS`.
8. Сохраните, дайте права: `chmod u+x analyze_users.sh`.
9. Запустите: `./analyze_users.sh`.

### Пример решения:

```bash
#!/bin/bash
# Анализ пользователей

# Сохраняем старое значение IFS
IFS_OLD="$IFS"
IFS=":"

user_count=0

echo "=== Список пользователей ==="
while read username password uid gid name home shell
do
    echo "Имя: $username"
    echo "UID: $uid"
    echo "Домашняя директория: $home"
    echo "Оболочка: $shell"
    echo "---"
    ((user_count++))
done < "/etc/passwd"

# Восстанавливаем IFS
IFS="$IFS_OLD"

echo "Всего пользователей: $user_count"
```
