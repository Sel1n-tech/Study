## Введение

Вы уже умеете передавать параметры в скрипт через командную строку и использовать их с помощью `$1`, `$2` и т.д. Но что, если пользователь забудет передать параметр? Или передаст неправильное количество параметров? Скрипт может сломаться или выдать ошибку.

В этом уроке вы узнаете:

- Как проверять наличие параметров перед использованием.
- Как получить количество переданных параметров.
- Как получить последний параметр.
- Как работают специальные переменные `$*` и `$@`.

Эти навыки помогут вам писать надёжные скрипты, которые не сломаются при отсутствии данных.

## Проверка наличия параметров

### Почему это важно?

Если скрипт ожидает параметр, а его нет — он может выдать ошибку или работать неправильно.

### Проверка, что параметр не пустой

Файл `check_param.sh`:

```bash
#!/bin/bash
# Проверяем, что параметр передан

if [ -n "$1" ]; then
    echo "Привет, $1! Рад тебя видеть."
else
    echo "Вы не указали имя. Использование: $0 <имя>"
    exit 1
fi
```

![](https://ucarecdn.stepik.net/fbbb94e1-2754-4216-aaad-af4e7deab1a3/)

Оператор `-n` проверяет, что строка не пустая. Если `$1` пустая — условие ложно.

Всегда оборачивайте переменные в двойные кавычки: `"$1"` — это предотвращает ошибки при пустых значениях.

## Специальная переменная `$#`

### Что это такое?

Переменная `$#` содержит **количество переданных параметров**. Это полезно, когда нужно проверить, что передано правильное количество аргументов.

### Проверка количества параметров

Файл `check_count.sh`:

```bash
#!/bin/bash
# Проверяем количество параметров

echo "Передано параметров: $#"

if [ $# -eq 0 ]; then
    echo "Нет параметров. Использование: $0 <параметр1> <параметр2> ..."
elif [ $# -eq 1 ]; then
    echo "Передан один параметр: $1"
else
    echo "Передано несколько параметров: $@"
fi
```

## Получение последнего параметра

Иногда нужно получить **последний** параметр, не зная, сколько всего параметров передано. Для этого можно использовать переменную `$#` (количество параметров) и подстановку команд.

### Получение последнего параметра

Файл `last_param.sh`:

```bash
#!/bin/bash
# Получаем последний параметр

if [ $# -eq 0 ]; then
    echo "Нет параметров. Использование: $0 <параметр1> <параметр2> ..."
    exit 1
fi

# Получаем последний параметр
last_param=${!#}
echo "Последний параметр: $last_param"
```

![](https://ucarecdn.stepik.net/33e9722c-9429-49fb-914f-65ac2c222f7f/)

`${!#}` — это подстановка команды. `$#` возвращает количество параметров, а `!` заставляет Bash подставить значение переменной с таким номером. Например, если `$# = 3`, то `${!#}` эквивалентно `${3}`.

Не используйте `$${#}` — это неверный синтаксис. Всегда используйте `${!#}`.

## Специальные переменные `$*` и `$@`

### Что это такое?

Эти переменные содержат **все параметры**, но работают по-разному:

|Переменная|Описание|
|---|---|
|`$*`|Все параметры как одна строка (`"$1 $2 ..."`)|
|`$@`|Все параметры как отдельные слова (`"$1" "$2" ...`) — предпочтительно|

### Разница между `$*` и `$@`

Файл `compare_star_at.sh`:

```bash
#!/bin/bash
# Сравниваем $* и $@

echo "Используем \$*: $*"
echo "Используем \$@: $@"

echo ""
echo "Итерация по \$*:"
for param in "$*"
do
    echo "  - $param"
done

echo ""
echo "Итерация по \$@:"
for param in "$@"
do
    echo "  - $param"
done
```

![](https://ucarecdn.stepik.net/51c0a2ac-c606-47e6-bc5b-2015c3075759/)

`"$*"` объединяет все параметры в одну строку, а `"$@"` сохраняет их как отдельные элементы.

Всегда используйте `"$@"` — он работает корректно с пробелами и является стандартом для большинства скриптов.

## Практическое задание: создайте скрипт «Анализ параметров»

### Цель:

Написать скрипт `analyze_params.sh`, который:

1. Проверяет, что передано хотя бы один параметр.
2. Выводит количество переданных параметров.
3. Выводит первый и последний параметр.
4. Выводит все параметры по очереди.

### Инструкция:

1. Создайте файл `analyze_params.sh`.
2. Добавьте shebang `#!/bin/bash`.
3. Проверьте количество параметров: `if [ $# -eq 0 ]; then ... exit 1; fi`.
4. Используйте `$#` для получения количества параметров.
5. Используйте `${!#}` для получения последнего параметра.
6. Используйте `"$@"` для перебора всех параметров.
7. Сохраните, дайте права: `chmod u+x analyze_params.sh`.
8. Запустите: `./analyze_params.sh Alex Jane Bob`.

### Пример решения:

```bash
#!/bin/bash
# Анализ параметров

if [ $# -eq 0 ]; then
    echo "Нет параметров. Использование: $0 <параметр1> <параметр2> ..."
    exit 1
fi

echo "=== Анализ параметров ==="
echo "Количество параметров: $#"
echo "Первый параметр: $1"
echo "Последний параметр: ${!#}"
echo ""

echo "Все параметры:"
count=1
for param in "$@"
do
    echo "  $count: $param"
    ((count++))
done
```
