**Scripted Pipeline**

Сценарный синтаксис является одним из способов оформления pipelines в Jenkins, его можно считать первоначальным вариантом описания шагов pipeline в виде кода. Скриптовой Pipeline начинается со слова **`node`** и внутри него идут различные инструкции, которые выполняют определенные задачи. Больше зависит от языка Groovy  особенно в части – проверки ошибок и работы с исключениями.

```bash
node {
    def hello = "Hello world"
    stage('Hello') {
        echo "${hello}"
        if (hello.isEmpty()) {
            echo "Variable is empty"
        } else {
            echo "Variable is not empty"
        }
    }
    stage('The End') {
        echo 'exit'
    }
}
```

**Declarative Pipeline**

Декларативный pipeline в Jenkins начинается со слова `pipeline`

```typescript
pipeline { 
    agent any

    stages {
        stage('Hello') {
            steps {
                echo 'Hello World'
            }
        }
        stage('The End') {
            steps {
                echo 'exit'
            }
        }
    }
}
```

Декларативный синтаксис – более новый и предпочтительный стиль оформления кода в Jenkins. Конвейеры, написанные в декларативном стиле, расположены в виде четких разделов, которые описывают состояния и результаты

### **Ключевое слово pipeline**

Декларативный pipeline в Jenkins начинается со слова **`pipeline`**

```undefined
pipeline { 

}
```

Ключевое слово **`pipeline`** в Jenkins Pipeline обозначает сам конвейер или поток выполнения. Это основная концепция Jenkins Pipeline, которая позволяет автоматизировать процессы сборки, тестирования и развертывания.

Jenkins Pipeline предоставляет возможность описывать поток выполнения как серию стадий, каждая из которых может состоять из нескольких шагов. Эти стадии могут включать в себя задачи сборки, тестирования, упаковки, развертывания и других операций, которые необходимо выполнить для создания, обновления или развертывания программного обеспечения.

Ключевое слово **`pipeline`** позволяет связать все эти стадии и шаги вместе, создавая непрерывный конвейер обработки. Это позволяет разработчикам автоматизировать процесс разработки, быстро реагировать на изменения и обеспечивать высокое качество выпускаемого ПО.

### Ключевое слово stages

Ключевое слово `**stages**` в Jenkins Pipeline используется для определения стадий или этапов в потоке выполнения.

### Ключевое слово stage

Ключевое слово `**stage**` в Jenkins Pipeline используется для определения отдельного этапа или стадии в потоке выполнения. Каждый этап может состоять из одного или нескольких шагов, которые выполняются последовательно

```javascript
    stages {
        stage('Hello') {
            steps {
                echo 'Hello World'
            }
        }
        stage('The End') {
            steps {
                echo 'exit'
            }
        }
    }
```

###  Ключевое слово **steps**

`**steps**` в Jenkins Pipeline используется для указания набора действий, которые должны быть выполнены на определенном этапе конвейера. Эти действия могут включать запуск команд, выполнение скриптов, загрузку файлов и многое другое.

Например, вы можете использовать шаги для сборки вашего проекта, тестирования его, упаковки и развертывания на сервере. Каждый шаг может быть выполнен с помощью определенной команды или скрипта, и результаты выполнения каждого шага могут быть просмотрены в консоли Jenkins.

В итоге получаем:

```typescript
pipeline { 
    agent any

    stages {
        stage('Hello') {
            steps {
                echo 'Hello World'
            }
        }
        stage('The End') {
            steps {
                echo 'exit'
            }
        }
    }
}
```
