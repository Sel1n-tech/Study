Метод — это имя, данное части кода, который может быть выполнен или вызван, один или несколько раз в программе.

Методам также могут быть заданы параметры, которые действуют в качестве входных значений для вызова метода.

Каждый вызов метода может использовать разные фактические параметры, определяющие поведение метода при его выполнении.

  
Методы Groovy разбивают большие программы на более мелкие управляемые единицы тем самым упрощая задачу программирования. Каждый метод отвечает за часть специфическая функциональность, необходимая в приложении. Один метод может вызывать или выполнять любой другой метод. Таким образом, задача, представленная одним методом, может быть разделена на подзадачи, реализуемые другими подметодами. Кроме того, методы, разработанные в одном  
программа может быть включена в другие программы, избегая дублирования кода.

Метод определяется с помощью ключевого слова **def**. Простейшая форма определения метода без параметров:

```csharp
def methodName() {
    // инструкции
}
```

```scss
def step() {
  println "Welcome !!!"
}

step()
```

В начале мы определяем метод step(). Код метода включает печать текста на экран. Затем метод вызывается с помощью вызова метода step() . Вывод программы: Welcome !!!

## Параметры метода:

Метод более полезен, если его поведение определяется значением одним или нескольким параметров. Мы можем передавать значения вызываемому методу, используя параметры метода. Метод с двумя параметрами выглядит так:

```java
def methodName(para1, para2) {
  // инструкции
}
```

Параметры метода отображаются в виде списка формальных имен параметров, заключенных в  
круглые скобки после имени метода. Имена параметров должны отличаться от друг друга.

```nginx
def step(name) {
  println "${name} Welcome !!!"
}

step('Valera')
```

Данный код распечатает:  Valera Welcome !!!

_Обратите внимание:_

- **параметры** - это переменные, которые используются при создании функции. Здесь это **name**
- **аргументы** - это фактические значения (данные), которые передаются функции при вызове. Здесь это **'Valera'**

Локальные переменные видны в теле метода, в котором они определяются. Это означает, что на них можно ссылаться только в них. Следовательно, в другом месте кода эти переменные не видны и обращатся к ним нельзя. 

## Параметры по умолчанию

Формальные параметры в определении метода могут указывать значения по умолчанию. Где даны значения по умолчанию, эти значения используются, если вызывающая сторона не передает их явно. Значения параметров по умолчанию показаны в виде назначений. Где по умолчанию параметры вводятся в определение метода, то они могут встречаться только  
после нестандартных параметров. То есть параметры по умолчанию могут использоваться только для  
параметры в конце списка формальных параметров. 

```javascript
def methodName(para1, para2 = 0, para3 = 0) {
  // инструкции
}
```

Второму и третьему параметрам присвоены значения по умолчанию.  
Затем можно вызвать метод с одним, двумя или тремя фактическими параметрами. Если указан только один фактический параметр, два других по умолчанию равны нулю. Если используются два фактических параметра, последний параметр равен нулю. Вызов метода должен включать как минимум один фактический параметр и не более трех фактических параметров.  
 

# Возвращаемые значения метода

Метод также может возвращать значение вызывающей стороне. 

```kotlin
return expression
```

Оператор указывает, что управление должно быть немедленно возвращено из метода, а код продолжит выполнение, после вызова метода. 

```python
def add(int a, int b) {
    return a+b
}
```

В Groovy последнее выражение,  в теле метода, может быть возвращено без обязательного использования ключевого слова **return**. Специально для коротких методов  его лучше опустить для краткости:  
 

```javascript
String toStr1() { return "hello" }
String toStr2() { "hello" }
```

### **Определение метода**

Метод определяется с типом возвращаемого значения или с ключевым словом def, чтобы сделать тип возвращаемого значения нетипизированным. Метод также может принимать любое количество аргументов, типы которых могут быть не объявлены явно. Модификаторы Java можно использовать как обычно, и если модификатор видимости не указан, метод является общедоступным.

Методы в Groovy всегда возвращают некоторое значение. Если оператор возврата не указан, будет возвращено значение, оцененное в последней выполненной строке. Например, обратите внимание, что ни один из следующих методов не использует ключевое слово return. 

```java
def someMethod() { 'method called' }                 // метод без объявленного возвращаемого типа и параметра                       
String anotherMethod() { 'another method called' }   // метод с явным типом возврата и без параметра       
def thirdMethod(param1) { "$param1 passed" }         // метод с параметром без определенного типа                
static String fourthMethod(String param1) {          // статический метод со строковым параметром
"$param1 passed" 
} 
```

### Именованные параметры

Методы также могут вызываться с именованными параметрами. Для поддержки этой нотации используется соглашение, в котором первым аргументом метода является Map. В теле метода к значениям параметров можно получить доступ, как и в картах нормалей (map.key). Если метод имеет только один аргумент карты, все предоставленные параметры должны быть именованы.

```java
def user(Map args) { "${args.name}: ${args.password}" }
user(name: 'Alex', password: 1234)
```

### Смешивание именованных и позиционных параметров

Именованные параметры можно смешивать с позиционными параметрами. Применяется то же соглашение, в этом случае в дополнение к аргументу Map в качестве первого аргумента рассматриваемый метод будет иметь дополнительные позиционные аргументы по мере необходимости. Предоставленные позиционные параметры при вызове метода должны быть в порядке. Именованные параметры могут быть в любом положении. Они группируются на карте и автоматически указываются в качестве первого параметра. 

```java
def user(Map args, Integer id) { println "${args.name}: ${args.password}, #ID is ${id}" }

user(name: 'Alex', password: 1234, 1) // Вызов метода с доп числовым аргументом типа Integer

user(2, name: 'Petro', password: 3909) // Вызов метода с измененным порядком следования аргументов
```

Если у нас нет Map в качестве первого аргумента, то для этого аргумента должна быть предоставлена карта вместо именованных параметров. Невыполнение этого требования приведет к исключению groovy.lang.MissingMethodException:

Смотрите на примере:

```java
def user(Integer number, Map args) { "${args.name}: ${args.age}, and the number is ${number}" }
user(3, [name: 'Max', password: 1])  
```

Явный **Map** аргумент вместо именованных аргументов делает вызов действительным  
Groovy позволяет смешивать именованные и позиционные параметры, это может привести к путанице. С осторожностью смешивайте именованные и позиционные аргументы.

### Аргументы по умолчанию

Аргументы по умолчанию делают параметры необязательными. Если аргумент не указан, метод принимает значение по умолчанию.

Это же правило применяется как к конструкторам, так и к методам. При использовании @TupleConstructor применяются дополнительные параметры конфигурации.

### Varargs

Groovy поддерживает методы с переменным числом аргументов.

Они определяются следующим образом:

```python
def methodName(p1, …​, pn, T…​ args)
```

Здесь methodName поддерживает n аргументов по умолчанию, а также неопределенное количество дополнительных аргументов, превышающих n.

```java
def check(Object... args) { args.length }
println check() == 0 // true
println check(1) == 1 // true
println check(1, 2) == 2 // true
```

В этом примере определяется метод **check()**, который может принимать любое количество аргументов, в том числе вообще не иметь аргументов. args.length вернет количество переданных аргументов.

Groovy допускает использование **T[]** в качестве альтернативы **T…​.** Это означает, что любой метод с массивом в качестве последнего параметра рассматривается Groovy как метод, который может принимать переменное количество аргументов.

```java
def check(Object[] args)  { args.length }
println check() == 0 // true
println check(1) == 1 // true
println check(1, 2) == 2 // true
```

Если метод с varargs вызывается с нулем в качестве параметра vararg, то аргумент будет нулевым, а не массивом длины один с нулем в качестве единственного элемента. 

```java
def check(Object[] args)  { args }
assert check(null) == null   // true
```

Если метод varargs вызывается с массивом в качестве аргумента, то аргументом будет этот массив, а не массив длины один, содержащий данный массив в качестве единственного элемента.

```java
def foo(Object... args) { args }
Integer[] ints = [1, 2]
assert foo(ints) == [1, 2]
```
