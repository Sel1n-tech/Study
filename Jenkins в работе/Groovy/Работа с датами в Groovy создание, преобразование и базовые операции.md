**Цель урока:**

- Научиться создавать объекты для представления даты и времени с помощью класса `Date` в Groovy.
- Понять и применить на практике основные методы класса `Date` для получения временных меток, сравнения дат и их преобразования в текст.

**Создание объекта текущей даты и времени**  
Класс `Date` в Groovy является основным для представления момента времени. Самый простой способ создать его — использовать конструктор без параметров. В результате будет создан объект, который хранит информацию о точной дате и времени в момент его создания внутри программы. Это удобно для фиксации момента совершения действия, например, времени запуска скрипта или записи события в журнал.

**Создание даты из количества миллисекунд**  
В основе работы с датами в Java и Groovy лежит отсчет времени в миллисекундах от определенной начальной точки, называемой «эпохой». По умолчанию этой точкой считается 1 января 1970 года, 00:00:00 по Гринвичу (UTC). Конструктор `Date(long millisec)` позволяет создать объект даты, отступив от этой эпохи указанное количество миллисекунд. Это полезно для точных расчетов времени или работы с системами, где время хранится в виде числовых меток.

**Преобразование даты в строку**  
Для удобного отображения даты и времени человеку объект `Date` можно легко преобразовать в текстовый формат. Это автоматически происходит при использовании метода `toString()`, который возвращает строку с датой в стандартном, легко читаемом виде. Часто это происходит неявно, например, при передаче объекта `Date` в функцию `println()`, которая сама вызывает `toString()` для преобразования объекта в текст для вывода на экран.

**Сравнение дат и получение временной метки**  
Для сравнения двух моментов времени на равенство можно использовать метод `equals()`. Однако более надежным и универсальным способом для любых сравнений (равно, раньше, позже) является метод `getTime()`. Он возвращает количество миллисекунд, прошедших с эпохи до момента, который хранится в объекте. Сравнивая эти числовые значения для двух разных объектов `Date`, можно однозначно определить, какой из моментов времени наступил раньше или позже. Метод `setTime(long time)` позволяет перезаписать значение существующего объекта `Date`, установив новую временную метку.

**Примеры:**

**Пример 1: Базовое использование Date**

```javascript
// Создание объекта с текущей датой и временем
Date currentDate = new Date()
println("Сейчас: " + currentDate.toString())

// Создание даты, отстоящей на 10 секунд (10000 мс) от эпохи
Date dateFromEpoch = new Date(10000)
println("10 сек от эпохи: " + dateFromEpoch)
```

> В первом случае мы получаем актуальную дату и время. Во втором — создаем фиксированную дату, соответствующую 1 января 1970 года, 04:00:10 (допущение: для часового пояса SAMT, который на +4 часа от UTC). Обратите внимание, что во второй строке мы не вызываем `.toString()` явно, так как Groovy делает это автоматически.

**Пример 2: Сравнение дат и работа с getTime()**

```javascript
// Создаем две даты
Date dateA = new Date("06/10/2024") // (допущение: парсится как 10 июня 2024)
Date dateB = new Date("08/10/2024") // (допущение: парсится как 10 августа 2024)

// Сравниваем с помощью getTime()
if (dateA.getTime() < dateB.getTime()) {
    println("Дата A наступила раньше Даты B.")
}

// Выводим числовые значения меток
println("Метка dateA: " + dateA.getTime())
println("Метка dateB: " + dateB.getTime())
```

_Разбор:_ Этот пример демонстрирует, как сравнить две даты, сравнив их числовые представления. Дата с меньшим значением `getTime()` наступила раньше. Также мы видим, как можно создать дату из строки, однако точный формат парсинга может зависеть от локали системы (допущение).

**Ключевые особенности:**

- **Простое создание:** Конструктор `new Date()` без параметров моментально возвращает объект с текущей датой и временем.
- **Основа на миллисекундах:** Время внутренне хранится как количество миллисекунд, прошедших с 1 января 1970 года (эпохи Unix), что позволяет выполнять точные вычисления.
- **Легкое преобразование в текст:** Автоматическое преобразование объекта `Date` в удобочитаемую строку с помощью метода `toString()` упрощает вывод информации для пользователя.
- **Сравнение через метки:** Надежнее всего сравнивать даты, сравнивая числовые значения, возвращаемые методом `getTime()`.
- **Изменимость:** Объекты `Date` можно изменять с помощью метода `setTime()`, что позволяет переиспользовать один и тот же объект для представления разных моментов времени.

### **Вывод:**

Класс `Date` предоставляет straightforward-механизм для работы с моментами времени в Groovy. Ключ к пониманию: представление о том, что любая дата это количество миллисекунд от фиксированной точки отсчета. Для начала работы достаточно создать объект и вывести его, а для более сложных операций (сравнение, арифметика) использовать методы `getTime()` и `setTime()`. На практике для сложных манипуляций с датами (добавление дней, месяцев) следует изучить класс `Calendar`, который построен на основе `Date` и предоставляет более богатый функционал.

В Groovy операции с датами очень просты. Groovy имеет множество функций, расширенных из JDK Date API, что позволяет нам упростить использование операций, связанных с датами.

### Date()

> Синтаксис: public Date()
> 
> Параметры:  None
> 
> Возвращаемое значение:  объект Date 

Класс `Date` в Groovy — это встроенный инструмент для работы с датами и временем. Он упрощает создание, хранение и манипуляцию моментами времени, такими как "сегодня", "вчера в 14:30" или "1 января 2020 года". Этот класс основан на одноимённом классе из стандартной библиотеки Java (`java.util.Date`), но Groovy расширяет его возможностями, делая работу с датами более удобной и понятной.

С помощью `Date` можно:

- Получить текущую дату и время;
- Создать дату из количества миллисекунд с 1 января 1970 года (так называемая "эпоха Unix");
- Сравнивать даты между собой;
- Преобразовывать дату в строку для отображения;
- Выполнять арифметические операции (например, прибавить или вычесть дни — с помощью дополнительных методов).

Например, чтобы получить текущую дату, достаточно написать:

```go
def today = new Date()
println today
```

> **output:** Sun Aug 24 12:03:20 UTC 2025

Этот код создаст объект `Date`, представляющий текущий момент, и выведет его в читаемом виде.

Также можно создать дату, указав количество миллисекунд с начальной точки отсчёта (1 января 1970 года, 00:00:00 по Гринвичу):

```go
def dateFromMillis = new Date(1000 * 60 * 60 * 24) // момент времени, наступивший ровно через 1 день (24 часа) после "эпохи Unix" (1 января 1970 года, 00:00:00 UTC).

println dateFromMillis
```

> **output:** **Fri Jan 02 00:00:00 UTC 1970**

**`def dateFromMillis = new Date(1000 * 60 * 60 * 24)`**

Эта строка создает новый объект даты, который представляет собой момент времени, наступивший ровно через 1 день (24 часа) после "эпохи Unix" (1 января 1970 года, 00:00:00 UTC).

Давайте разберем по шагам, как это работает:

1. **`1000`**  это количество миллисекунд в **одной секунде**.
    
2. **`1000 * 60`**  получаем количество миллисекунд в **одной минуте** (60 секунд).
    
3. **`1000 * 60 * 60`**  получаем количество миллисекунд в **одном часе** (60 минут).
    
4. **`1000 * 60 * 60 * 24`**  и, наконец, получаем количество миллисекунд в **одних сутках** (24 часа).
    

**Результат вычисления:** `1000 * 60 * 60 * 24 = 86 400 000 миллисекунд`

**`new Date(86 400 000)`** - конструктор класса `Date` принимает это вычисленное значение. Он создает объект даты, который соответствует моменту, наступившему через 86 400 000 миллисекунд после начала "эпохи".

Каждый объект `Date` хранит время с точностью до миллисекунды. Две даты считаются равными, если они представляют один и тот же момент времени — то есть их значения в миллисекундах совпадают.

Для получения этого значения используется метод `getTime()`, который возвращает число миллисекунд с эпохи. Обратно, метод `setTime(long milliseconds)` позволяет изменить момент времени, который представляет объект `Date`.

Хотя класс `Date` удобен для простых задач, для сложных операций, прибавления месяцев или учёта часовых поясов  рекомендуется использовать более современные инструменты, такие как `Calendar` или, в новых версиях Groovy и Java, классы из пакета `java.time` (например, `LocalDateTime`, `ZonedDateTime`).

Тем не менее, `Date` остаётся полезным для базовой работы с временными метками, логирования, сравнения моментов и форматированного вывода даты.
