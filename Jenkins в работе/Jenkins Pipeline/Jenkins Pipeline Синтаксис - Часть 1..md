## **Типы данных**

**Примитивные типы:**

- целые типы: byte(8 бит), short(16 бит), int(32 бит) и long(64 бит)
- типы с плавающей точкой: float(32 бит) и  double(64 бит)
- boolean тип (true или false)
- char тип (16 бит, можно использовать как числовой тип, представляющий код UTF-16)

**Примитивы и обертки:**

- boolean - java.lang.Boolean
- char - java.lang.Character
- short - java.lang.Short
- int - java.lang.Integer
- long -  java.lang.Long
- float - java.lang.Float
- double - java.lang.Double

## **Строки**

- Строка в одинарных кавычках
    
    - ```bash
        'a single-quoted string'
        ```
        
- Строка в тройных одинарных кавычках
    
    - ```python
        '''a triple-single-quoted string'''
        ```
        
- Строка в двойных кавычках
    
    - ```bash
        "a double-quoted string"
        ```
        
- Строка с тройными двойными кавычками
    
    - ```python
        """ this is string """
        ```
        

Конкатенация строк 

```vbnet
‘This is ‘ + ‘Text’
```

Интерполяция строки 

```kotlin
“this is ${Variable1}”
```

## **Переменные**

**Определение переменной:**

```css
String str1

def y
```

**Присвоение переменной:**

```ini
y = 1

str1 = “This is new string”
```

**Множественное присваивание:**

```vbnet
def (q, w, r) = [ 0.001, 9 , ‘new text’]
```

**Получить тип переменной:**

```css
println q.getClass()
```
