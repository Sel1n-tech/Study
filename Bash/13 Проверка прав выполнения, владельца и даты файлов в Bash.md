## Введение

Вы уже умеете проверять существование файлов, их тип и права на чтение/запись. Но часто нужно убедиться, что вы можете **выполнить** файл (например, скрипт), являетесь ли вы его **владельцем**, или что файл **не устарел** по сравнению с другим. Эти проверки критически важны для написания надёжных и безопасных скриптов.

Этот урок поможет вам:

- Понять, как проверить права на выполнение файла.
- Использовать операторы `-x`, `-O`, `-G`.
- Сравнивать даты создания файлов (`-nt`, `-ot`).
- Избегать распространённых ошибок при работе с этими операторами.

## Проверка прав на выполнение (`-x`)

Часто нужно убедиться, что файл можно запустить, прежде чем пытаться его выполнить.

### Проверка прав на выполнение скрипта

Файл `check_exec.sh`:

```bash
#!/bin/bash
# Проверяем, можно ли выполнить скрипт

script_name="./my_script.sh"

if [ -x "$script_name" ]
then
    echo "Файл $script_name доступен для выполнения."
    echo "Запускаем скрипт..."
    ./"$script_name"
else
    echo "Файл $script_name недоступен для выполнения."
    echo "Дайте права на выполнение с помощью 'chmod u+x $script_name'"
fi
```

## Проверка владельца файла (`-O`)

Иногда нужно убедиться, что вы являетесь владельцем файла — например, перед удалением или изменением конфигурационного файла.

### Проверка владельца файла

Файл `check_owner.sh`:

```bash
#!/bin/bash
# Проверяем, является ли текущий пользователь владельцем файла

file_name="/etc/passwd"

if [ -O "$file_name" ]
then
    echo "Вы являетесь владельцем файла $file_name."
else
    echo "Вы не являетесь владельцем файла $file_name."
fi
```

## Проверка группы файла (`-G`)

Оператор `-G` проверяет, принадлежит ли файл **группе по умолчанию** текущего пользователя. Это не то же самое, что проверка всех групп, в которых состоит пользователь.

### Проверка группы файла

Файл `check_group.sh`:

```bash
#!/bin/bash
# Проверяем, принадлежит ли файл группе по умолчанию пользователя

file_name="$HOME/testing.txt"

# Создаём файл для теста
touch "$file_name"

if [ -G "$file_name" ]
then
    echo "Файл $file_name принадлежит группе по умолчанию пользователя."
else
    echo "Файл $file_name не принадлежит группе по умолчанию пользователя."
fi

# Меняем группу файла
sudo chgrp sharing "$file_name"

if [ -G "$file_name" ]
then
    echo "После смены группы: файл $file_name принадлежит группе по умолчанию пользователя."
else
    echo "После смены группы: файл $file_name не принадлежит группе по умолчанию пользователя."
fi
```

## Сравнение дат файлов (`-nt`, `-ot`)

Иногда нужно проверить, какой из двух файлов **новее** или **старее**. Это полезно при автоматизации установки программ или обновления конфигураций.

### Операторы:

|Оператор|Описание|
|---|---|
|`file1 -nt file2`|Проверяет, что `file1` **новее** `file2` (дата создания/изменения)|
|`file1 -ot file2`|Проверяет, что `file1` **старее** `file2`|

### Сравнение дат файлов

Файл `compare_dates.sh`:

```bash
#!/bin/bash
# Сравниваем даты файлов

file1="check_user.sh"
file2="check_owner.sh"

# Создаём файлы для теста
touch "$file1"
sleep 5  # Ждём 5 секунд, чтобы файлы имели разные даты
touch "$file2"

if [ "$file1" -nt "$file2" ]
then
    echo "Файл $file1 новее файла $file2."
elif [ "$file1" -ot "$file2" ]
then
    echo "Файл $file1 старее файла $file2."
else
    echo "Файлы $file1 и $file2 имеют одинаковую дату."
fi
```

![](https://ucarecdn.stepik.net/503d9785-d763-4c68-8f1c-99569e435092/)

Эти операторы **не проверяют существование файлов**! Если файл не существует, условие считается ложным.

## Практическое задание: создайте скрипт «Безопасный запуск»

### Цель:

Написать скрипт `safe_run.sh`, который:

1. Проверяет, существует ли файл `my_app.sh`.
2. Проверяет, является ли файл обычным файлом (`-f`).
3. Проверяет, доступен ли файл для выполнения (`-x`).
4. Если файл доступен для выполнения — запускает его.
5. Если файл не доступен для выполнения — выводит сообщение об ошибке и предлагает дать права.

### Инструкция:

1. Создайте файл `safe_run.sh`.
2. Добавьте shebang `#!/bin/bash`.
3. Используйте `[ -f ... ]` для проверки файла, `[ -x ... ]` для проверки прав.
4. Используйте `./"$filename"` для запуска файла.
5. Сохраните, дайте права: `chmod u+x safe_run.sh`.
6. Запустите: `./safe_run.sh`.

### Пример решения:

```bash
#!/bin/bash
# Безопасный запуск скрипта

script_name="my_app.sh"

echo "Проверяем файл: $script_name"

if [ ! -f "$script_name" ]; then
    echo "Файл $script_name не существует."
    exit 1
fi

if [ ! -x "$script_name" ]; then
    echo "Файл $script_name недоступен для выполнения."
    echo "Предлагаю дать права на выполнение: chmod u+x $script_name"
    exit 1
fi

echo "Файл $script_name существует и доступен для выполнения."
echo "Запускаем..."
./"$script_name"
```

## Заключение

Вы узнали, как:

- Проверять права на выполнение файла с помощью `-x`.
- Проверять, является ли текущий пользователь владельцем файла (`-O`) или принадлежит ли файл его группе (`-G`).
- Сравнивать даты файлов с помощью `-nt` и `-ot`.
- Создавать надёжные скрипты, которые не сломаются при отсутствии нужных прав или файлов.
