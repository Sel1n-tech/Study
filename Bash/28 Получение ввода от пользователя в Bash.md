## Введение

Вы уже умеете передавать данные в скрипт через параметры командной строки и обрабатывать опции с помощью `getopts`. Но что, если нужно, чтобы пользователь ввёл данные **во время выполнения скрипта**? Например, имя, пароль или подтверждение действия.

Для этого в Bash есть команда **`read`** — она позволяет считывать ввод с клавиатуры и сохранять его в переменную.

Этот урок поможет вам:

- Понять, как работает команда `read`.
- Использовать её для получения одного или нескольких значений.
- Обрабатывать ввод с таймером и ограничением по количеству символов.
- Скрывать ввод (например, пароли).
- Читать данные из файла.

## Основы команды `read`

### Что это такое?

Команда `read` ожидает ввода от пользователя и сохраняет его в переменную.

### Простой ввод

Файл `greet_user.sh`:

```bash
#!/bin/bash
# Запрашиваем имя пользователя

echo -n "Введите ваше имя: "
read name
echo "Привет, $name! Рад тебя видеть."
```

![](https://ucarecdn.stepik.net/3e2336dc-fc24-4dc9-ae6c-d42ca2870c6a/)

Опция `-n` у команды `echo` подавляет перевод строки, поэтому приглашение и ввод находятся на одной строке.

## Ввод нескольких значений

Команда `read` может считывать несколько значений за один раз, если они разделены пробелами.

### Ввод имени и фамилии

Файл `full_name.sh`:

```bash
#!/bin/bash
# Запрашиваем имя и фамилию

echo -n "Введите ваше имя и фамилию: "
read first last
echo "Здравствуйте, $last $first!"
```

![](https://ucarecdn.stepik.net/a805b8bc-a2f3-40ee-a778-7ccf7e2501ca/)

Первая часть ввода сохраняется в переменную `first`, вторая — в `last`.

Если вы не указали переменные для `read`, он сохранит весь ввод в специальную переменную `REPLY`.

## Таймер и ограничение по времени

Иногда нужно, чтобы скрипт не ждал бесконечно — например, если пользователь не ответил.

Для этого используется опция `-t`.

### Ввод с таймером

Файл `timed_input.sh`:

```bash
#!/bin/bash
# Запрашиваем имя с таймером

echo -n "Введите ваше имя (у вас есть 5 секунд): "
if read -t 5 name; then
    echo "Привет, $name! Рад тебя видеть."
else
    echo "Время истекло. Попробуйте снова."
fi
```

![](https://ucarecdn.stepik.net/e5c86df9-8580-4903-8dec-fd9582684885/)

Команда `read` возвращает ненулевой код завершения, если таймер истёк — это можно использовать в `if`.

## Ограничение по количеству символов

Если нужно получить только один символ (например, подтверждение действия), используйте опцию `-n`.

### Подтверждение действия

Файл `confirm_action.sh`:

```bash
#!/bin/bash
# Запрашиваем подтверждение

echo -n "Вы уверены, что хотите продолжить? [Y/N]: "
read -n 1 answer

case "$answer" in
    [Yy])
        echo ""
        echo "Действие подтверждено. Продолжаем..."
        ;;
    [Nn])
        echo ""
        echo "Действие отменено. Выход."
        exit 0
        ;;
    *)
        echo ""
        echo "Неизвестный ответ. Выход."
        exit 1
        ;;
esac
```

![](https://ucarecdn.stepik.net/2e08f4af-dfe9-4499-8a3e-70e653129dbe/)

Пользователь не должен нажимать Enter — достаточно нажать одну клавишу.

## Скрытие ввода (пароли)

Если нужно ввести пароль или другую конфиденциальную информацию, используйте опцию `-s`. Ввод не будет отображаться на экране.

### Ввод пароля

Файл `password_input.sh`:

```bash
#!/bin/bash
# Запрашиваем пароль

echo -n "Введите пароль: "
read -s password
echo ""  # Переходим на новую строку
echo "Пароль принят. (В реальном скрипте его нужно проверить)"
```

![](https://ucarecdn.stepik.net/00979930-07a5-4576-8438-f754ccdebc58/)

Пароль не отображается на экране — это важно для безопасности.

## Чтение данных из файла

Команда `read` также может читать данные из файла — для этого используется перенаправление ввода.

### Чтение файла построчно

Файл `read_file.sh`:

```bash
#!/bin/bash
# Читаем файл построчно

filename="data.txt"

if [ ! -f "$filename" ]; then
    echo "Файл $filename не найден."
    exit 1
fi

count=1
while read line; do
    echo "Строка $count: $line"
    ((count++))
done < "$filename"

echo "Обработка файла завершена."
```

![](https://ucarecdn.stepik.net/8d567e57-c726-48d7-bf2a-8e47cee2c4b5/)

Каждая строка файла считывается в переменную `line` и выводится на экран.

## Практическое задание: создайте скрипт «Регистрация пользователя»

### Цель:

Написать скрипт `register_user.sh`, который:

1. Запрашивает у пользователя:
    - Имя.
    - Возраст.
    - Пароль (скрытый ввод).
2. Проверяет, что возраст больше 18.
3. Если возраст меньше 18 — выводит сообщение об ошибке.
4. Если всё в порядке — выводит приветствие и сохраняет данные в файл `users.txt`.

### Инструкция:

1. Создайте файл `register_user.sh`.
2. Добавьте shebang `#!/bin/bash`.
3. Используйте `read` для получения имени, возраста и пароля.
4. Используйте `if` для проверки возраста.
5. Сохраните данные в файл `users.txt`.
6. Сохраните, дайте права: `chmod u+x register_user.sh`.
7. Запустите: `./register_user.sh`.

### Пример решения:

```bash
#!/bin/bash
# Регистрация пользователя

echo -n "Введите ваше имя: "
read name

echo -n "Введите ваш возраст: "
read age

echo -n "Введите пароль: "
read -s password
echo ""

# Проверяем возраст
if [ $age -lt 18 ]; then
    echo "Вам должно быть не менее 18 лет для регистрации."
    exit 1
fi

# Сохраняем данные в файл
echo "Имя: $name" >> users.txt
echo "Возраст: $age" >> users.txt
echo "Пароль: [скрыт]" >> users.txt
echo "---" >> users.txt

echo "Пользователь $name успешно зарегистрирован!"
echo "Данные сохранены в users.txt"
```
