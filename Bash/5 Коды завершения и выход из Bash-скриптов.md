## Введение

До сих пор мы запускали скрипты, и они просто заканчивали работу после выполнения последней команды. Но в реальном мире важно знать — **успешно ли выполнился скрипт или произошла ошибка?** Это позволяет автоматизировать процессы: если один скрипт завершился с ошибкой, следующий не должен запускаться.

В этом уроке вы узнаете:

- Что такое **код завершения (exit status)**.
- Как проверить результат выполнения команды.
- Как **вручную установить код завершения** своего скрипта.
- Почему коды ограничены диапазоном от 0 до 255.

## Что такое код завершения?

### Определение

Каждая команда в Linux при завершении возвращает **целое число от 0 до 255**, называемое **кодом завершения (exit status)**. Этот код сообщает оболочке (shell), как прошло выполнение команды.

Запомните главное правило:

- **`0` — успех** (команда выполнилась без ошибок).
- **Любое другое число (`1`, `2`, `127`, ...) — ошибка**.

### Как посмотреть код завершения?

Используйте специальную переменную `$?`. Она всегда содержит код завершения **последней выполненной команды**.

**Пример:**

```bash
date
echo $?
```

![](https://ucarecdn.stepik.net/a25a1cfe-6b4e-4a00-af80-18cee08d2de9/)

Команда `date` выполнилась успешно, поэтому код `0`.

**Ошибка:**

![](https://ucarecdn.stepik.net/a81d31df-8841-45f4-bae9-07fbb5c7941b/)

Команда не найдена, поэтому код `127`.

## Стандартные коды завершения

Хотя нет жёстких правил, в Linux принято использовать следующие коды:

|Код|Описание|
|---|---|
|**0**|Успешное завершение команды|
|**1**|Общая неизвестная ошибка|
|**2**|Неправильное использование командной строки (например, неверный синтаксис)|
|**126**|Команда не может быть выполнена (например, нет прав на запуск файла)|
|**127**|Команда не найдена|
|**128+x**|Фатальная ошибка с сигналом `x` (например, `Ctrl+C` = 130)|
|**255**|Код вне допустимого диапазона|

**Пример:**

Нет прав на выполнение?, код `126`.

## Команда `exit` — контролируем выход из скрипта

По умолчанию, когда ваш скрипт заканчивает работу, он возвращает код завершения **последней команды**. Но часто нужно вернуть **свой собственный код** — например, чтобы сообщить внешней системе, что скрипт выполнился успешно, но с предупреждением.

### Синтаксис:

```bash
exit [код]
```

Если код не указан, скрипт возвращает код последней команды.

**Пример: возвращаем свой код**

Создадим файл `script_exit.sh`:

```bash
#!/bin/bash
# Тестирование exit

var1=10
var2=30
result=$((var1 + var2))

echo "Результат: $result"
exit 5
```

И запустим:

![](https://ucarecdn.stepik.net/30d648bf-2f3b-4fc1-a44b-ad27c55b87aa/)

Мы явно указали `exit 5`, поэтому `$?` равен `5`, а не `0` (код `echo`).

**Практическое применение:**  
Вы можете использовать `exit 0` для успешного завершения и `exit 1` для ошибки. Это стандарт для большинства скриптов.

## Использование переменных в `exit`

Вы можете передать в `exit` значение переменной.

**Пример:**

Файл `script_var_exit.sh`:

```bash
#!/bin/bash
# Используем переменную в exit

var1=10
var2=30
result=$((var1 + var2))

echo "Результат: $result"
exit $result
```

![](https://ucarecdn.stepik.net/e9fe22be-7513-49b7-8fee-4a2e581b97c3/)

Код завершения теперь равен значению переменной `result`.

## Важное ограничение — диапазон 0–255

Коды завершения могут быть только в диапазоне **от 0 до 255**. Если вы попытаетесь передать число больше 255, shell автоматически «обрежет» его с помощью операции **остатка от деления на 256** (модульная арифметика).

**Пример:**

Файл `script_overflow.sh`:

```bash
#!/bin/bash
# Тестирование переполнения

var1=10
var2=30
result=$((var1 * var2))  # 300

echo "Значение: $result"
exit $result
```

Запустим:

![](https://ucarecdn.stepik.net/48dfd529-fc3d-4379-958f-06269565c7c7/)

Почему `44`?  
Потому что `300 % 256 = 44`.  
Shell берёт остаток от деления на 256, чтобы получить число в допустимом диапазоне.

Не используйте большие числа в `exit`. Они будут «сломаны». Для передачи сложной информации лучше использовать вывод в файл или переменные окружения.

## Практическое задание: создайте «умный» скрипт с проверкой

### Цель:

Написать скрипт `check_calc.sh`, который:

1. Принимает два числа как аргументы (например, `./check_calc.sh 10 5`).
2. Складывает их.
3. Если сумма больше 100 — возвращает код `100`.
4. Если сумма меньше 100 — возвращает код `0`.
5. Если сумма равна 100 — возвращает код `50`.
6. Выводит сообщение с результатом.

### Инструкция:

Создайте файл `check_calc.sh`.

Добавьте shebang `#!/bin/bash`.

Получите аргументы через `$1` и `$2`. Количество переданных аргументов можно проверить через `$#`.

Выполните сложение.

Используйте условие `if` (мы ещё не проходили, но вот простой шаблон — можно скопировать):

```bash
if [ $sum -gt 100 ]; then
    echo "Сумма больше 100: $sum"
    exit 100
elif [ $sum -eq 100 ]; then
    echo "Сумма равна 100: $sum"
    exit 50
else
    echo "Сумма меньше 100: $sum"
    exit 0
fi
```

Сохраните, дайте права: `chmod u+x check_calc.sh`.

Запустите с разными аргументами и проверьте `$?`.

### Пример решения:

```bash
#!/bin/bash
# Проверка суммы и возврат кода завершения

if [ $# -ne 2 ]; then
    echo "Использование: $0 <число1> <число2>"
    exit 1
fi

num1=$1
num2=$2
sum=$((num1 + num2))

if [ $sum -gt 100 ]; then
    echo "Сумма больше 100: $sum"
    exit 100
elif [ $sum -eq 100 ]; then
    echo "Сумма равна 100: $sum"
    exit 50
else
    echo "Сумма меньше 100: $sum"
    exit 0
fi
```
