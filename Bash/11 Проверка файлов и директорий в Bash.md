## Введение

Вы уже умеете сравнивать числа и строки с помощью команды `test` или `[ ]`. Но часто нужно работать с файловой системой — проверять, существует ли файл, является ли он директорией, доступен ли для чтения или записи. Это особенно важно при написании скриптов, которые создают резервные копии, записывают логи или обрабатывают данные из файлов.

Этот урок поможет вам:

- Понять, как проверять существование файлов и директорий.
- Использовать операторы `-d`, `-f`, `-e` и другие.
- Проверять права доступа к файлам.
- Создавать надёжные скрипты, которые не сломаются при отсутствии нужных файлов.

## Операторы проверки файлов

Команда `test` (или `[ ]`) позволяет проверять состояние файлов и директорий с помощью следующих операторов:

|Оператор|Описание|
|---|---|
|`-d file`|Проверяет, существует ли файл и является ли он **директорией**|
|`-e file`|Проверяет, существует ли файл или директория|
|`-f file`|Проверяет, существует ли файл и является ли он **обычным файлом**|
|`-r file`|Проверяет, существует ли файл и доступен ли для **чтения**|
|`-w file`|Проверяет, существует ли файл и доступен ли для **записи**|
|`-x file`|Проверяет, существует ли файл и доступен ли для **выполнения**|
|`-s file`|Проверяет, существует ли файл и **не пустой** (размер > 0)|

Всегда оборачивайте имя файла в двойные кавычки: `"$filename"` — это предотвращает ошибки при именах файлов с пробелами или специальными символами.

## Проверка директорий (`-d`)

Часто нужно убедиться, что директория существует, прежде чем пытаться в неё записать файл или перейти в неё.

### Проверка директории перед переходом

Файл `check_dir.sh`:

```bash
#!/bin/bash
# Проверяем, существует ли директория

jump_directory="/home/sviatoslav"

if [ -d "$jump_directory" ]
then
    echo "Директория $jump_directory существует."
    cd "$jump_directory"
    ls
else
    echo "Директория $jump_directory не существует."
fi
```

## Проверка существования файла или директории (`-e`)

Оператор `-e` проверяет, существует ли объект (файл или директория). Это полезно, когда вы не знаете, что именно ожидаете — файл или директорию.

### Проверка файла и директории

Файл `check_exists.sh`:

```bash
#!/bin/bash
# Проверяем существование файла и директории

location="$HOME"
file_name="wtf.txt"

echo "Проверяем директорию: $location"
if [ -e "$location" ]
then
    echo "Директория $location существует."
else
    echo "Директория $location не существует."
    exit 1
fi

echo ""
echo "Проверяем файл: $location/$file_name"
if [ -e "$location/$file_name" ]
then
    echo "Файл $location/$file_name существует."
else
    echo "Файл $location/$file_name не существует. Создаём его..."
    touch "$location/$file_name"
    echo "Текущая дата: $(date)" >> "$location/$file_name"
    echo "Файл создан и обновлён."
fi
```

После создания файла запускаем скрипт ещё раз — теперь он выведет, что файл существует.

## Проверка, является ли объект файлом (`-f`)

Если вам нужно быть уверенным, что объект — это именно файл, а не директория, используйте оператор `-f`.

### Проверка типа объекта

Файл `check_type.sh`:

```bash
#!/bin/bash
# Проверяем, является ли объект файлом

item_name="$HOME"

echo "Проверяем объект: $item_name"
if [ -e "$item_name" ]
then
    echo "Объект $item_name существует."

    if [ -f "$item_name" ]
    then
        echo "$item_name — это файл."
    else
        echo "$item_name — это не файл (скорее всего, директория)."
    fi
else
    echo "Объект $item_name не существует."
fi
```

## Проверка прав доступа (`-r`, `-w`, `-x`)

Иногда нужно проверить, можно ли читать, писать или выполнять файл.

### Проверка прав доступа

Файл `check_permissions.sh`:

```bash
#!/bin/bash
# Проверяем права доступа к файлу

filename="my_script.sh"

if [ -e "$filename" ]
then
    echo "✅ Файл $filename существует."

    if [ -r "$filename" ]
    then
        echo "Файл доступен для чтения."
    else
        echo "Файл недоступен для чтения."
    fi

    if [ -w "$filename" ]
    then
        echo "Файл доступен для записи."
    else
        echo "Файл недоступен для записи."
    fi

    if [ -x "$filename" ]
    then
        echo "Файл доступен для выполнения."
    else
        echo "Файл недоступен для выполнения."
    fi
else
    echo "Файл $filename не существует."
fi
```

## Практическое задание: создайте скрипт «Обновление лога»

### Цель:

Написать скрипт `update_log.sh`, который:

1. Проверяет, существует ли директория `/var/log/myapp`.
2. Если директория не существует — создаёт её.
3. Проверяет, существует ли файл `/var/log/myapp/app.log`.
4. Если файл не существует — создаёт его и пишет туда заголовок.
5. Добавляет текущую дату и время в конец файла.
6. Выводит сообщение о результате.

### Инструкция:

1. Создайте файл `update_log.sh`.
2. Добавьте shebang `#!/bin/bash`.
3. Используйте `[ -d ... ]` для проверки директории, `[ -f ... ]` для файла.
4. Используйте `mkdir -p` для создания директории, `touch` для файла, `>>` для добавления данных.
5. Сохраните, дайте права: `chmod u+x update_log.sh`.
6. Запустите: `./update_log.sh`.

### Пример решения:

```bash
#!/bin/bash
# Обновление лог-файла приложения

log_dir="/var/log/myapp"
log_file="$log_dir/app.log"

# Проверяем и создаём директорию
if [ ! -d "$log_dir" ]; then
    echo "Директория $log_dir не существует. Создаём..."
    sudo mkdir -p "$log_dir"
    if [ $? -eq 0 ]; then
        echo "Директория создана."
    else
        echo "Не удалось создать директорию. Проверьте права."
        exit 1
    fi
fi

# Проверяем и создаём файл
if [ ! -f "$log_file" ]; then
    echo "Файл $log_file не существует. Создаём..."
    touch "$log_file"
    echo "=== Лог-файл приложения ===" > "$log_file"
    echo "Файл создан."
fi

# Добавляем текущую дату и время
echo "$(date): Скрипт выполнен." >> "$log_file"
echo "Лог-файл обновлён."
```
