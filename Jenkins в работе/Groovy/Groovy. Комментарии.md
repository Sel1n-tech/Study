## **Однострочный комментарий**

Однострочные комментарии начинаются с **//** и могут быть найдены в любой позиции в строке.

Следующие символы **//** до конца строки считаются частью комментария.

![](https://lh5.googleusercontent.com/e3B11PdkdaOj9gmdDH3nBlm2cIgj9W061O5nYcsyNd81U2O2h8-vb40tTSZmwdrSrQfRQQeBvQWdARmh1NchPN-YCDhoqBfVC1bVHe2GfhP-4YGVDM5dGaM918DPdrAmyLFHllVxrBvCu7D2Uts7jQ)

Если попытаетесь выполнить следующий код то получите в результате:

```undefined
hello
```

## **Shebang #!**

Помимо однострочного комментария, есть специальный строковый комментарий **#!**, часто называемый строкой shebang, понятной в системах UNIX, который позволяет запускать сценарии непосредственно из командной строки при условии, что вы установили дистрибутив Groovy и groovy команда доступна в PATH.

## **Многострочный комментарий**

Многострочный комментарий начинается с **/*** и может быть найден в любой позиции в строке.

  
Следующие ниже символы **/*** будут считаться частью комментария, включая символы новой строки, вплоть до первого ***/**закрытия комментария.

Таким образом, многострочные комментарии могут быть помещены в конец оператора или даже внутри оператора.

## **Groovydoc комментарий**

Как и многострочные комментарии, комментарии **Groovydoc** являются многострочными.

Начинаются **/**** и заканчиваются ***/**.

Эти комментарии связаны с:

- определения типов (классы, интерфейсы, перечисления, аннотации),
- определения полей и свойств
- определения методов

Хотя компилятор не будет жаловаться на то, что комментарии Groovydoc не связаны с указанными выше языковыми элементами, вам следует добавить к этим конструкциям комментарий прямо перед ними.  
Groovydoc следует тем же соглашениям, что и собственный Javadoc. Таким образом, вы сможете использовать те же теги, что и в Javadoc.

_Строки, следующие за первой строкой комментария **Groovydoc**, могут необязательно начинаться со звездочки *._

```javascript
/**
 * Этот код для очень занятого студента, который не хочет вводить его руками!
 */
class Passenger {
    /** Фамилия и имя типа String */
    String firstName
    String lastName

    /**
     * Это метод hello
     *
     * @param принимает строку 
     * @return возвращает строку 
     */
    String hello() {
       "Hello ${firstName} ${lastName}"
    }
}

Passenger p = new Passenger()
p.firstName = "Alex"
p.lastName = "Fox"
p.hello()
```
