## Введение

Вы уже умеете запускать задачи в определённое время с помощью команды `at`. Но что, если нужно выполнять задачу **регулярно** — каждый день, каждую неделю или каждый месяц?

Для этого в Linux есть мощный инструмент — **`cron`**. Он позволяет планировать задачи с высокой точностью — например, каждый день в 8:00 утра или каждую среду в 15:30.

Также существует команда **`anacron`**, которая решает проблему `cron` — если система была выключена, `anacron` выполнит пропущенные задачи при включении.

Этот урок поможет вам:

- Понять, как работает `cron` и его таблица.
- Научиться создавать регулярные задачи.
- Использовать `anacron` для задач, которые должны выполняться даже после отключения системы.
- Создавать надёжные скрипты, которые автоматически выполняются по расписанию.

## Что такое `cron`?

### Определение

`cron` — это демон (фоновый процесс), который запускает задачи по расписанию. Расписание хранится в специальных файлах — **`crontab`** (сокращение от _cron table_).

### Формат строки `crontab`:

```no-highlight
минута час день_месяца месяц день_недели команда
```

Все поля могут содержать:

- Число (например, `15`).
- Диапазон (например, `1-5`).
- Символ `*` (любое значение).
- Список значений (например, `1,3,5`).

### Запуск задачи каждый день в 10:15

```no-highlight
15 10 * * * /home/user/backup.sh
```

Задача будет запускаться каждый день в 10:15.

### Запуск задачи каждый понедельник в 16:16

```no-highlight
16 16 * * 1 /home/user/report.sh
```

`1` — понедельник (дни недели: 0=воскресенье, 1=понедельник, ..., 6=суббота).

### Запуск задачи в 12:00 первого числа каждого месяца

```no-highlight
00 12 1 * * /home/user/monthly_cleanup.sh
```

```no-highlight
1 — первое число месяца.
```

## Работа с `crontab`

### Просмотр задач

Чтобы посмотреть свои задачи, используйте:

```bash
crontab -l
```

### Редактирование задач

Чтобы отредактировать задачи, используйте:

```bash
crontab -e
```

По умолчанию `crontab -e` открывает редактор `nano`. Если вы предпочитаете `vim`, установите переменную окружения: `export EDITOR=vim`.

## Предопределённые директории `cron`

Если не нужно создавать сложные расписания, можно просто скопировать скрипт в одну из предопределённых директорий:

|Директория|Частота|
|---|---|
|`/etc/cron.hourly`|Каждый час|
|`/etc/cron.daily`|Каждый день|
|`/etc/cron.weekly`|Каждую неделю|
|`/etc/cron.monthly`|Каждый месяц|

### Запуск скрипта каждый день

Файл `daily_backup.sh`:

```bash
#!/bin/bash
# Ежедневное резервное копирование

echo "Начинаю резервное копирование..."
cp -r /home/user/data /home/user/backup/
echo "Резервное копирование завершено."
```

![](https://ucarecdn.stepik.net/ddabb922-fd39-4252-9521-c7cef45f4ca8/)

Скрипт будет запускаться каждый день в 06:25 (по умолчанию для `cron.daily`).

## Команда `anacron`

### Что это такое?

`anacron` — это альтернатива `cron`, которая решает проблему: если система была выключена, `cron` не выполнит пропущенные задачи. `anacron` же выполнит их при включении.

### Где хранятся задачи `anacron`?

Файл конфигурации: `/etc/anacrontab`

### Формат строки `anacrontab`:

```bash
период_в_днях задержка_в_минутах идентификатор команда
```

`anacron` используется для задач, которые должны выполняться регулярно, но не критично точно — например, очистка логов или обновление баз данных.

### Запуск ежедневной очистки

Файл `/etc/anacrontab`:

![](https://ucarecdn.stepik.net/29efb55c-5129-4f3d-83f3-322cf8445b8c/)

`1 5` — задача выполняется раз в день, через 5 минут после запуска `anacron`.

## Практическое задание: создайте скрипт «Ежедневная очистка»

### Цель:

Написать скрипт `daily_cleanup.sh`, который:

1. Удаляет файлы старше 7 дней в директории `/tmp`.
2. Записывает результат в лог-файл `/var/log/cleanup.log`.
3. Планирует выполнение скрипта каждый день с помощью `cron`.

### Инструкция:

1. Создайте файл `daily_cleanup.sh`.
2. Добавьте shebang `#!/bin/bash`.
3. Найдите и удалите файлы старше 7 дней.
4. Запишите результат в лог-файл.
5. Добавьте задачу в `crontab`.
6. Сохраните, дайте права: `chmod u+x daily_cleanup.sh`.
7. Запустите: `sudo crontab -e`.

### Пример решения:

```bash
#!/bin/bash
# Ежедневная очистка

log_file="/var/log/cleanup.log"

echo "=== Начало очистки $(date) ===" >> "$log_file"

# Удаляем файлы старше 7 дней
find /tmp -type f -mtime +7 -delete

echo "Очистка завершена." >> "$log_file"
```

Добавьте в `crontab`:

```no-highlight
0 6 * * * /home/user/daily_cleanup.sh
```

Скрипт будет запускаться каждый день в 6:00 утра.
