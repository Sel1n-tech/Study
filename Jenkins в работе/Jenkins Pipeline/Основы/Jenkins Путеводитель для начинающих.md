## **Введение**

Добро пожаловать в мир Jenkins! Если вы впервые открыли главную страницу и растерялись от обилия кнопок и меню - не переживайте. Это не хаос, а набор мощных инструментов, которые скоро станут вашими верными помощниками в автоматизации.

Этот путеводитель проведет вас по 12 ключевым элементам интерфейса. Мы разберем их назначение просто, понятно и с пользой. Вы удивитесь, как быстро Jenkins из "непонятного инструмента" превратится в вашего мощного союзника.

![](https://ucarecdn.stepik.net/1dac0e37-4fd5-4778-8725-7760b61a5d05/)

Давайте начнем наше знакомство с самой верхней части экрана.

## **Верхняя панель навигации** 

Здесь собраны самые важные инструменты для глобальной навигации, поиска и управления системой.

![](https://ucarecdn.stepik.net/6156517b-72c7-4816-94b3-ae34c464c9ec/)

### **1. Логотип Jenkins**

- **Что это?** Главный заголовок и кнопка "домой". Один клик по логотипу или названию всегда вернет вас на главную страницу (Dashboard) из любого раздела.
- **Контекст видимости**: Виден всегда.

### **2. Иконка Поиска** ![](https://ucarecdn.stepik.net/5687c872-3892-405c-8056-0fcc2e39d5b1/)

- **Что это?** Моментальный поиск по всем объектам Jenkins: задачам (jobs), папкам, пользователям и другим сущностям.
- **Как применить?** Начните вводить название, и Jenkins в реальном времени покажет совпадения. Это особенно удобно, когда в системе сотни проектов.
- **Лайфхак**: Используйте горячие клавиши **`CTRL + K`** (или `CMD + K`), чтобы мгновенно активировать поиск, не отрывая рук от клавиатуры.

### **3. Manage Jenkins (Управление Jenkins)** ![](https://ucarecdn.stepik.net/df650253-88f5-49bd-8798-26aa85f90304/)

- **Что это?** Ссылка на "мозг" всей системы, доступная только администраторам.
- **Как применить?** Отсюда управляют всей инфраструктурой CI/CD: устанавливают плагины, настраивают безопасность, подключают агентов сборки и конфигурируют системные утилиты.
- **Контекст видимости**: Виден **только администраторам**.

### **4. Профиль пользователя** ![](https://ucarecdn.stepik.net/10a708be-c833-4336-8f43-a930a628276d/)

- **Что это?** Меню для управления вашим профилем.
- **Как применить?** Здесь можно изменить личные настройки (например, пароль или API-токен) и выйти из системы (Log out).
- **Контекст видимости**: Появляется **только** после входа в систему.

### **5. Add description (Добавить описание)**

![](https://ucarecdn.stepik.net/9c83af7a-dcb4-4ba5-9756-f87a13ae65bf/)

- **Что это?** Возможность добавить текстовое описание для текущего представления (View), которое увидят все пользователи.
- **Лайфхак**: Используйте эту функцию, чтобы оставить полезную информацию для команды: ссылки на документацию, контакты ответственных или краткое назначение дашборда.
- **Контекст видимости**: Доступна **только пользователям с правами на редактирование View**.

## **Основная рабочая область**

Это центральная часть экрана, где вы будете создавать задачи и организовывать рабочее пространство.

### **Боковая панель**

Слева расположена панель, которая дает полное представление о состоянии сборок и загрузке системы в реальном времени.

![](https://ucarecdn.stepik.net/003c87af-c358-4931-9451-0af47123d787/)

### **6. New Item (Создать элемент)** ![](https://ucarecdn.stepik.net/71d441fe-fdfb-4f42-9456-20585675b86e/)

- **Что это?** Ключевая кнопка для создания новых объектов это может быть задача (job), папка для их организации или сложный Pipeline.
- **Как применить?** После нажатия Jenkins предложит выбрать тип элемента и задать ему имя. Это отправная точка для любой автоматизации.
- **Контекст видимости**: Виден, если у вас есть права на создание заданий.

### **7. Build History (История сборок)** ![](https://ucarecdn.stepik.net/6af240d8-45e2-4405-b9e1-00d3da93d06e/)

- **Что это?** Хроника всех недавно завершенных сборок в системе.
- **Как применить?** Позволяет быстро оценить результаты последних запусков: увидеть статус (успех/неудача), время выполнения и перейти к деталям любой сборки.

### **8. Build Queue (Очередь сборок)**

![](https://ucarecdn.stepik.net/96f0c643-11a0-4f34-bf77-aa1688bdc39d/)

- **Что это?** Список заданий, которые ожидают своей очереди на выполнение.
- **Почему это важно?** Если задания скапливаются здесь, это сигнал: все исполнители (executors) заняты. Если очередь постоянно переполнена, стоит задуматься о добавлении новых агентов сборки.

### **9. Build Executor Status (Статус исполнителей)**

![](https://ucarecdn.stepik.net/c15cbbc9-613e-44be-92bb-9017cdc9f579/)

- **Что это?** Индикатор загрузки Jenkins. Показывает, сколько "слотов" для выполнения задач (executors) занято, а сколько свободно (например, `1/2` означает, что занят один из двух).
- **Почему это важно?** Помогает визуально оценить текущую нагрузку на master-узел или агенты. По умолчанию на master-узле сконфигурировано 2 исполнителя.

### **10. Приветственное сообщение "Welcome to Jenkins!"**

- **Что это?** Стартовый экран, который вы видите в пустом проекте. Он подсказывает, с чего начать.
- **Контекст видимости**: Отображается, **пока в текущем представлении (View) нет ни одной задачи**. Исчезает, как только вы создадите первый элемент.

![](https://ucarecdn.stepik.net/293eb367-cb14-4317-889f-ada621be1a7a/)

## **Нижняя панель - Техническая информация**

В самом низу страницы находятся полезные ссылки для продвинутых пользователей и администраторов.

![](https://ucarecdn.stepik.net/41df5308-be44-4ad2-953e-27b5013174ae/)

#### **11. REST API**

- **Что это?** Ссылка на встроенную документацию по REST API.
- **Зачем это нужно?** Jenkins можно управлять не только через веб-интерфейс, но и программно. Через API можно запускать сборки, получать их статусы и интегрировать Jenkins с другими системами.

#### **12. Версия Jenkins**

- **Что это?** Отображение текущей установленной версии Jenkins (например, `2.528.1`).
- **Зачем это нужно?** Эта информация критически важна для администраторов при диагностике проблем, поиске совместимых плагинов и планировании обновлений.
