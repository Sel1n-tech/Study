### Шаг 5. Некоторые рекомендации по работе с VS Code (Настройка на PIP8)

Некоторые ошибки в программе будут прописаны в разделе **PROBLEMS** (в следующем случае мы специально удалили закрывающую скобку, что является синтаксической ошибкой в Python).

![](https://ucarecdn.stepik.net/d36455a4-603e-4e3a-ae77-7b83c32084f4/)

Такое возможно благодаря плагину Pylance, который был автоматически установлен вместе с расширением Python.

![](https://ucarecdn.stepik.net/17b203f6-fbd6-4b4a-8410-b8a4b1875d37/)

В разделе **Settings** (настройки) можно включить автосохранение программы. Программа будет автоматически сохраняться спустя некоторое время. Для этого с помощью сочетания клавиш **Ctrl** + **,** переходим в **Settings** (также в настройки можно перейти через **File** -> **Preferences** -> **Settings**). Печатаем **auto save** и находим нужную настройку.

![](https://ucarecdn.stepik.net/1731f667-54e1-4a2c-ba43-f83226191885/)

В открывшемся окне выбираем пункт afterDelay.

![](https://ucarecdn.stepik.net/aced0b52-ad2a-4dc2-965e-0010ee5439ea/)

Автоформатирование программы можно включить также в разделе **Settings**​​​. Это очень удобная и полезная функция. Ваш файл будет автоматически форматироваться по стандартам PEP8 (официальный стандарт написания кода на языке Python). Для этого печатаем в настройках **format on save** и находим нужную настройку:

![](https://ucarecdn.stepik.net/713433ef-2e16-49be-ab70-030c78ed3a1c/)

Ставим галочку:

![](https://ucarecdn.stepik.net/78082461-11af-486d-82c8-d888c752545a/)

Вернемся к файлу с нашей программой. При нажатии сочетания клавиш **Ctrl** + **S** у нас выскочит окошко, что IDE хочет отформатировать файл. Нажимаем на клавишу **Black**:

![](https://ucarecdn.stepik.net/69e0d9c3-83c4-451b-898b-4f9267877d20/)

Через несколько секунд у нас автоматически установится форматер Black.

Если же у вас такое окно не появилось, придется установить форматер вручную. Это можно сделать через вкладку **Extensions**, введя в строку поиска **black formatter**:

![](https://ucarecdn.stepik.net/1ec8fe86-98b4-4c6d-930e-d9a8864d1d79/)

Или это можно сделать через командную строку. Чтобы попасть в командную строку, нужно использовать клавиш **Win** + **R**, в появившемся окне "**Выполнить**" ввести команду **cmd** и нажать **Enter**. После этого скачаем форматер следующей командой: `pip install black`.

Теперь наша программа будет форматироваться каждый раз после нажатия сочетания **Ctrl** + **S** (возможно, придётся перезапустить программу VS Code для работы автоформатера). Учитывайте, что программа будет форматироваться только при отсутствии синтаксических ошибок.

### Тема оформления
Изменить тему оформления в VS Code также возможно (если хотите, чтобы всё было красиво и приятно для глаз). Ищем в настройках **color theme**. И в этой настройке выбираем т
у тему, которая вам понравится больше. Темы менять также можно через шестеренку в левом нижнем углу ![](https://ucarecdn.stepik.net/8ea9f47a-3cee-4cea-b0c0-02c8509b8bcb/) -> **Themes** -> **Color Theme**. И дальше клавишами вверх-вниз листать (тема будет меняться на ходу, так что можно будет посмотреть все сразу).

![](https://ucarecdn.stepik.net/b8a7ff9f-e065-4846-84d1-086de9a2c731/)

Изменить размер иконок в самой VS Code можно с помощью **Ctrl** **+** (увеличение) и **Ctrl** **-** (уменьшение).

В VS Code есть ещё очень много интересного. Можете поискать сами какие-нибудь классные расширения или удобные настройки.
