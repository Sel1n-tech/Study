## Введение

Вы уже умеете сравнивать числа и проверять существование файлов с помощью команды `test` или `[ ]`. Но часто нужно работать со строками — проверять, равны ли две строки, или пуста ли переменная, или какая из них больше. Это особенно важно при обработке пользовательского ввода, имён файлов или данных из конфигурационных файлов.

Урок поможет вам:

- Понять, как сравнивать строки на равенство и неравенство.
- Использовать операторы `<` и `>` для сравнения порядка строк.
- Проверять, пуста ли строка или содержит данные.
- Избегать распространённых ошибок при работе со строками.

## Операторы сравнения строк

Команда `test` (или `[ ]`) позволяет сравнивать строки с помощью следующих операторов:

|Оператор|Описание|
|---|---|
|`str1 = str2`|Проверяет, равны ли строки (обратите внимание: один знак `=`)|
|`str1 != str2`|Проверяет, не равны ли строки|
|`str1 < str2`|Проверяет, меньше ли `str1` чем `str2` (по ASCII-порядку)|
|`str1 > str2`|Проверяет, больше ли `str1` чем `str2` (по ASCII-порядку)|
|`-n str`|Проверяет, что строка **не пустая** (длина > 0)|
|`-z str`|Проверяет, что строка **пустая** (длина = 0)|

Всегда оборачивайте переменные в двойные кавычки: `"$var"` — это предотвращает ошибки при пустых значениях или значениях с пробелами.

Файл `check_user.sh`:

if [ "$USER" = "$testuser" ]

## Сравнение порядка строк (`<` и `>`)

Это самая сложная часть. Операторы `<` и `>` в Bash **не такие, как в математике**. Они сравнивают строки по **ASCII-порядку** — то есть по кодам символов.

### Символы `<` и `>` интерпретируются как перенаправление

Если вы просто напишете `[ $val1 > $val2 ]`, Bash подумает, что вы хотите записать вывод в файл `$val2`.

**Ошибка:**

```bash
val1="baseball"
val2="hockey"
if [ $val1 > $val2 ]; then
    echo "$val1 больше $val2"
fi
```

Создастся файл `hockey` и скрипт выведет "baseball больше hockey", хотя это неверно.

![](https://ucarecdn.stepik.net/b94e54b5-9f3c-4b53-bde6-632fa31bacbf/)

### Решение: экранировать символы

Используйте обратный слэш `\` перед символами `<` и `>`.

**Правильно:**

```bash
val1="baseball"
val2="hockey"
if [ "$val1" \> "$val2" ]; then
    echo "$val1 больше $val2"
else
    echo "$val1 меньше $val2"
fi
```

![](https://ucarecdn.stepik.net/607691db-a77f-410d-832d-2b21cd909b48/)

Теперь результат правильный: в ASCII `'b'` (98) меньше `'h'` (104).

## ASCII-порядок и регистр букв

### Верхний и нижний регистр

В ASCII-порядке **заглавные буквы идут раньше строчных**. То есть `'A'` (65) меньше `'a'` (97). Это может быть неожиданным, если вы привыкли к алфавитному порядку, где `'a'` идёт первым.

**Пример:**

```bash
val1="Testing"
val2="testing"
if [ "$val1" \> "$val2" ]; then
    echo "$val1 больше $val2"
else
    echo "$val1 меньше $val2"
fi
```

![](https://ucarecdn.stepik.net/ef89059a-489b-44c5-a0ee-ccc7e74c329c/)

Почему? Потому что `'T'` (84) меньше `'t'` (116).

Если вам нужен "естественный" алфавитный порядок, используйте команду `sort` — она учитывает локальную настройку системы.

## Проверка длины строки — `-n` и `-z`

Часто нужно проверить, содержит ли переменная данные или она пуста.

### Операторы:

- `-n str` → `true`, если строка **не пустая**.
- `-z str` → `true`, если строка **пустая**.

### Проверка ввода

Файл `check_input.sh`:

```bash
#!/bin/bash
# Проверяем, ввёл ли пользователь данные

input="Привет!"

if [ -n "$input" ]; then
    echo "Вы ввели: '$input'"
else
    echo "Вы ничего не ввели."
fi

empty=""
if [ -z "$empty" ]; then
    echo "Переменная 'empty' пуста."
fi
```

Это полезно для проверки обязательных аргументов или пользовательского ввода.

## Практическое задание: создайте скрипт «Проверка пароля»

### Цель:

Написать скрипт `password_check.sh`, который:

1. Запрашивает у пользователя пароль (можно использовать `read` или передать как аргумент).
2. Проверяет:
    - Если пароль пуст — выводит "Пароль не может быть пустым".
    - Если пароль равен "secret" — выводит "Доступ разрешён".
    - Если пароль не равен "secret" — выводит "Неверный пароль".
3. Использует операторы `-z`, `=`, `!=`.

### Инструкция:

1. Создайте файл `password_check.sh`.
2. Добавьте shebang `#!/bin/bash`.
3. Получите пароль через `read` или аргумент `$1`.
4. Используйте `if [ -z "$password" ]`, `if [ "$password" = "secret" ]`, `if [ "$password" != "secret" ]`.
5. Сохраните, дайте права: `chmod u+x password_check.sh`.
6. Запустите: `./password_check.sh secret` или `./password_check.sh`.

### Пример решения:

```bash
#!/bin/bash
# Проверка пароля

if [ $# -eq 0 ]; then
    echo "Введите пароль:"
    read password
else
    password="$1"
fi

if [ -z "$password" ]; then
    echo "Пароль не может быть пустым."
elif [ "$password" = "secret" ]; then
    echo "Доступ разрешён."
else
    echo "Неверный пароль."
fi
```
