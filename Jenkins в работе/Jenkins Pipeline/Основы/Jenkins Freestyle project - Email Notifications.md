> **Зачем в Jenkins используют уведомления по электронной почте и как это вам поможет в работе?**
> 
>   
> Jenkins Email Notifications используются для отправки уведомлений о различных событиях, связанных с работой Jenkins. Например, при запуске сборки проекта, изменении статуса сборки, завершении сборки или возникновении ошибки.
> 
> Отправка уведомлений по электронной почте позволяет администраторам Jenkins получать информацию о состоянии системы и быстро реагировать на возникающие проблемы. Также это может помочь в улучшении коммуникации между разработчиками и администраторами Jenkins.

# Уведомления по электронной почте

Для настройки электронной почты, перейдите **Manage Jenkins > Configure System**

1. Проверьте установлена ли почта администратора Jenkins:

![](https://ucarecdn.stepik.net/00455840-8ade-4228-8a21-91d65d78414a/)

###  Настройки секции E-mail Notification (Уведомление по электронной почте)

![](https://ucarecdn.stepik.net/b2b35cbe-f7c2-4551-823e-35b0b57469b6/)

- **SMTP-server** по умолчанию будет использовать сервер localhost, если это поле оставить пустым 
- **SMTP Port** при использовании SSL порт будет по умолчанию 465; в противном случае значение по умолчанию равно 25
- **Reply-To-Address** поле Адрес для ответа здесь не является обязательным

### Настройки секции Extended E-mail Notification (Расширенные уведомления по электронной почте )

Обратите внимание что в дополнение к основным настройкам электронной почты есть так же и расширенные настройки, которые могут добавить множество дополнительных конфигураций для отправки электронной почты через Jenkins.

Вам нужно найти секцию **Extended E-mail Notification**

![](https://ucarecdn.stepik.net/5396f331-fcbf-464e-b662-0e1291d75547/)
