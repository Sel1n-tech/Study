### **Постфиксный инкремент**

Также можно с **постфиксным инкрементом** `x++` рассмотреть такой пример:

```java
int x = 5
println(x++)   // значение x до инкремента
println(x)     // значение x после инкремента
```

выполняет следующие действия:

1. Создаёт переменную `x` и присваивает ей значение 5.
    
2. Выводит значение `x` на экран с помощью метода `println`.
    
3. Увеличивает значение `x` на 1 с помощью оператора инкремента `x**++**`. Обратите внимание ++ стоят после переменной
    
4. Снова выводит значение `x` на экран.
    

В результате выполнения этого кода на экран будет выведено:

- **5** — распечает значение `x` до выполнения инкремента;
- **6** — распечает значение `x` после инкремента.

### **Префиксный инкремент**

Тот же пример что и выше, но уже в префиксной формой `++x`:

```java
int x = 5
println(++x)
println(x)
```

**Префиксный инкремент** выполняет следующие действия:

1. Создаёт переменную `x` и присваивает ей значение 5.
    
2. Увеличивает значение `x` на 1 с помощью оператора инкремента `**++**x`. Обратите внимание ++ стоит перед переменной
    
3. Выводит значение `x` на экран с помощью метода `println`.
    
4. Снова выводит значение `x` на экран.
    

В результате выполнения этого кода на экран будет выведено:

- **6** — распечатает значение `x` после инкремента;
- **6** — значение `x` после повторного вывода.

В Groovy оператор += используется для увеличения значения переменной на определённое число. Он добавляет значение правого операнда к левому операнду и присваивает результат левому операнду.

Пример использования оператора **+=:**

```go
def x = 5
x += 3
println(x)
```

- _В этом примере значение переменной `x` равно **5**._
- _Затем мы используем оператор `+=` для добавления **3** к `x` и присваивания значения переменной `x`._
- _В результате выполнения программы на экран будет выведено значение **8**_

> Таким образом, оператор `+=` изменяет значение левого операнда.

Этот же пример, но с использованием двух переменных `**x**` и `**y**`:

```java
int x = 5 // Создаётся переменная x и ей присваивается значение 5.
int y = 19 // Создаётся переменная y и ей присваивается значение 19.
println("x += y, result: " +  (x += y) ) 
/*
  Происходит сложение значений переменных x и y. 
  Результат сложения присваивается переменной x. 
  Также происходит вывод результата сложения на экран.
*/
println("x: $x") // Происходит вывод значения переменной x на экран.
println("y: $y") // Происходит вывод значения переменной y на экран.
```

## **Логические операторы** 

Groovy предлагает три логических оператора для логических выражений:

- &&: логическое "и"
    
- ||: логическое "или"
    
- !: логическое "не"
    

Проиллюстрируем их следующими примерами:

assert !false            "не" ложно верно

assert true && true правда "и" правда правда

assert true || false   истина "или" ложь верно

![](https://ucarecdn.stepik.net/34e6116c-4317-474b-813b-f42a1139a48c/)

Логический || оператор поддерживает короткое замыкание: если левый операнд истинен, он знает, что результат будет истинным в любом случае, поэтому он не будет оценивать правый операнд. Правый операнд будет оцениваться, только если левый операнд ложен.

То же самое и с логическим && оператором: если левый операнд ложен, он знает, что результат будет ложным в любом случае, поэтому он не будет оценивать правый операнд. Правый операнд будет оцениваться, только если левый операнд истинен.

Логическое «не» имеет более высокий приоритет, чем логическое «и».

Логическое «и» имеет более высокий приоритет, чем логическое «или».

![](https://lh4.googleusercontent.com/E7wsCYJdFKfGr4GxIUdcXqVQWsOcKBjoi_DOkHDmnZzgO_PAEUVhNVl5c2TfJQHbu_C7I7P8x7ww0jl6S1MKsyU9o-WWR16FR84stiFM13ntLY6XAJx_-8dpvpk4cAPIa-ZXf6vTHxm3ifeoxueQKA)

```go
println !false
println true && true
println true || false
```

Output:

```bash
true
true
true
```

## **Побитовые операторы**

**Бит** — минимальная единица измерения информации в компьютере. Его название происходит от английского “binary digit” — "двоичное число". Бит может быть выражен одним из двух чисел: 1 или 0.

Когда у вас есть двоичное число, т.е отдельные биты — нули и единицы. Именно с ними мы можем выполнять операции, которые называются побитовыми.

Groovy предлагает четыре побитовых оператора:

![](https://ucarecdn.stepik.net/7ced981a-e6f3-4f3c-90f5-60eaf0029e98/)

Битовые операторы могут быть применены на аргументы , которые типа byte, short, int, long, или BigInteger.

В Groovy побитовые операторы являются перегружаемыми , что означает, что вы можете определять поведение этих операторов для любого типа объекта.
