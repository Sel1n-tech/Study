## Введение

Вы уже умеете перенаправлять вывод команд в файлы, а ошибки — в отдельные файлы. Но что, если нужно **полностью подавить** весь вывод — например, при запуске скрипта в фоновом режиме? Или создать временный файл, который автоматически удалится после завершения работы?

Для этого в Linux есть два мощных инструмента:

- **Файл `/dev/null`** — «черная дыра», куда можно отправить любой вывод, чтобы он исчез.
- **Команда `mktemp`** — для создания уникальных временных файлов и директорий.

Этот урок поможет вам:

- Понять, как работает файл `/dev/null`.
- Подавлять вывод и ошибки с помощью `/dev/null`.
- Создавать временные файлы и директории с помощью `mktemp`.
- Автоматически удалять временные файлы после завершения работы.

## Подавление вывода с помощью `/dev/null`

### Что это такое?

Файл `/dev/null` — это специальный файл, который **принимает любые данные, но не хранит их**.

Любые данные, записанные в `/dev/null`, просто исчезают.

Это идеально подходит для подавления вывода команд — особенно полезно при работе в фоновом режиме.

### Подавление обычного вывода

Файл `suppress_output.sh`:

```bash
#!/bin/bash
# Подавляем обычный вывод

echo "Это сообщение будет подавлено." > /dev/null
echo "Это сообщение будет на экране."
```

Сообщение, записанное в `/dev/null`, не отображается на экране.

### Подавление ошибок

Файл `suppress_errors.sh`:

```bash
#!/bin/bash
# Подавляем ошибки

ls -l badfile.txt 2> /dev/null
echo "Ошибки подавлены. Скрипт продолжает работу."
```

![](https://ucarecdn.stepik.net/1b397370-0949-4b26-9b61-b007ab7f354f/)

Ошибка `ls: cannot access 'badfile.txt'` не отображается на экране.

### Подавление всего вывода (и ошибок)

Файл `suppress_all.sh`:

```bash
#!/bin/bash
# Подавляем всё

echo "Это сообщение исчезнет." > /dev/null
ls -l badfile.txt 2> /dev/null
echo "Всё подавлено. Ничего не видно."
```

Оба сообщения — и обычный вывод, и ошибка — подавлены.

## Создание временных файлов с помощью `mktemp`

### Что это такое?

Команда `mktemp` создаёт **уникальный временный файл** или директорию. Она гарантирует, что имя файла будет уникальным, чтобы избежать конфликтов.

### Синтаксис:

```bash
mktemp [опции] шаблон
```

Шаблон должен заканчиваться шестью буквами `X` — `mktemp` заменит их на случайные символы.

### Создание временного файла

Файл `create_temp_file.sh`:

```bash
#!/bin/bash
# Создаем временный файл

tempfile=$(mktemp temp.XXXXXX)
echo "Временный файл создан: $tempfile"
echo "Это тестовое содержимое." > "$tempfile"
cat "$tempfile"
rm "$tempfile"  # Удаляем файл
echo "Временный файл удалён."
```

![](https://ucarecdn.stepik.net/66936c62-8ad1-4f2b-a691-664ef0d80b5d/)

Файл был создан, использован и удалён.

## Создание временного файла в `/tmp`

По умолчанию `mktemp` создаёт файл в текущей директории.

Чтобы создать файл в системной директории `/tmp`, используйте опцию `-t`.

### \Создание временного файла в `/tmp`

Файл `create_temp_in_tmp.sh`:

```bash
#!/bin/bash
# Создаем временный файл в /tmp

tempfile=$(mktemp -t temp.XXXXXX)
echo "Временный файл создан в /tmp: $tempfile"
echo "Это тестовое содержимое." > "$tempfile"
cat "$tempfile"
rm "$tempfile"
echo "Временный файл удалён."
```

![](https://ucarecdn.stepik.net/74031d3b-fd29-43eb-8c25-7c84aa2b6b9a/)

Файл был создан в `/tmp` — это стандартное место для временных файлов.

## Практическое задание: создайте скрипт «Обработка данных с временным файлом»

### Цель:

Написать скрипт `process_data.sh`, который:

1. Создаёт временный файл в `/tmp`.
2. Записывает в него список файлов в текущей директории.
3. Читает содержимое временного файла и выводит его на экран.
4. Удаляет временный файл.
5. В конце выводит сообщение об успешном завершении.

### Инструкция:

1. Создайте файл `process_data.sh`.
2. Добавьте shebang `#!/bin/bash`.
3. Используйте `mktemp -t data.XXXXXX` для создания временного файла.
4. Используйте `ls -l > "$tempfile"` для записи списка файлов.
5. Используйте `cat "$tempfile"` для вывода содержимого.
6. Используйте `rm "$tempfile"` для удаления файла.
7. Сохраните, дайте права: `chmod u+x process_data.sh`.
8. Запустите: `./process_data.sh`.

### Пример решения:

```bash
#!/bin/bash
# Обработка данных с временным файлом

# Создаем временный файл
tempfile=$(mktemp -t data.XXXXXX)
echo "Временный файл создан: $tempfile"

# Записываем список файлов
ls -l > "$tempfile"

# Выводим содержимое
echo ""
echo "=== Содержимое временного файла ==="
cat "$tempfile"

# Удаляем временный файл
rm "$tempfile"
echo ""
echo "Временный файл удалён. Обработка завершена."
```
