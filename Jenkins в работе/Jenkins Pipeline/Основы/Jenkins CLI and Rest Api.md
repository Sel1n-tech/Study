**Jenkins CLI (Command Line Interface)** - это утилита командной строки для управления Jenkins. Она позволяет выполнять различные действия, такие как запуск задач, настройка параметров, управление пользователями и многое другое. Jenkins CLI использует Java-based API и может быть использована на любой платформе, поддерживающей Java.

Jenkins CLI может быть полезен в следующих ситуациях:

- Настройка параметров Jenkins: Jenkins CLI позволяет пользователям быстро и удобно изменять настройки сервера, такие как настройки плагинов, конфигурации задач и т.д. Это может быть полезно, если нужно быстро настроить сервер для выполнения определенных задач.
- Запуск скриптов: Jenkins CLI может использоваться для запуска скриптов на сервере Jenkins. Это позволяет автоматизировать выполнение задач, таких как сборка проектов, тестирование и развертывание приложений.
- Управление задачами: Jenkins CLI позволяет создавать, запускать и управлять задачами на сервере Jenkins. Пользователи могут создавать новые задачи, изменять их параметры и запускать их в заданное время.
- Отладка: Jenkins CLI предоставляет возможность отлаживать задачи на сервере, что может быть полезно при разработке новых плагинов или при устранении неполадок в работе сервера.
- Управление пользователями и группами: Jenkins CLI позволяет управлять пользователями и группами на сервере Jenkins, включая создание новых пользователей, изменение их прав доступа и т.д.

**Jenkins REST API (Representational State Transfer)** - это набор веб-сервисов, которые позволяют взаимодействовать с Jenkins-сервером через HTTP-запросы. Он предоставляет доступ к различным функциональностям Jenkins, таким как запуск задач, управление проектами, настройка плагинов и т.д. REST API основан на стандарте HTTP и может использоваться для автоматизации процессов, интеграции с другими системами и создания скриптов для автоматизации задач.

Использование REST API в Jenkins может быть полезно в следующих случаях:

- **Автоматизация задач:** Jenkins REST API может использоваться для автоматизации различных задач, таких как создание новых проектов, запуск тестов, отправка уведомлений и т.д.
- **Интеграция с другими системами:** REST API позволяет интегрировать Jenkins с другими системами, такими как системы контроля версий, системы управления задачами и т.д., что упрощает работу с Jenkins.
- **Создание скриптов**: Jenkins REST API можно использовать для создания скриптов на различных языках программирования, которые могут автоматизировать различные задачи в Jenkins.
- **Мониторинг Jenkins:** c помощью Jenkins REST API можно получать информацию о состоянии Jenkins и его компонентов, что позволяет мониторить работу Jenkins и принимать меры при необходимости.
- **Разработка плагинов:** Jenkins REST API также может использоваться при разработке плагинов для Jenkins, чтобы обеспечить более гибкую и удобную интеграцию с другими системами

## Примеры:

- **Информация справочная для  Jenkins API**
    
    - http://<jenkins host>/api/
        
- **Получить информацию в формате json**
    
    - http://<jenkins host>/api/json?pretty=true
        
- **Сделать фильтры по name, color, url**
    
    - http://<host>/api/json?pretty=true&tree=jobs[name,color, url]
        
- **Получить информацию о конкретной сборке**
    
    - http://<host>/job/<JOB_NAME>/api/json?pretty=true
