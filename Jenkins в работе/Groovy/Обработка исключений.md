Исключение - это нештатная ситуация, ошибка во время выполнения программы. К примеру деление на ноль. Обработка исключений обычно есть в том или ином виде на любом языке программирования. Исключение обычно нарушает нормальный поток приложения, поэтому нам нужно использовать обработку исключений. В Groovy обработка исключений такая же, как в Java.

## try / catch / finally

Существует пять ключевых слов, используемых в исключениях: **try**, **catch**, **throw**, **throws**, **finally**.

Порядок обработки исключений следующий:

1. Инструкции программы, которые вы хотите отслеживать на предмет возникновения исключений, помещаются в блок try.
2. Если исключение произошло, то оно передаётся дальше. 
3. Перехват исключения можно выполнить при помощи блока **catch** и обработать его.

Так же следует учесть следующие моменты:

- Чтобы передать исключение вручную, используется **throw**.
- Любое исключение, созданное и передаваемое внутри метода, должно быть указано в его интерфейсе ключевым словом **throws**. 
- Любой код, который следует выполнить обязательно после завершения блока **try**, помещается в блок **finally**
- Системные исключения автоматически передаются самим компилятором. 
- Компилятор не разрешит, чтобы обработки подклассов-исключений были ниже, чем catch для суперклассов.
- В блоке try-catch может быть больше одного catch.
- Если происходит исключение, выполняется код первого подходящего блока catch.
- Выполняется один catch, или не выполняется ни одного.  
     

Шпаргалка значений ключевых слов:

- **try** – блок кода, в котором может произойти исключение
- **catch** – блок кода, в котором происходит обработка исключения
- **finally** – блок кода, который является необязательным, но при его наличии выполняется в любом случае независимо от результатов выполнения блока **try**.
- **throw** – используется для возбуждения исключения
- **throws** – используется в сигнатуре методов для предупреждения, о том что метод может выбросить исключение.

Общий синтаксис такой:

```csharp
try {
    // тут отслеживаются ошибки
}
catch (type_exception_1 exceptionObj) {
    // обрабатываем Error1
}
catch (type_exception_2 exceptionObj) {
    // обрабатываем Error2
}
finally {
    // код, который будет выполнен всегда после завершения блока try
}
```

Вы можете указать полный набор блоков try-catch-finally, try-catch или try-finally.

Скобки { } необходимы вокруг тела каждого блока.

```java
try {
    println '0xb3'.toLong()   // это вызовет исключение
    println 'finished'        // эта точка никогда не должна быть достигнута
} catch ( e ) {
    println e
    println e.getMessage()
    println e.printStackTrace()
}
```

Мы можем поместить код в предложение **finally** после соответствующего предложения **try**, так что независимо от того, вызывает ли код в предложении **try** исключение, код в предложении **finally** всегда будет выполняться:

```java
def msg = 'empty'
try {
    def a = 5, b = 0
    try {
        def k = a / b
        println("never reached due")        
    } finally {
        msg = "It's ok"  //always executed even if Exception thrown
    }
} catch ( e ) {
    println(e) // java.lang.ArithmeticException: Division by zero
    println(msg) // It's ok
}
```
