**`git blame`** — это полезный инструмент для **поиска автора каждой строки** в файле и определения, когда эта строка была последний раз изменена.

Что показывает команда:

- **Хеш коммита** (a1b2c3d) — идентификатор изменения
- **Автор** (Ivan Petrov) — кто написал
- **Дата** (2024-01-15) — когда изменили
- **Строка** (1)) — номер строки
- **Код** — содержимое строки

## **Примеры**

```bash
# вызов справки по команде
git blame --help

# базовый пример использования команды
git blame css/styles.css

#получить email автора изменений
git blame css/styles.css -e

# вывод содержимого файла на экран (Linux-команда)
cat web_pages/index.html

# получить только коммиты, в которых изменения были в строках с 8 по 10
git blame web_pages/index.html -L 8,10

# получить только коммиты, в которых изменения были в конце файла с 8 строки
git blame web_pages/index.html -L 8

# получить только коммиты, в которых изменения были именно в 10 строке
git blame web_pages/index.html -L 10,10

# Игнорировать изменения пробелов (полезно, если коммит содержал только форматирование строк)
git blame -w index.html

# фильтрация по дате (since - 'начиная с')
git blame --since="3 weeks ago" index.html
git blame --since="2025.01.01" index.html
```

## Итоги

`git blame` — это не про обвинения, а про:

- ✅ **Понимание** кода
- ✅ **Поиск** авторов для вопросов
- ✅ **Анализ** истории изменений
- ✅ **Решение** проблем быстрее

Вы хотите узнать, кто написал строки 15-20 в файле `app.js`. Какая команда поможет это сделать? 
- git blame -L 15,20 app.js
