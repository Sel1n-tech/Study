## Введение

Вы уже умеете использовать циклы `for`, `while` и `until` для повторения команд. Но что, если вам нужно **выйти из цикла досрочно** или **пропустить текущую итерацию**? Для этого в Bash есть две полезные команды:

- **`break`** — прерывает выполнение цикла.
- **`continue`** — пропускает текущую итерацию и переходит к следующей.

Этот урок поможет вам:

- Понять, как работают команды `break` и `continue`.
- Использовать их в простых и вложенных циклах.
- Избежать распространённых ошибок при их использовании.
- Применять команды в реальных задачах.

## Команда `break`

### Что это такое?

Команда `break` позволяет **досрочно выйти из цикла**. Как только она выполняется, цикл прекращает работу, и управление передаётся следующей команде после `done`.

### Синтаксис:

```bash
break [n]
```

Без параметра `break` выходит из текущего (внутреннего) цикла. С параметром `n` — из `n`-го уровня вложенности.

### Выход из цикла при достижении условия

Файл `break_simple.sh`:

```bash
#!/bin/bash
# Выходим из цикла, когда счётчик равен 5

for i in {1..10}
do
    if [ $i -eq 5 ]; then
        echo "Достигнуто значение 5. Выходим из цикла."
        break
    fi
    echo "Итерация: $i"
done

echo "Цикл завершён."
```

Цикл остановился на значении 5, хотя список содержал числа до 10.

## Команда `continue`

### Что это такое?

Команда `continue` позволяет **пропустить текущую итерацию цикла** и перейти к следующей. Она не прерывает цикл, а просто «перепрыгивает» через текущий шаг.

### Синтаксис:

```bash
continue [n]
```

Без параметра `continue` пропускает текущую итерацию текущего цикла. С параметром `n` — пропускает итерацию на `n`-м уровне вложенности.

### Пропуск чётных чисел

Файл `continue_even.sh`:

```bash
#!/bin/bash
# Пропускаем чётные числа

for i in {1..10}
do
    if [ $((i % 2)) -eq 0 ]; then
        continue
    fi
    echo "Нечётное число: $i"
done
```

![](https://ucarecdn.stepik.net/4d81ad03-ad94-42e9-9ff3-3dbdebb22a21/)

Чётные числа (2, 4, 6, 8, 10) были пропущены.

## Работа с вложенными циклами

### Проблема:

В вложенных циклах `break` и `continue` по умолчанию действуют только на **внутренний цикл**. Иногда нужно выйти из внешнего цикла — для этого используется параметр `n`.

### Выход из внутреннего цикла

Файл `break_inner.sh`:

```bash
#!/bin/bash
# Выход из внутреннего цикла

for (( a=1; a<=3; a++ ))
do
    echo "Внешний цикл: $a"
    for (( b=1; b<=5; b++ ))
    do
        if [ $b -eq 3 ]; then
            echo "  Достигнуто значение 3 во внутреннем цикле. Выходим из него."
            break
        fi
        echo "  Внутренний цикл: $b"
    done
done
```

![](https://ucarecdn.stepik.net/e48cba8b-4b93-457e-a30a-fc2a8cdbbfb5/)

Внутренний цикл останавливается на значении 3, но внешний продолжает работу.

## Выход из внешнего цикла

Чтобы выйти из внешнего цикла изнутри внутреннего, используйте `break 2` (где `2` — уровень вложенности).

### Выход из внешнего цикла

Файл `break_outer.sh`:

```bash
#!/bin/bash
# Выход из внешнего цикла

for (( a=1; a<=3; a++ ))
do
    echo "Внешний цикл: $a"
    for (( b=1; b<=5; b++ ))
    do
        if [ $b -eq 3 ] && [ $a -eq 2 ]; then
            echo "  Достигнуто значение 3 во внутреннем цикле и 2 во внешнем. Выходим из обоих циклов."
            break 2
        fi
        echo "  Внутренний цикл: $b"
    done
done

echo "Циклы завершены."
```

![](https://ucarecdn.stepik.net/a9e53b08-2794-4df2-8587-f9bef33141be/)

Циклы остановились, когда было достигнуто условие `b=3` и `a=2`.

## Практическое задание: создайте скрипт «Поиск элемента»

### Цель:

Написать скрипт `find_element.sh`, который:

1. Принимает список чисел как аргументы (`$@`).
2. Запрашивает у пользователя число для поиска.
3. Перебирает список чисел.
4. Если число найдено — выводит его позицию и выходит из цикла.
5. Если число не найдено — выводит сообщение об этом.

### Инструкция:

1. Создайте файл `find_element.sh`.
2. Добавьте shebang `#!/bin/bash`.
3. Проверьте, что аргументы переданы: `if [ $# -eq 0 ]; then ... exit 1; fi`.
4. Запросите число для поиска: `read target`.
5. Используйте `for` для перебора аргументов.
6. Используйте `break` для выхода из цикла при нахождении числа.
7. Сохраните, дайте права: `chmod u+x find_element.sh`.
8. Запустите: `./find_element.sh 10 20 30 40`.

### Пример решения:

```bash
#!/bin/bash
# Поиск элемента в списке

if [ $# -eq 0 ]; then
    echo "Использование: $0 <число1> <число2> ..."
    exit 1
fi

echo -n "Введите число для поиска: "
read target

found=false
position=0

for num in "$@"
do
    position=$((position + 1))
    if [ "$num" -eq "$target" ]; then
        echo "Число $target найдено на позиции $position."
        found=true
        break
    fi
done

if [ "$found" = false ]; then
    echo "Число $target не найдено в списке."
fi
```
