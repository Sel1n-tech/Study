## Введение

Вы уже умеете перехватывать сигналы с помощью команды `trap` — например, `SIGINT` (Ctrl+C) или `SIGTERM`. Но что, если нужно выполнить действия **перед завершением** скрипта — например, удалить временные файлы, закрыть соединения или вывести сообщение?

Для этого в Bash есть возможность перехватывать **завершение** скрипта с помощью сигнала `EXIT`.

Также важно уметь **изменять** или **удалять** обработчики сигналов — например, если вы хотите временно отключить обработку `Ctrl+C` во время критической операции.

Этот урок поможет вам:

- Понять, как перехватывать завершение скрипта.
- Научиться изменять и удалять обработчики сигналов.
- Создавать надёжные скрипты, которые корректно завершают работу и очищают ресурсы.

## Перехват завершения скрипта (`EXIT`)

### Что это такое?

Сигнал `EXIT` отправляется скрипту **перед его завершением** — независимо от того, как он завершился: нормально, по `exit`, или по сигналу.

Это идеально подходит для выполнения «очистки» перед завершением — например, удаления временных файлов.

### Перехват завершения

Файл `cleanup_on_exit.sh`:

```bash
#!/bin/bash
# Перехват завершения скрипта

# Создаём временный файл
touch temp.txt
echo "Временный файл temp.txt создан."

# Устанавливаем обработчик завершения
trap 'echo "Очистка: удаляем temp.txt"; rm temp.txt' EXIT

echo "Нажмите Ctrl+C или дождитесь окончания работы."
sleep 5
echo "Скрипт завершён нормально."
```

Файл `temp.txt` был удалён при завершении скрипта в обоих случаях.

### Перехват завершения при прерывании

Файл `cleanup_on_interrupt.sh`:

```bash
#!/bin/bash
# Перехват завершения при прерывании

touch temp.txt
echo "Временный файл temp.txt создан."

trap 'echo "Очистка: удаляем temp.txt"; rm temp.txt' EXIT

echo "Нажмите Ctrl+C для прерывания."
while true; do
    echo "Работаю..."
    sleep 1
done
```

## Изменение обработчиков сигналов

### Что это такое?

Вы можете изменить обработчик сигнала в любой момент скрипта — например, временно отключить обработку `Ctrl+C` во время критической операции.

### Изменение обработчика

Файл `modify_trap.sh`:

```bash
#!/bin/bash
# Изменение обработчика сигнала

cleanup() {
    echo "Очистка: удаляем temp.txt"
    rm temp.txt
}

# Устанавливаем первый обработчик
trap 'echo "Прерывание запрещено!"; exit 1' SIGINT

touch temp.txt
echo "Временный файл temp.txt создан."

echo "Нажмите Ctrl+C — прерывание запрещено."
sleep 3

# Изменяем обработчик
trap 'cleanup; echo "Скрипт завершён.";' SIGINT

echo "Теперь можно нажать Ctrl+C."
while true; do
    echo "Работаю..."
    sleep 1
done
```

## Удаление обработчиков сигналов

### Что это такое?

Если вы больше не хотите обрабатывать сигнал, можно вернуть его к стандартному поведению с помощью `trap --`.

### Удаление обработчика

Файл `remove_trap.sh`:

```bash
#!/bin/bash
# Удаление обработчика сигнала

touch temp.txt
echo "Временный файл temp.txt создан."

# Устанавливаем обработчик
trap 'echo "Очистка: удаляем temp.txt"; rm temp.txt' SIGINT

echo "Нажмите Ctrl+C — обработка включена."
sleep 3

# Удаляем обработчик
trap -- SIGINT
echo "Обработчик SIGINT удалён. Теперь Ctrl+C завершит скрипт."

while true; do
    echo "Работаю..."
    sleep 1
done
```

![](https://ucarecdn.stepik.net/210c362e-d463-4576-8eb5-aaab0c43db0d/)

После удаления обработчика `Ctrl+C` завершает скрипт без очистки.

Используйте `trap --` для возврата к стандартному поведению.

Также можно использовать `trap -` — это то же самое.

## Практическое задание: создайте скрипт «Безопасное копирование»

### Цель:

Написать скрипт `safe_copy.sh`, который:

1. Принимает два аргумента: исходный файл и целевой файл.
2. Копирует файл.
3. Устанавливает обработчик `EXIT` для удаления целевого файла в случае ошибки.
4. Устанавливает обработчик `SIGINT` для вывода сообщения и завершения работы.
5. При успешном завершении — удаляет обработчик `EXIT`.

### Инструкция:

1. Создайте файл `safe_copy.sh`.
2. Добавьте shebang `#!/bin/bash`.
3. Проверьте количество аргументов: `if [ $# -ne 2 ]; then ... exit 1; fi`.
4. Установите обработчик `EXIT` для удаления целевого файла.
5. Установите обработчик `SIGINT` для вывода сообщения.
6. Выполните копирование.
7. При успешном завершении — удалите обработчик `EXIT`.
8. Сохраните, дайте права: `chmod u+x safe_copy.sh`.
9. Запустите: `./safe_copy.sh source.txt destination.txt`.

### Пример решения:

```bash
#!/bin/bash
# Безопасное копирование

if [ $# -ne 2 ]; then
    echo "Использование: $0 <исходный_файл> <целевой_файл>"
    exit 1
fi

source="$1"
dest="$2"

# Устанавливаем обработчик EXIT для удаления целевого файла
trap 'echo "Ошибка: удаляем $dest"; rm "$dest" 2>/dev/null; exit 1' EXIT

# Устанавливаем обработчик SIGINT
trap 'echo "Прерывание: завершаем работу..."; exit 1' SIGINT

# Копируем файл
if cp "$source" "$dest"; then
    echo "Файл успешно скопирован: $dest"
    # Удаляем обработчик EXIT — теперь файл можно оставить
    trap -- EXIT
else
    echo "Ошибка при копировании."
    exit 1
fi
```
