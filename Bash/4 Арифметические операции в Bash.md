**Как складывать, умножать и даже делить с дробными числами в shell-скриптах**

## Введение

В большинстве языков программирования арифметика — дело простое: `a = 5 + 3.14`. В Bash же всё иначе. Базовые операции возможны, но с «подводными камнями»:

- Bash умеет работать **только с целыми числами**.
- Для дробных (вещественных) чисел нужен внешний инструмент — `bc`.
- Без правильного синтаксиса даже простое умножение вызывает ошибки.

Этот урок поможет вам уверенно выполнять математические операции в скриптах — от базовых вычислений до точных расчётов с дробями.

## Классика — `expr` (лучше знать, но не использовать)

В старых Unix-скриптах часто встречается команда `expr` — она выполняла арифметику в эпоху Bourne Shell.

### Пример:

```bash
expr 3 + 4
```

![](https://ucarecdn.stepik.net/da26ba6b-6b55-4f6b-88f1-4e516cca516c/)

### Почему `expr` неудобен?

**Требует пробелов вокруг операторов:**  
`expr 3+4` → ошибка.  
`expr 3 + 4` → правильно.

![](https://ucarecdn.stepik.net/43fa76e3-9c52-411f-8aef-55110f8cd1bb/)

**Многие символы конфликтуют с оболочкой** (например, `*`).

```bash
expr 5 * 2
```

![](https://ucarecdn.stepik.net/6f124377-1f0a-4360-97bf-0843bee00699/)Чтобы заставить работать — экранируйте (\).

**Для присваивания нужна подстановка команд:**

```bash
result=$(expr 10 + 5)
echo $result
```

![](https://ucarecdn.stepik.net/87b8ea8d-8a69-4f2e-ac7b-3514f26fb58f/)

`expr` остался для совместимости, но в современных скриптах его почти не используют.

## Современный способ — `$((...))`

Начиная с Bash 2.0 появился **встроенный арифметический интерпретатор**. Он работает проще, быстрее и без экранирования.

### Синтаксис:

```no-highlight
var=$((выражение))
```

или (старый, но тоже рабочий стиль):

```no-highlight
var=$[выражение]   # устаревшая форма — лучше не использовать
```

### Примеры:

```bash
a=10
b=3

sum=$((a + b))      # 13
diff=$((a - b))     # 7
prod=$((a * b))     # 30
quot=$((a / b))     # 3  ← обратите внимание: дробная часть отбрасывается!
rem=$((a % b))      # 1
```

![](https://ucarecdn.stepik.net/fe483503-dafa-4327-b59f-d91389556513/)

Bash не поддерживает дробные числа. При делении `10 / 3` получится `3`, а не `3.333`.

### Использование в скрипте:

```bash
#!/bin/bash
x=100
y=45
z=$((x * (y - 30)))
echo "Результат: $z"
```

![](https://ucarecdn.stepik.net/9c0a9629-63f6-4a3e-bbc0-8c42fb3a859d/)

**Преимущества `$((...))`:**

- Не требует экранирования `*`, `/`, `%`.
- Поддерживает скобки, переменные, унарные операторы (`++`, `--`, `-`).
- Встроен в оболочку — работает быстро.

## Дробные числа — `bc` (Bash Calculator)

Когда нужны **вещественные вычисления** (например, `3.14 * 2.5`), Bash обращается к утилите `bc`.

### Что такое `bc`?

Это отдельная программа — калькулятор с поддержкой:

- дробных чисел,
- переменных,
- функций (`sqrt`, `length`, `scale`),
- условий и циклов (но это уже продвинутый уровень).

### Простой запуск:

```bash
echo "3.14 * 2.5" | bc -l
```

![](https://ucarecdn.stepik.net/9e8fd71b-5ba9-4fad-88b2-894d6b50b73a/)

**Флаг `-l`** включает математическую библиотеку и устанавливает `scale=20` (20 знаков после запятой).

### Контроль точности: `scale`

По умолчанию `scale=0` — т.е. `bc` ведёт себя как Bash:

```bash
echo "7 / 3" | bc
```

![](https://ucarecdn.stepik.net/5d2d0459-512e-4f0b-a36f-1b3f992d1f13/)

С изменением `scale`:

```bash
echo "scale=4; 7 / 3" | bc
```

![](https://ucarecdn.stepik.net/1176fa83-3de0-4301-933d-ab7433751b7d/)

**`scale=N`** — задаёт количество цифр после запятой.

## Использование `bc` в скриптах

### Через `echo` и конвейер (подходит для коротких выражений)

```bash
#!/bin/bash
radius=5
pi=3.14159

# Площадь круга: S = π·r²
area=$(echo "scale=4; $pi * $radius * $radius" | bc)
echo "Площадь круга радиусом $radius: $area"
```

![](https://ucarecdn.stepik.net/20e0cb23-148d-4eeb-94ab-5cbbd4141cc0/)

Оборачивайте выражение в кавычки.

Используйте `$pi`, а не `pi` — это подстановка переменной из Bash.

Пробелы после `;` не обязательны, но улучшают читаемость.

### Here Document (лучше для сложных вычислений)

Если у вас много промежуточных вычислений — удобнее использовать **встроенный ввод**:

```bash
#!/bin/bash
a=2.5
b=4.3
c=1.8

result=$(bc << EOF
scale=5
x = $a + $b
y = x * $c
y / 2
EOF
)

echo "Итоговый результат: $result"
```

![](https://ucarecdn.stepik.net/41bdada5-3f44-45da-8568-fa7b25f84c5a/)

**Почему это удобно:**

- Можно определить промежуточные переменные (`x`, `y`).
- Легко читать и править.
- Не нужно управлять кавычками и экранированием.

## Практическое задание: «Финансовый калькулятор»

### Задача:

Написать скрипт `calc_interest.sh`, который:

1. Принимает исходную сумму (`principal`), процентную ставку (`rate`), срок в годах (`years`).
2. Рассчитывает **сложные проценты** по формуле:
    
    A=P⋅(1+r)nA=P⋅(1+r)n
    
    где:
    
    - AA — итоговая сумма,
    - PP — начальная сумма,
    - rr — ставка в долях (например, 5% = 0.05),
    - nn — число лет.
3. Выводит итог с точностью до 2 знаков после запятой.

### Подсказки:

- Используйте `bc`, потому что нужны возведение в степень (`^`) и дроби.
- В `bc` степень записывается как `^`.
- Установите `scale=2` в начале выражения.

### Пример решения:

```bash
#!/bin/bash
# Финансовый калькулятор: сложные проценты

principal=1000    # начальная сумма
rate=0.05         # 5% годовых
years=3           # срок

final=$(bc << EOF
scale=2
p = $principal
r = $rate
n = $years
a = p * (1 + r) ^ n
a
EOF
)

echo "Через $years года при ставке $(echo "$rate*100" | bc)% годовых:"
echo "$principal рублей → $final рублей "
```
