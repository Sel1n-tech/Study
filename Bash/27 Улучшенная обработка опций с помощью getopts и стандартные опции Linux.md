## Введение

Вы уже умеете использовать команду `getopt` для обработки опций командной строки. Но в современных системах есть ещё более мощный и удобный инструмент — встроенная команда **`getopts`** (обратите внимание: это `getopts`, а не `getopt`).

Кроме того, в Linux существуют **стандартные опции**, которые имеют общепринятые значения — например, `-h` для справки, `-v` для подробного вывода. Использование таких опций делает ваши скрипты более удобными и привычными для пользователей.

Этот урок поможет вам:

- Понять, как работает команда `getopts`.
- Использовать её для обработки опций в цикле.
- Обрабатывать опции с значениями и без них.
- Применять стандартные опции Linux в своих скриптах.

## Что такое `getopts`?

Команда `getopts` — это **встроенная** в Bash утилита для обработки опций командной строки. В отличие от `getopt`, она не создаёт новую строку, а **поочерёдно обрабатывает параметры** и сохраняет результат в переменных.

### Синтаксис:

```bash
getopts опция_строка переменная
```

`getopts` работает внутри цикла `while`, и при каждом вызове обрабатывает следующий параметр. Когда опции закончатся, он возвращает ненулевой код завершения.

## Формат опции-строки

Опция-строка (`optstring`) определяет, какие опции разрешены и требуют ли они значений.

|Символ|Значение|
|---|---|
|`a`|Опция `-a` без значения|
|`a:`|Опция `-a`, требующая значения (двоеточие после буквы)|

Если опция требует значения, `getopts` автоматически сохраняет его в переменную `OPTARG`.

## Пример использования `getopts`

### Простой обход опций

Файл `handle_options_getopts.sh`:

```bash
#!/bin/bash
# Обработка опций с помощью getopts

while getopts "abc" opt; do
    case "$opt" in
        a)
            echo "Найдена опция -a"
            ;;
        b)
            echo "Найдена опция -b"
            ;;
        c)
            echo "Найдена опция -c"
            ;;
        \?)
            echo "Неизвестная опция: -$OPTARG"
            ;;
    esac
done

echo ""
echo "Параметры:"
shift $((OPTIND-1))
for param in "$@"
do
    echo "  - $param"
done
```

## Обработка опций с значениями

Если опция требует значения, используйте двоеточие в опция-строке. Значение будет доступно в переменной `OPTARG`.

### Пример 2: Опция с значением

Файл `option_with_value.sh`:

```bash
#!/bin/bash
# Обработка опции с значением

while getopts "o:v" opt; do
    case "$opt" in
        o)
            output_file="$OPTARG"
            echo "Файл вывода: $output_file"
            ;;
        v)
            echo "Подробный вывод включён."
            ;;
        \?)
            echo "Неизвестная опция: -$OPTARG"
            ;;
    esac
done

echo ""
echo "Параметры:"
shift $((OPTIND-1))
for param in "$@"
do
    echo "  - $param"
done
```

## Стандартные опции Linux

В Linux существует набор **общепринятых опций**, которые имеют стандартное значение. Использование этих опций делает ваши скрипты более удобными и привычными для пользователей.

|Опция|Описание|
|---|---|
|`-a`|Показать все объекты|
|`-c`|Подсчитать количество|
|`-d`|Указать директорию|
|`-f`|Указать файл для чтения|
|`-h`|Показать справку|
|`-q`|Работать в тихом режиме|
|`-r`|Рекурсивно обрабатывать директории|
|`-v`|Выводить подробную информацию|
|`-y`|Автоматически отвечать «да» на все вопросы|

Используйте эти опции в своих скриптах — это сделает их более дружелюбными к пользователям.

## Практическое задание: создайте скрипт «Умный файловый менеджер»

### Цель:

Написать скрипт `file_manager.sh`, который:

1. Принимает опции:
    - `-h` — выводит справку.
    - `-v` — включает подробный вывод.
    - `-d <dir>` — указывает директорию для обработки.
    - `-r` — рекурсивно обрабатывает поддиректории.
2. После опций обрабатывает оставшиеся параметры как имена файлов.
3. Выводит список файлов и директорий.

### Инструкция:

1. Создайте файл `file_manager.sh`.
2. Добавьте shebang `#!/bin/bash`.
3. Используйте `getopts` для обработки опций.
4. Используйте `shift $((OPTIND-1))` для перехода к параметрам.
5. Сохраните, дайте права: `chmod u+x file_manager.sh`.
6. Запустите: `./file_manager.sh -v -d /home/user -r file1.txt file2.txt`.

### Пример решения:

```bash
#!/bin/bash
# Умный файловый менеджер

# Обработка опций
while getopts "hvd:r" opt; do
    case "$opt" in
        h)
            echo "Использование: $0 [-h] [-v] [-d <директория>] [-r] <файлы>"
            echo "  -h    Показать эту справку"
            echo "  -v    Включить подробный вывод"
            echo "  -d    Указать директорию для обработки"
            echo "  -r    Рекурсивно обрабатывать поддиректории"
            exit 0
            ;;
        v)
            verbose=true
            echo "Подробный вывод включён."
            ;;
        d)
            directory="$OPTARG"
            echo "Директория: $directory"
            ;;
        r)
            recursive=true
            echo "Рекурсивный режим включён."
            ;;
        \?)
            echo "Неизвестная опция: -$OPTARG"
            ;;
    esac
done

# Переходим к параметрам
shift $((OPTIND-1))

# Проверяем, что переданы файлы
if [ $# -eq 0 ]; then
    echo "❌ Не переданы файлы. Использование: $0 <файл1> <файл2> ..."
    exit 1
fi

# Выводим список файлов
echo ""
echo "=== Список файлов ==="
count=1
for file in "$@"
do
    if [ -f "$file" ]; then
        size=$(ls -l "$file" | awk '{print $5}')
        echo "Файл #$count: $file (размер: $size байт)"
    elif [ -d "$file" ]; then
        echo "Директория #$count: $file"
    else
        echo "Объект #$count: $file (неизвестный тип)"
    fi
    ((count++))
done

if [ "$verbose" = true ]; then
    echo ""
    echo "Подробная информация:"
    for file in "$@"
    do
        echo "  Имя: $file"
        echo "  Тип: $(file "$file")"
        echo "  ---"
    done
fi
```
