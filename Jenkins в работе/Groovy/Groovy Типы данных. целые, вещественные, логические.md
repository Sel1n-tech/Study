На любом языке программирования вам необходимо использовать различные переменные для хранения различных типов информации.

_**Переменные** - это зарезервированные ячейки памяти для хранения значений_.

Это означает, что при создании переменной вы резервируете некоторое пространство в памяти для хранения значения, связанного с переменной. Можем хранить информацию о различных типах данных, таких как строка, символ,  целое число, вещественные, логическое значение. В зависимости от типа данных переменной операционная система выделяет память и решает, что можно сохранить в зарезервированной объем памяти.

Если рассмотреть типы данных вообщем, то и можно было бы разделить вот на такие общие группы: 

- **Числовые**
    
    - **целочисленные (byte, char, short, int, long)**
        
    - **вещественные**
        
- **Boolean (Логические)**
    
- **String**
    
- **List**
    
- **Array**
    
- **Map (Ассоциативный массив)**
    

## Целочисленные литеральные типы

В Groovy целочисленные литеральные типы такие же, как в Java:

- **byte** - используется для представления байтового значения. Пример 1
- **char** - определяет одно символьный литерал(по факту берется из java). Пример  2
- **short** - используется для обозначения короткого числа. Пример 10
- **int** - используется для представления целых чисел. Пример 1234
- **long** - используется для обозначения длинного числа. Например 100000090.

## **Двоичные числа**

начинаются с **0b**

![](https://lh5.googleusercontent.com/V8kviIWed8CKOxQGELfp1RsB2m6hAQfZcMys_MnL1cGJhGGtFsOeeOsFRTcer-jkAKvbcMPEjS5nMGqiEC3WIk3lwijU0t7fzrhLJN2y6j6RrEwKh5jhUOweKp9f4mHYu6hwJqeq_QZMPSn1xf8QwA)

 Если выполнить код выше то получим на консоли: 

```bash
0b11 == 3: true
0b10101111 == 175: true
```

**0b11 == 3 получили вот так** **(011)₂ = (0 × 2²) + (1 × 2¹) + (1 × 2⁰) = 3**

**0b10101111 получили так** **(010101111)₂ = (0 × 2⁸) + (1 × 2⁷) + (0 × 2⁶) + (1 × 2⁵) +  (0 × 2⁴) + (1 × 2³) + (1 × 2²) + (1 × 2¹) + (1 × 2⁰) = 175**

## **Восьмеричные числа**

начинаются с **0**

![](https://ucarecdn.stepik.net/e1b6293f-45d9-4287-8827-e949393d1dd7/)

**012 получили вот так 012 = (0 × 8²) + (1 × 8¹) + (2 × 8⁰) = 10**

**077 получили так 077 = (0 × 8²) + (7 × 8¹) + (7 × 8⁰) = 63**

# **Шестнадцатеричные числа**

начинаются с **0x**

![](https://lh3.googleusercontent.com/l3zVGqDMawXDBBCnP6zDwmP5xBizwxNQPu5stLuc-SmknNw19JmNdygYVgTSL_Psvb8c43KFT8mQXwuwnaLdHYd2tyKoO0bWJWoWY5kQVYdb9POnJvo2rswrZRH6-gJ2NN31P0qWSSchtUFYyDH3DA)

 Если выполнить код выше то получим на консоли:  

```bash
xInt == 119 true
xShort == 170 true
```

**0x77 получили вот так  (77)₁₆ = (7 × 16¹) + (7 × 16⁰) = (119)₁₀**

**0xaa получим (AA)₁₆ = (10 × 16¹) + (10 × 16⁰) = (170)₁₀**

# **Вещественные числа**

- **float** - используется для представления 32-битных чисел с плавающей запятой. Пример - 1.234
    
- **double** - используется для представления 64-битных чисел с плавающей запятой, которые являются более длинными десятичными числовые представления, которые могут потребоваться время от времени. 
    
- **java.lang.BigDecimal**
    

Типы десятичных литералов такие же, как в Java:

В них могут использоваться экспоненты с буквой **e** или **E**, за которой следует необязательный знак, а также целое число, представляющее показатель степени:

**1e3  ==  1_000.0**

**2E4  == 20_000.0**

При написании длинных буквальных чисел сложнее понять, как некоторые числа сгруппированы вместе, например, с группами из тысяч слов. Вы можете размещать подчеркивание в числовых литералах, для упрощения записи и чтения длинных чисел.

Вы можете создавать десятичные числа этих типов с помощью следующих объявлений:

![](https://lh5.googleusercontent.com/gJ0XtEDqt17FaZpO2d5S_ZVxwTANOqt2fkE5f09v-Uk2lhpd7VyWgQggi5tkHNZwiN_B8U07zsLilvtRCSoXe_R65zPLc-AlColf9FMRzsxqJL5d3aNf9lFK5s59JRpLtL3jXrRARh2-OP6DZRwtmQ)

Для удобства вычисления точных десятичных чисел Groovy выбирает java.lang.BigDecimal тип десятичного числа. Кроме того, оба float и double поддерживаются, но требуют явного объявления типа, приведения типа или суффикса. Даже если BigDecimal это значение по умолчанию для десятичных чисел, такие литералы принимаются в методах или замыканиях, принимающих float или double как типы параметров.

> `Десятичные числа не могут быть представлены в двоичном, восьмеричном или шестнадцатеричном представлении.`

## **Логические значения** 

**Boolean** - это особый тип данных, который используется для представления истинных значений: **true** и **false**.

Используйте этот тип данных для простых флагов, которые отслеживают истинные / ложные условия.

Логические значения могут храниться в переменных, как и любой другой тип данных:

![](https://lh6.googleusercontent.com/lxsG4WA2cg9dywNVQYFLrUmrNXtu7HqEH0z38O0EDgN3x8eBMgpHQ3-vE5sOL6D8gI6gHdulrA_YlaTGEm0rlhJlPpDL9P1dJiwt8-StUQEE42WykxCspB8wC9eqiUL8mqOJRNegLA5crMGbppZhdQ)
