## Когда возникают конфликты?

- **Изменение одних и тех же строк** в разных ветках
- **Удаление файла** в одной ветке и его изменение в другой
- **Переименование файла** в одной ветке и изменение в другой
- **Конфликты в бинарных файлах** (изображения, PDF и т.д.)

## **Как выглядят конфликты?**

```nginx
Git помечает конфликтующие участки в файлах:
<<<<<<< HEAD        # Ваши изменения (текущая ветка)
Ваша версия кода
=======             # Разделитель
Чужие изменения (ветка, которую мержите)
>>>>>>> branch-name
```

## Новые команды

```applescript
# показать различия между конфликтующими версиями
git diff

# показать различия в указанном файле
git diff page2.html

# оставить свою версию файла
git checkout --ours css/styles.css

# принять чужую версию файла
git checkout --theirs web_pages/page3.html

# отменить слияние и вернуться к состоянию до мержа
git merge --abort
```

## Жизненный цикл конфликта

1. **Попытка** **слияния**: git merge feature-branch
2. **Обнаружение конфликта**: Git сообщает о проблеме
3. **Ручное разрешение**: Редактирование конфликтующих файлов
4. **Подтверждение решения**: Добавление файлов и завершение слияния
