## Введение

Вы уже умеете использовать цикл `for` для перебора списков значений и данных из файлов. Но часто нужно автоматически обрабатывать все файлы в директории или выполнить набор команд определённое количество раз. Для этого в Bash есть два мощных инструмента:

- **Шаблоны (wildcards)** — для автоматического перебора файлов.
- **C-подобный синтаксис** — для создания классических циклов с счётчиком.

Этот урок поможет вам:

- Использовать шаблоны (`*`, `?`) для перебора файлов в директории.
- Избежать ошибок при работе с именами файлов, содержащими пробелы.
- Применять C-подобный синтаксис цикла `for`.
- Создавать сложные циклы с несколькими переменными.

## Работа с файлами через шаблоны (Wildcards)

### Зачем это нужно?

Если вы хотите обработать все файлы в директории, но не знаете их имён, используйте шаблоны. Шаблон `*` означает «любое количество любых символов», а `?` — «один любой символ».

### Синтаксис:

```bash
for файл in путь/к/директории/*
do
    команды
done
```

Шаблон `*` заменяется на список всех файлов и директорий в указанной директории. Это называется **file globbing**.

### Перебор всех файлов в директории

Файл `list_files.sh`:

```bash
#!/bin/bash
# Перебираем все файлы в текущей директории

for file in ./*
do
    if [ -d "$file" ]; then
        echo "📁 $file — это директория."
    elif [ -f "$file" ]; then
        echo "📄 $file — это файл."
    else
        echo "❓ $file — неизвестный объект."
    fi
done
```

## Безопасная работа с именами файлов, содержащими пробелы

### Проблема:

Если имя файла содержит пробелы, цикл `for` может работать неправильно, потому что Bash интерпретирует пробел как разделитель.

**Ошибка:**

```bash
for file in /home/user/my files/*
do
    echo "Обрабатываем: $file"
done
```

Если в директории есть файл `My Document.txt`, он будет разбит на `My`, `Document.txt`.

### Всегда оборачивайте `$file` в двойные кавычки!

```bash
for file in /home/user/my\ files/*
do
    echo "Обрабатываем: \"$file\""
done
```

Это гарантирует, что каждое имя файла будет обработано как единое целое.

## C-подобный синтаксис цикла `for`

### Что это такое?

В отличие от классического `for var in list`, в Bash есть ещё один формат цикла — **C-подобный**, который напоминает синтаксис языка C.

### Синтаксис:

```bash
for (( инициализация; условие; шаг ))
do
    команды
done
```

Этот синтаксис идеально подходит для циклов с счётчиком, когда нужно выполнить команды определённое количество раз.

### Вывод чисел от 1 до 10

Файл `count_numbers.sh`:

```bash
#!/bin/bash
# Выводим числа от 1 до 10

for (( i=1; i<=10; i++ ))
do
    echo "Следующее число: $i"
done
```

Обратите внимание: переменная `i` не требует знака `$` внутри `(( ))`.

## Использование нескольких переменных

C-подобный цикл позволяет использовать несколько переменных одновременно, каждая из которых может иметь свой собственный процесс итерации.

### Две переменные — одна увеличивается, другая уменьшается

Файл `two_counters.sh`:

```bash
#!/bin/bash
# Две переменные в одном цикле

for (( a=1, b=10; a<=10; a++, b-- ))
do
    echo "$a - $b"
done
```

## Практическое задание: создайте скрипт «Анализ файлов»

### Цель:

Написать скрипт `analyze_files.sh`, который:

1. Принимает путь к директории как аргумент (`$1`).
2. Проверяет, существует ли директория.
3. Если директория существует — перебирает все файлы в ней.
4. Для каждого файла выводит:
    - Имя файла.
    - Размер файла.
    - Тип файла (файл или директория).
5. В конце выводит общее количество файлов и директорий.

### Инструкция:

1. Создайте файл `analyze_files.sh`.
2. Добавьте shebang `#!/bin/bash`.
3. Проверьте количество аргументов: `if [ $# -ne 1 ]; then ... exit 1; fi`.
4. Проверьте существование директории: `if [ ! -d "$1" ]; then ... exit 1; fi`.
5. Используйте `for file in "$1"/*` для перебора файлов.
6. Используйте `[ -f "$file" ]` и `[ -d "$file" ]` для проверки типа файла.
7. Используйте `ls -l "$file" | awk '{print $5}'` для получения размера файла.
8. Сохраните, дайте права: `chmod u+x analyze_files.sh`.
9. Запустите: `./analyze_files.sh /path/to/directory`.

### Пример решения:

```bash
#!/bin/bash
# Анализ файлов в директории

if [ $# -ne 1 ]; then
    echo "Использование: $0 <путь_к_директории>"
    exit 1
fi

directory="$1"

if [ ! -d "$directory" ]; then
    echo "❌ Директория '$directory' не существует."
    exit 1
fi

echo "Анализируем директорию: $directory"
echo ""

file_count=0
dir_count=0

for file in "$directory"/*
do
    if [ -f "$file" ]; then
        size=$(ls -l "$file" | awk '{print $5}')
        echo "📄 Файл: $(basename "$file") | Размер: $size байт"
        ((file_count++))
    elif [ -d "$file" ]; then
        echo "📁 Директория: $(basename "$file")"
        ((dir_count++))
    fi
done

echo ""
echo "=== Статистика ==="
echo "Файлов: $file_count"
echo "Директорий: $dir_count"
```
