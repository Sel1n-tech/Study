## Введение

Вы уже умеете создавать скрипты, которые выполняют команды, принимают решения и работают с файлами. Но что, если нужно **управлять** скриптом во время его выполнения? Например, остановить его, приостановить или обработать сигнал от системы?

Для этого в Linux используются **сигналы** — специальные сообщения, которые отправляются процессам для управления их работой.

Этот урок поможет вам:

- Понять, что такое сигналы и как они работают.
- Научиться обрабатывать сигналы с помощью команды `trap`.
- Использовать клавиатурные комбинации (`Ctrl+C`, `Ctrl+Z`) для управления процессами.
- Создавать надёжные скрипты, которые корректно реагируют на сигналы.

## Что такое сигналы?

### Определение

Сигнал — это **сообщение**, которое операционная система отправляет процессу для управления его работой. Сигналы могут быть отправлены пользователем (например, нажатием `Ctrl+C`), другим процессом или самой системой.

### Самые распространённые сигналы:

|Сигнал|Название|Описание|
|---|---|---|
|`SIGINT` (2)|Прерывание|Отправляет `Ctrl+C`. Обычно завершает процесс.|
|`SIGQUIT` (3)|Завершение|Отправляет `Ctrl+\`. Завершает процесс и создаёт дамп памяти.|
|`SIGTERM` (15)|Завершение|Запрос на завершение. Процесс может его игнорировать.|
|`SIGKILL` (9)|Уничтожение|Принудительное завершение. Нельзя игнорировать.|
|`SIGSTOP` (17)|Приостановка|Приостанавливает процесс. Нельзя игнорировать.|
|`SIGCONT` (19)|Продолжение|Возобновляет приостановленный процесс.|

Сигналы `SIGINT` и `SIGTERM` можно перехватить и обработать в скрипте. Сигналы `SIGKILL` и `SIGSTOP` нельзя игнорировать — они всегда приводят к немедленному завершению или приостановке процесса.

## Клавиатурные комбинации

### Прерывание процесса (`Ctrl+C`)

Нажатие `Ctrl+C` отправляет сигнал `SIGINT` текущему процессу, который обычно завершает его работу.

### Прерывание цикла

Файл `interrupt_loop.sh`:

```bash
#!/bin/bash
# Цикл, который можно прервать

echo "Нажмите Ctrl+C для выхода."
while true; do
    echo "Работаю..."
    sleep 1
done
```

Нажатие `Ctrl+C` завершило цикл.

### Приостановка процесса (`Ctrl+Z`)

Нажатие `Ctrl+Z` отправляет сигнал `SIGTSTP`, который **приостанавливает** процесс. Процесс остаётся в памяти и может быть возобновлён.

### Приостановка и возобновление

Файл `pause_process.sh`:

```bash
#!/bin/bash
# Приостановка процесса

echo "Нажмите Ctrl+Z для приостановки."
while true; do
    echo "Работаю..."
    sleep 1
done
```

Процесс был приостановлен. Чтобы возобновить его, введите `fg`.

## Команда `trap` — обработка сигналов

### Что это такое?

Команда `trap` позволяет указать, какие команды выполнять при получении определённого сигнала.

### Синтаксис:

```bash
trap 'команды' сигнал
```

Можно указывать несколько сигналов через пробел. Например, `trap 'cleanup' SIGINT SIGTERM`.

### Обработка `SIGINT`

Файл `handle_sigint.sh`:

```bash
#!/bin/bash
# Обработка сигнала SIGINT

cleanup() {
    echo ""
    echo "Очистка и завершение работы..."
    exit 0
}

# Устанавливаем обработчик сигнала SIGINT
trap cleanup SIGINT

echo "Нажмите Ctrl+C для выхода."
while true; do
    echo "Работаю..."
    sleep 1
done
```

![](https://ucarecdn.stepik.net/62e5d0c7-ca68-4a4f-918e-cedb54ea55e6/)

При нажатии `Ctrl+C` вызывается функция `cleanup`, которая выводит сообщение и завершает скрипт.

## Обработка нескольких сигналов

Можно установить один обработчик для нескольких сигналов.

### Обработка `SIGINT` и `SIGTERM`

Файл `handle_multiple_signals.sh`:

```bash
#!/bin/bash
# Обработка нескольких сигналов

cleanup() {
    echo ""
    echo "Очистка и завершение работы..."
    exit 0
}

# Устанавливаем обработчик для SIGINT и SIGTERM
trap cleanup SIGINT SIGTERM

echo "Нажмите Ctrl+C или отправьте SIGTERM для выхода."
while true; do
    echo "Работаю..."
    sleep 1
done
```

## Практическое задание: создайте скрипт «Безопасное завершение»

### Цель:

Написать скрипт `safe_exit.sh`, который:

1. Запускает бесконечный цикл.
2. Устанавливает обработчики для `SIGINT` и `SIGTERM`.
3. При получении сигнала:
    - Выводит сообщение «Завершение...».
    - Удаляет временный файл `temp.txt`.
    - Завершает работу.

### Инструкция:

1. Создайте файл `safe_exit.sh`.
2. Добавьте shebang `#!/bin/bash`.
3. Создайте временный файл `temp.txt`.
4. Напишите функцию `cleanup`, которая удаляет файл и завершает скрипт.
5. Используйте `trap` для установки обработчиков.
6. Запустите цикл `while true`.
7. Сохраните, дайте права: `chmod u+x safe_exit.sh`.
8. Запустите: `./safe_exit.sh`.

### Пример решения:

```bash
#!/bin/bash
# Безопасное завершение

# Создаём временный файл
touch temp.txt
echo "Временный файл temp.txt создан."

# Функция очистки
cleanup() {
    echo ""
    echo "Завершение работы. Удаляем временный файл..."
    rm temp.txt
    echo "Временный файл удалён. До свидания!"
    exit 0
}

# Устанавливаем обработчики сигналов
trap cleanup SIGINT SIGTERM

echo "Нажмите Ctrl+C или отправьте SIGTERM для выхода."
while true; do
    echo "Работаю..."
    sleep 1
done
```
