## Введение

Вы уже умеете создавать скрипты, которые выполняют команды, принимают решения и работают с циклами. Но часто нужно, чтобы скрипт **принимал данные извне** — например, числа для вычислений, имена файлов для обработки или строки для вывода. Для этого в Bash используются **параметры командной строки**.

Этот урок поможет вам:

- Понять, как передавать параметры в скрипт.
- Использовать специальные переменные `$1`, `$2`, `$@` и `$*`.
- Обрабатывать строки с пробелами.
- Получать имя скрипта с помощью `$0` и `basename`.

## Что такое параметры командной строки?

Параметры командной строки — это данные, которые вы передаёте скрипту при его запуске. Они разделяются пробелами.

### Пример:

```bash
./addem.sh 10 30
```

Здесь `10` и `30` — это параметры, которые скрипт может использовать внутри себя.

Параметры доступны через специальные переменные: `$1`, `$2`, `$3` и т.д.

## Позиционные параметры (`$1`, `$2`, ...)

Когда вы запускаете скрипт с параметрами, Bash автоматически присваивает их значения специальным переменным:

|Переменная|Значение|
|---|---|
|`$0`|Имя скрипта (или полный путь к нему)|
|`$1`|Первый параметр|
|`$2`|Второй параметр|
|`$n`|n-й параметр (до `$9`)|
|`${10}`|Десятый и последующие параметры (обязательно в фигурных скобках!)|

### Вычисление факториала

Файл `factorial.sh`:

```bash
#!/bin/bash
# Вычисляем факториал числа, переданного как параметр

number=$1
factorial=1

for (( i=1; i<=number; i++ ))
do
    factorial=$((factorial * i))
done

echo "Факториал числа $number равен $factorial"
```

Переменная `$1` содержит значение первого параметра — `7`.

## Работа со строками и пробелами

Если параметр содержит пробелы, его нужно заключить в кавычки, иначе Bash разобьёт его на несколько параметров.

### Приветствие с именем

Файл `greet.sh`:

```bash
#!/bin/bash
# Приветствуем пользователя

echo "Привет, $1! Рад тебя видеть."
```

![](https://ucarecdn.stepik.net/53cd650b-ab8d-4210-be5a-11cfcb66e915/)

Без кавычек `Святослав Владимирович` воспринимается как два параметра — `$1="Святослав"`, `$2="Владимирович"`. С кавычками — один параметр.

Всегда оборачивайте параметры в двойные кавычки: `"$1"` — это предотвращает ошибки при пустых значениях или значениях с пробелами.

## Переменные `$@` и `$*`

Иногда нужно получить **все параметры** сразу — для этого используются переменные `$@` и `$*`.

|Переменная|Описание|
|---|---|
|`$@`|Все параметры как отдельные слова (`"$1" "$2" ...`) — предпочтительно|
|`$*`|Все параметры как одна строка (`"$1 $2 ..."`)|

### Вывод всех параметров

Файл `show_params.sh`:

```bash
#!/bin/bash
# Выводим все переданные параметры

echo "Все параметры через \$@:"
for param in "$@"
do
    echo "  - $param"
done

echo ""
echo "Все параметры через \$*:"
echo "  - $*"
```

![](https://ucarecdn.stepik.net/8352a780-991c-44da-828d-0b3e9845c880/)

Используйте `$@` — он сохраняет границы слов и работает корректно с пробелами.

## Получение имени скрипта

Переменная `$0` содержит имя скрипта (или полный путь к нему). Иногда нужно получить только имя без пути — для этого используется команда `basename`.

### Использование `basename`

Файл `script_name.sh`:

```bash
#!/bin/bash
# Получаем имя скрипта

script_name=$(basename "$0")
echo "Имя скрипта: $script_name"

# Можно использовать имя скрипта для выбора действия
if [ "$script_name" = "addem.sh" ]; then
    result=$(( $1 + $2 ))
    echo "Сумма: $result"
elif [ "$script_name" = "mul.sh" ]; then
    result=$(( $1 * $2 ))
    echo "Произведение: $result"
fi
```

Теперь один и тот же код может выполнять разные действия в зависимости от имени файла.

## Практическое задание: создайте скрипт «Калькулятор»

### Цель:

Написать скрипт `calc.sh`, который:

1. Принимает три параметра: число1, операция (+, -, *, /), число2.
2. Выполняет указанную операцию.
3. Выводит результат.
4. Если операция не поддерживается — выводит сообщение об ошибке.

### Инструкция:

1. Создайте файл `calc.sh`.
2. Добавьте shebang `#!/bin/bash`.
3. Проверьте количество аргументов: `if [ $# -ne 3 ]; then ... exit 1; fi`.
4. Присвойте параметры переменным: `num1=$1`, `op=$2`, `num2=$3`.
5. Используйте `case` для выбора операции.
6. Сохраните, дайте права: `chmod u+x calc.sh`.
7. Запустите: `./calc.sh 10 + 5`, `./calc.sh 10 * 3`.

### Пример решения:

```bash
#!/bin/bash
# Калькулятор

if [ $# -ne 3 ]; then
    echo "Использование: $0 <число1> <операция> <число2>"
    echo "Операции: +, -, *, /"
    exit 1
fi

num1=$1
op=$2
num2=$3

case "$op" in
    "+")
        result=$(( num1 + num2 ))
        echo "$num1 + $num2 = $result"
        ;;
    "-")
        result=$(( num1 - num2 ))
        echo "$num1 - $num2 = $result"
        ;;
    "*")
        result=$(( num1 * num2 ))
        echo "$num1 * $num2 = $result"
        ;;
    "/")
        if [ $num2 -eq 0 ]; then
            echo "Деление на ноль невозможно!"
            exit 1
        fi
        result=$(( num1 / num2 ))
        echo "$num1 / $num2 = $result"
        ;;
    *)
        echo "Неизвестная операция: $op"
        echo "Поддерживаемые операции: +, -, *, /"
        exit 1
        ;;
esac
```
